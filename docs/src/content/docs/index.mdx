## Features

<CardGrid stagger>
	<Card title="Modular Architecture" icon="puzzle">
		Extend functionality with 8+ official plugins including OAuth, JWT, and Multi-tenancy that you can opt-in to.
	</Card>
	<Card title="Type-Safe & Compiled" icon="approve-check">
		Built with Go idioms in mind. No runtime schema magic—everything is strongly typed and checked at compile time.
	</Card>
	<Card title="Database Agnostic" icon="setting">

	</Card>
	<Card title="High Performance" icon="rocket">
		Designed for speed with minimal allocation overhead and efficient session management using Redis.
	</Card>
