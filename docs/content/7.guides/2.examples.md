## Basic Authentication

A simple authentication setup with email and password.

::card-group
  :::card
  ---
  title: View Example
  to: https://github.com/theinventorylib/aegis/tree/main/examples/01-basic-auth
  target: _blank
  icon: i-simple-icons-github
  ---
  Complete working example with sign up, sign in, and protected routes.
  :::
::

```go
package main

import (
    "database/sql"
    "log"
    "net/http"
    
    "github.com/go-chi/chi/v5"
    "github.com/theinventorylib/aegis"
    "github.com/theinventorylib/aegis/core"
    "github.com/theinventorylib/aegis/router"
)

func main() {
    db, _ := sql.Open("postgres", "postgres://localhost/myapp")
    
    auth := aegis.New(&core.Config{
        DB:      db,
        Secret:  "your-secret-key-32-chars-minimum!",
        BaseURL: "http://localhost:8080",
    })
    
    r := chi.NewRouter()
    router.Mount(r, auth)
    
    // Protected routes
    r.Group(func(r chi.Router) {
        r.Use(auth.RequireAuth())
        r.Get("/api/profile", profileHandler)
    })
    
    http.ListenAndServe(":8080", r)
}
```

## OAuth Integration

Add social login with Google and GitHub.

::card-group
  :::card
  ---
  title: View Example
  to: https://github.com/theinventorylib/aegis/tree/main/examples/02-oauth-auth
  target: _blank
  icon: i-simple-icons-github
  ---
  OAuth setup with Google, GitHub, and callback handling.
  :::
::

```go
import (
    "github.com/theinventorylib/aegis/plugins/oauth"
)

oauthPlugin := oauth.New(&oauth.Config{
    Providers: []oauth.Provider{
        {
            Name:         "google",
            ClientID:     os.Getenv("GOOGLE_CLIENT_ID"),
            ClientSecret: os.Getenv("GOOGLE_CLIENT_SECRET"),
            RedirectURL:  "http://localhost:8080/auth/callback/google",
            Scopes:       []string{"email", "profile"},
        },
        {
            Name:         "github",
            ClientID:     os.Getenv("GITHUB_CLIENT_ID"),
            ClientSecret: os.Getenv("GITHUB_CLIENT_SECRET"),
            RedirectURL:  "http://localhost:8080/auth/callback/github",
            Scopes:       []string{"user:email"},
        },
    },
})

auth.Use(oauthPlugin)
```

## Multi-Tenant Organizations

Implement organizations with teams and permissions.

::card-group
  :::card
  ---
  title: View Example
  to: https://github.com/theinventorylib/aegis/tree/main/examples/03-organizations
  target: _blank
  icon: i-simple-icons-github
  ---
  Multi-tenant setup with organizations, members, and roles.
  :::
::

```go
import (
    "github.com/theinventorylib/aegis/plugins/organizations"
)

orgsPlugin := organizations.New(&organizations.Config{
    DefaultRole:      "member",
    MaxMembersPerOrg: 100,
})

auth.Use(orgsPlugin)

// Create organization
r.Post("/orgs", func(w http.ResponseWriter, r *http.Request) {
    user := core.GetUser(r.Context())
    org, err := orgsPlugin.CreateOrg(r.Context(), "My Company", user.ID)
    // ...
})

// Check organization membership
r.Get("/orgs/{orgID}/data", func(w http.ResponseWriter, r *http.Request) {
    user := core.GetUser(r.Context())
    orgID := chi.URLParam(r, "orgID")
    
    isMember, _ := orgsPlugin.IsMember(r.Context(), orgID, user.ID)
    if !isMember {
        http.Error(w, "Forbidden", http.StatusForbidden)
        return
    }
    // ...
})
```

## JWT API Authentication

Build a JWT-based API with token rotation.

::card-group
  :::card
  ---
  title: View Example
  to: https://github.com/theinventorylib/aegis/tree/main/examples/04-api-jwt
  target: _blank
  icon: i-simple-icons-github
  ---
  RESTful API with JWT authentication and refresh tokens.
  :::
::

```go
import (
    "github.com/theinventorylib/aegis/plugins/jwt"
)

jwtPlugin := jwt.New(&jwt.Config{
    SigningMethod: "HS256",
    Issuer:        "myapp.com",
    ExpiresIn:     15 * time.Minute,
})

auth.Use(jwtPlugin)

// Login and get JWT
r.Post("/api/login", func(w http.ResponseWriter, r *http.Request) {
    // ... authenticate user
    token, _ := jwtPlugin.GenerateToken(user.ID, nil)
    json.NewEncoder(w).Encode(map[string]string{
        "token": token,
    })
})

// Protected API endpoint
r.Group(func(r chi.Router) {
    r.Use(jwtPlugin.Middleware())
    r.Get("/api/data", dataHandler)
})
```

## Real-World Patterns

### Rate Limiting

Protect authentication endpoints from brute force attacks:

```go
import (
    "github.com/ulule/limiter/v3"
    "github.com/ulule/limiter/v3/drivers/store/memory"
)

store := memory.NewStore()
rate := limiter.Rate{
    Period: 1 * time.Hour,
    Limit:  5,
}
middleware := limiter.NewMiddleware(limiter.New(store, rate))

r.With(middleware.Handler).Post("/auth/signin", signinHandler)
```

### Email Verification Flow

Require email verification before access:

```go
import (
    "github.com/theinventorylib/aegis/plugins/emailotp"
)

emailPlugin := emailotp.New(&emailotp.Config{
    SendEmail: sendEmailFunc,
})

auth.Use(emailPlugin)

// After signup, send verification
r.Post("/auth/signup", func(w http.ResponseWriter, r *http.Request) {
    user, _ := auth.CreateUser(ctx, email, password)
    emailPlugin.SendVerification(ctx, user.ID, user.Email)
    // ...
})

// Middleware to check verification
func requireVerified(next http.Handler) http.Handler {
    return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
        user := core.GetUser(r.Context())
        if !user.EmailVerified {
            http.Error(w, "Email not verified", http.StatusForbidden)
            return
        }
        next.ServeHTTP(w, r)
    })
}
```

### Redis Session Caching

Use Redis for high-performance session storage:

```go
import (
    "github.com/redis/go-redis/v9"
)

redisClient := redis.NewClient(&redis.Options{
    Addr:     "localhost:6379",
    Password: "",
    DB:       0,
})

auth := aegis.New(&core.Config{
    DB:          db,
    Secret:      secret,
    BaseURL:     baseURL,
    RedisClient: redisClient,
})
```
