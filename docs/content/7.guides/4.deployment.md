## Deployment Guide

Learn how to deploy Aegis applications to various platforms.

## Prerequisites

Before deploying:

- [ ] Run migrations on production database
- [ ] Set environment variables
- [ ] Configure HTTPS/TLS
- [ ] Set up monitoring
- [ ] Test in staging environment

## Environment Variables

Create a `.env` file (never commit this):

```bash
# Database
DATABASE_URL=postgres://user:password@localhost:5432/myapp

# Aegis
AEGIS_SECRET=your-production-secret-32-chars-minimum
BASE_URL=https://yourapp.com

# Redis (optional)
REDIS_URL=redis://localhost:6379

# OAuth (if using)
GOOGLE_CLIENT_ID=your-google-client-id
GOOGLE_CLIENT_SECRET=your-google-secret
GITHUB_CLIENT_ID=your-github-client-id
GITHUB_CLIENT_SECRET=your-github-secret

# Email (if using)
SMTP_HOST=smtp.example.com
SMTP_PORT=587
SMTP_USER=your-email@example.com
SMTP_PASSWORD=your-smtp-password
```

## Docker Deployment

### Dockerfile

```dockerfile
FROM golang:1.25-alpine AS builder

WORKDIR /app
COPY go.mod go.sum ./
RUN go mod download

COPY . .
RUN CGO_ENABLED=0 GOOS=linux go build -o main .

FROM alpine:latest
RUN apk --no-cache add ca-certificates

WORKDIR /root/
COPY --from=builder /app/main .

EXPOSE 8080
CMD ["./main"]
```

### docker-compose.yml

```yaml
version: '3.8'

services:
  app:
    build: .
    ports:
      - "8080:8080"
    environment:
      - DATABASE_URL=postgres://postgres:password@db:5432/myapp
      - AEGIS_SECRET=${AEGIS_SECRET}
      - BASE_URL=https://yourapp.com
      - REDIS_URL=redis://redis:6379
    depends_on:
      - db
      - redis
    restart: unless-stopped

  db:
    image: postgres:15-alpine
    environment:
      - POSTGRES_PASSWORD=password
      - POSTGRES_DB=myapp
    volumes:
      - postgres_data:/var/lib/postgresql/data
    restart: unless-stopped

  redis:
    image: redis:7-alpine
    restart: unless-stopped

volumes:
  postgres_data:
```

Deploy with:

```bash
docker-compose up -d
```

## Cloud Platforms

### Railway

1. Create a new project on [Railway](https://railway.app)
2. Add PostgreSQL and Redis services
3. Connect your GitHub repository
4. Set environment variables
5. Deploy

```bash
# Install Railway CLI
npm i -g @railway/cli

# Login
railway login

# Deploy
railway up
```

### Render

Create `render.yaml`:

```yaml
services:
  - type: web
    name: aegis-app
    env: go
    buildCommand: go build -o main .
    startCommand: ./main
    envVars:
      - key: DATABASE_URL
        fromDatabase:
          name: aegis-db
          property: connectionString
      - key: AEGIS_SECRET
        generateValue: true
      - key: BASE_URL
        value: https://yourapp.onrender.com
      - key: REDIS_URL
        fromService:
          name: aegis-redis
          type: redis
          property: connectionString

databases:
  - name: aegis-db
    databaseName: aegis
    user: aegis

  - name: aegis-redis
    type: redis
```

Deploy:

```bash
# Connect repository to Render
# Push to main branch
git push origin main
```

### AWS (ECS/Fargate)

1. **Build and push Docker image**:

```bash
aws ecr get-login-password --region us-east-1 | \
  docker login --username AWS --password-stdin your-account.dkr.ecr.us-east-1.amazonaws.com

docker build -t aegis-app .
docker tag aegis-app:latest your-account.dkr.ecr.us-east-1.amazonaws.com/aegis-app:latest
docker push your-account.dkr.ecr.us-east-1.amazonaws.com/aegis-app:latest
```

2. **Create task definition** (`task-definition.json`):

```json
{
  "family": "aegis-app",
  "networkMode": "awsvpc",
  "requiresCompatibilities": ["FARGATE"],
  "cpu": "256",
  "memory": "512",
  "containerDefinitions": [
    {
      "name": "aegis-app",
      "image": "your-account.dkr.ecr.us-east-1.amazonaws.com/aegis-app:latest",
      "portMappings": [
        {
          "containerPort": 8080,
          "protocol": "tcp"
        }
      ],
      "environment": [
        {
          "name": "BASE_URL",
          "value": "https://yourapp.com"
        }
      ],
      "secrets": [
        {
          "name": "DATABASE_URL",
          "valueFrom": "arn:aws:secretsmanager:region:account:secret:db-url"
        },
        {
          "name": "AEGIS_SECRET",
          "valueFrom": "arn:aws:secretsmanager:region:account:secret:aegis-secret"
        }
      ]
    }
  ]
}
```

3. **Create ECS service**:

```bash
aws ecs create-service \
  --cluster your-cluster \
  --service-name aegis-service \
  --task-definition aegis-app \
  --desired-count 2 \
  --launch-type FARGATE \
  --network-configuration "awsvpcConfiguration={subnets=[subnet-xxx],securityGroups=[sg-xxx],assignPublicIp=ENABLED}"
```

## Database Migrations

### Production Migration Strategy

```bash
# 1. Backup database
pg_dump $DATABASE_URL > backup.sql

# 2. Apply migrations
aegis export --dialect postgres --format golang-migrate --output ./migrations
migrate -path ./migrations -database $DATABASE_URL up

# 3. Verify
psql $DATABASE_URL -c "SELECT * FROM schema_migrations;"
```

### Zero-Downtime Migrations

1. **Make schema backward compatible**
2. **Deploy new code**
3. **Run migrations**
4. **Remove old code paths**

Example:

```sql
-- Step 1: Add new column (nullable)
ALTER TABLE users ADD COLUMN new_field TEXT;

-- Step 2: Backfill data (after deployment)
UPDATE users SET new_field = old_field WHERE new_field IS NULL;

-- Step 3: Make non-nullable (in next migration)
ALTER TABLE users ALTER COLUMN new_field SET NOT NULL;

-- Step 4: Drop old column (in later migration)
ALTER TABLE users DROP COLUMN old_field;
```

## Monitoring

### Health Check Endpoint

```go
r.Get("/health", func(w http.ResponseWriter, r *http.Request) {
    // Check database
    if err := db.Ping(); err != nil {
        http.Error(w, "Database unhealthy", http.StatusServiceUnavailable)
        return
    }
    
    // Check Redis (if using)
    if redisClient != nil {
        if err := redisClient.Ping(r.Context()).Err(); err != nil {
            http.Error(w, "Redis unhealthy", http.StatusServiceUnavailable)
            return
        }
    }
    
    w.WriteHeader(http.StatusOK)
    w.Write([]byte("OK"))
})
```

### Prometheus Metrics

```go
import (
    "github.com/prometheus/client_golang/prometheus"
    "github.com/prometheus/client_golang/prometheus/promhttp"
)

var (
    authAttempts = prometheus.NewCounterVec(
        prometheus.CounterOpts{
            Name: "auth_attempts_total",
            Help: "Total authentication attempts",
        },
        []string{"method", "status"},
    )
)

func init() {
    prometheus.MustRegister(authAttempts)
}

// Instrument your handlers
authAttempts.WithLabelValues("email", "success").Inc()

// Expose metrics endpoint
r.Handle("/metrics", promhttp.Handler())
```

### Logging

```go
import (
    "log/slog"
    "github.com/theinventorylib/aegis/core"
)

// Structured logging with automatic context extraction
slog.Info("authentication successful",
    "user_id", user.ID,
    "method", "email",
    "ip", core.GetIPAddress(r.Context()), // Extracted from context
    "user_agent", core.GetUserAgent(r.Context()),
)

slog.Error("database error",
    "error", err.Error(),
    "operation", "CreateUser",
)
```

## SSL/TLS Configuration

### Let's Encrypt with Caddy

Create `Caddyfile`:

```
yourapp.com {
    reverse_proxy localhost:8080
}
```

Run:

```bash
caddy run
```

### Manual Certificate

```go
import "crypto/tls"

tlsConfig := &tls.Config{
    MinVersion: tls.VersionTLS12,
    CurvePreferences: []tls.CurveID{
        tls.CurveP256,
        tls.X25519,
    },
    CipherSuites: []uint16{
        tls.TLS_ECDHE_ECDSA_WITH_AES_256_GCM_SHA384,
        tls.TLS_ECDHE_RSA_WITH_AES_256_GCM_SHA384,
    },
}

server := &http.Server{
    Addr:      ":443",
    Handler:   router,
    TLSConfig: tlsConfig,
}

server.ListenAndServeTLS("cert.pem", "key.pem")
```

## Scaling

### Horizontal Scaling

- Use Redis for session storage (shared across instances)
- Database connection pooling
- Load balancer (ALB, Nginx)
- Stateless application design

### Vertical Scaling

Tune resources based on load:

```go
db.SetMaxOpenConns(25)
db.SetMaxIdleConns(25)
db.SetConnMaxLifetime(5 * time.Minute)
```

### Caching Strategy

```go
// Cache session lookups
if cached, err := redisClient.Get(ctx, "session:"+token).Result(); err == nil {
    return parseSession(cached), nil
}

// Fall back to database
session, err := store.GetSession(ctx, token)
if err == nil {
    // Cache for 15 minutes
    redisClient.Set(ctx, "session:"+token, session, 15*time.Minute)
}
```

## Troubleshooting

### High Memory Usage

- Check connection pool settings
- Monitor goroutine leaks
- Use pprof for profiling

### Slow Queries

- Add database indexes
- Use EXPLAIN ANALYZE
- Enable query logging

### Session Issues

- Verify Redis connection
- Check clock synchronization
- Review session expiration settings
