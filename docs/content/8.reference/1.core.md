# Core API Reference

The `aegis` package provides the main entry point for the framework.

## Types

### `Aegis`
The main struct that holds all authentication state and services.

```go
type Aegis struct {
    // ... internal fields
}
```

### `Config`
Configuration passed to `New`.

```go
type Config struct {
    // DB Connection (required)
    DB *sql.DB
    
    // Master Secret for signing tokens (required, min 32 chars)
    Secret string
    
    // Base URL of the application
    BaseURL string
    
    // Session Configuration
    Session *SessionConfig
    
    // Password Policy
    PasswordPolicy *PasswordPolicyConfig
}
```

## Methods

### `New`
Creates a new Aegis instance.

```go
func New(ctx context.Context, cfg *config.Config) (*Aegis, error)
```

### `Use`
Registers a plugin.

```go
func (a *Aegis) Use(ctx context.Context, plugin Plugin) error
```

### `AuthMiddleware`
Returns the main authentication middleware.

```go
func (a *Aegis) AuthMiddleware() func(http.Handler) http.Handler
```

### `MountRoutes`
Mounts authentication routes to a router.

```go
func (a *Aegis) MountRoutes(prefix string)
```

## Config Package

### `SessionConfig`

```go
type SessionConfig struct {
    SessionExpiry time.Duration // Default: 24h
    RefreshExpiry time.Duration // Default: 7d
    CookieSettings CookieSettings
    Redis *RedisConfig
}
```

### `RedisConfig`

```go
type RedisConfig struct {
    Host string
    Port int
    Password string
    DB int
}
```
