# Core API Reference

The `aegis` package provides the main entry point for the framework.

## Types

### `Aegis`
The main struct that holds all authentication state and services.

```go
type Aegis struct {
    // ... internal fields
}
```

### `Config`
Configuration created via builder pattern using `config.Default()`.

```go
// Create with builder pattern
cfg := config.Default().
    WithDB(db).                    // *sql.DB (required)
    WithRouter(r).                 // router.Router (required)
    WithSecret([]byte("...")).     // []byte (required, min 32 bytes)
    WithSessionExpiry(24 * time.Hour).
    WithRefreshExpiry(7 * 24 * time.Hour).
    WithCookieName("aegis_session").
    WithCookieDomain("").
    WithCookieSecure(true).
    WithCookieHTTPOnly(true).
    WithCookieSameSite("Lax").
    WithAPIOnlyMode(false).
    WithBearerAuth(false).
    WithArgon2Time(1).
    WithArgon2Memory(64 * 1024).
    WithArgon2Threads(4).
    WithRateLimiting(5, time.Minute).
    WithRedis(&config.RedisConfig{...}).
    WithPasswordPolicy(&core.PasswordPolicy{...}).
    WithAuditLogger(auditLogger)
```

## Methods

### `New`
Creates a new Aegis instance.

```go
func New(ctx context.Context, cfg *config.Config) (*Aegis, error)
```

### `Use`
Registers a plugin.

```go
func (a *Aegis) Use(ctx context.Context, plugin Plugin) error
```

### `AuthMiddleware`
Returns the main authentication middleware.

```go
func (a *Aegis) AuthMiddleware() func(http.Handler) http.Handler
```

### `MountRoutes`
Mounts authentication routes to a router.

```go
func (a *Aegis) MountRoutes(prefix string)
```

## Config Package

### Builder Methods

| Method | Description | Default |
|--------|-----------|----------|
| `WithDB(db)` | Set database connection | required |
| `WithRouter(r)` | Set router (use `router.NewChiRouter`) | required |
| `WithSecret([]byte)` | Set signing secret (min 32 bytes) | required |
| `WithSessionExpiry(d)` | Session duration | `24h` |
| `WithRefreshExpiry(d)` | Refresh token duration | `7d` |
| `WithCookieName(s)` | Session cookie name | `"aegis_session"` |
| `WithCookieDomain(s)` | Cookie domain | `""` |
| `WithCookieSecure(b)` | HTTPS-only cookies | `true` |
| `WithCookieHTTPOnly(b)` | HttpOnly cookies | `true` |
| `WithCookieSameSite(s)` | SameSite attribute | `"Lax"` |
| `WithAPIOnlyMode(b)` | API-only (no cookies) | `false` |
| `WithBearerAuth(b)` | Enable Bearer token auth | `false` |
| `WithArgon2Time(n)` | Argon2 iterations | `1` |
| `WithArgon2Memory(n)` | Argon2 memory (KB) | `65536` |
| `WithArgon2Threads(n)` | Argon2 threads | `4` |
| `WithRateLimiting(n, d)` | Rate limit config | disabled |
| `WithRedis(cfg)` | Redis configuration | `nil` |
| `WithPasswordPolicy(p)` | Password validation rules | defaults |
| `WithAuditLogger(l)` | Custom audit logger | no-op |

### `RedisConfig`

```go
type RedisConfig struct {
    Addr     string
    Password string

}
```
