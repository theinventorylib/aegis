---
title: Framework Integration
description: Integrate Aegis with Chi, Echo, Gin, and standard net/http using the router adapters.
---

Aegis defines a `Router` interface (`github.com/theinventorylib/aegis/router`) that any HTTP framework can implement. The `router/routers` sub-package ships ready-made adapters for Chi, Gin, and Echo.

## Router Interface

All adapters implement the same `router.Router` interface:

```go
type Router interface {
    GET(path string, handler http.HandlerFunc)
    POST(path string, handler http.HandlerFunc)
    PUT(path string, handler http.HandlerFunc)
    PATCH(path string, handler http.HandlerFunc)
    DELETE(path string, handler http.HandlerFunc)
    Use(middleware func(http.Handler) http.Handler)
    ServeHTTP(w http.ResponseWriter, r *http.Request)
    Group(path, groupName string) GroupRouter
}
```

Pass any `Router` implementation to Aegis via `config.WithRouter(r)`. All three adapters live in `github.com/theinventorylib/aegis/router/routers`.

## Chi (Recommended)

Chi is the recommended router. Use `routers.NewChiRouter` to wrap a `*chi.Mux`:

```go
import (
    "net/http"

    "github.com/go-chi/chi/v5"
    "github.com/theinventorylib/aegis"
    "github.com/theinventorylib/aegis/config"
    "github.com/theinventorylib/aegis/router/routers"
)

mux := chi.NewRouter()
r := routers.NewChiRouter(mux)

cfg := config.Default().
    WithDB(db).
    WithRouter(r).
    WithSecret([]byte("your-secret-key-must-be-32-chars!"))

a, err := aegis.New(ctx, cfg)
if err != nil {
    log.Fatal(err)
}

// Mount all auth routes under /auth
a.MountRoutes("/auth")

// Chi's own middleware and routes work alongside Aegis
mux.Use(a.AuthMiddleware())
mux.Group(func(r chi.Router) {
    r.Use(a.RequireAuth())
    r.Get("/dashboard", dashboardHandler)
})

http.ListenAndServe(":8080", mux)
```

## Gin

Use `routers.NewGinRouter` to wrap a `*gin.Engine`. Standard `net/http` handlers are automatically bridged via `gin.WrapF`:

```go
import (
    "net/http"

    "github.com/gin-gonic/gin"
    "github.com/theinventorylib/aegis"
    "github.com/theinventorylib/aegis/config"
    "github.com/theinventorylib/aegis/router/routers"
)

engine := gin.Default()
r := routers.NewGinRouter(engine)

cfg := config.Default().
    WithDB(db).
    WithRouter(r).
    WithSecret([]byte("your-secret-key-must-be-32-chars!"))

a, err := aegis.New(ctx, cfg)
if err != nil {
    log.Fatal(err)
}

a.MountRoutes("/auth")

// Aegis middleware works via echo.WrapMiddleware
engine.Use(gin.WrapH(a.AuthMiddleware()(http.HandlerFunc(
    func(w http.ResponseWriter, r *http.Request) {},
))))

engine.Run(":8080")
```

## Echo

Use `routers.NewEchoRouter` to wrap an `*echo.Echo` instance. The adapter bridges `net/http` types via `echo.WrapHandler` and `echo.WrapMiddleware`:

```go
import (
    "github.com/labstack/echo/v4"
    "github.com/labstack/echo/v4/middleware"
    "github.com/theinventorylib/aegis"
    "github.com/theinventorylib/aegis/config"
    "github.com/theinventorylib/aegis/router/routers"
)

e := echo.New()
e.Use(middleware.Logger())
e.Use(middleware.Recover())
r := routers.NewEchoRouter(e)

cfg := config.Default().
    WithDB(db).
    WithRouter(r).
    WithSecret([]byte("your-secret-key-must-be-32-chars!"))

a, err := aegis.New(ctx, cfg)
if err != nil {
    log.Fatal(err)
}

a.MountRoutes("/auth")

// Apply auth middleware to Echo
e.Use(echo.WrapMiddleware(a.AuthMiddleware()))

e.Start(":8080")
```

## Route Groups

Every adapter supports `Router.Group(path, groupName)` for mounting plugins on a sub-path. Plugins use groups internally to namespace their routes. You can also call `Group` directly:

```go
api := r.Group("/api", "API")
api.GET("/me", meHandler)
api.POST("/orders", createOrderHandler)
```

The returned `GroupRouter` has the same HTTP method set as `Router` and supports nested groups.

## Standard net/http

If you are not using a third-party framework you can implement the `router.Router` interface yourself against any `http.ServeMux` or handler chain, or use Chi with `routers.NewChiRouter` and serve the `chi.Mux` directly:

```go
mux := chi.NewRouter()
r := routers.NewChiRouter(mux)

a, _ := aegis.New(ctx, config.Default().
    WithDB(db).
    WithRouter(r).
    WithSecret(secret),
)

a.MountRoutes("/auth")

http.ListenAndServe(":8080", mux)
```
