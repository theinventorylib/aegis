# Framework Integration

Aegis is built on standard `net/http` interfaces, making it compatible with almost any Go web framework.

## Chi (Official Support)

Aegis provides first-class support for `go-chi`, as it is built on `net/http` standards.

```go
import (
    "github.com/go-chi/chi/v5"
    "github.com/theinventorylib/aegis/router"
)

r := chi.NewRouter()

// Mount all auth routes at /auth/*
router.Mount(r, auth)

// Protect routes
r.Group(func(r chi.Router) {
    r.Use(auth.AuthMiddleware())
    r.Get("/dashboard", dashboardHandler)
})
```

## Echo

To use Aegis with [Echo](https://echo.labstack.com/), you simply wrap the standard middleware.

```go
import (
    "github.com/labstack/echo/v4"
    "github.com/theinventorylib/aegis"
)

e := echo.New()

// Mount routes (Echo's WrapHandler converts http.Handler)
// Note: router.Mount expects a chi.Router interface, so for Echo 
// you might need to mount handlers manually or use an adapter.
// Easiest way:
authHandler := auth.Handler() // Returns http.Handler
e.Any("/auth/*", echo.WrapHandler(http.StripPrefix("/auth", authHandler)))

// Middleware
e.GET("/dashboard", dashboardHandler, echo.WrapMiddleware(auth.AuthMiddleware()))
```

## Fiber

[Fiber](https://gofiber.io/) uses a custom (FastHTTP) context, so you need an adapter like `gofiber/adaptor`.

```go
import (
    "github.com/gofiber/fiber/v2"
    "github.com/gofiber/adaptor/v2"
)

app := fiber.New()

// Middleware
app.Use("/dashboard", adaptor.HTTPMiddleware(auth.AuthMiddleware()))

// Routes
// It's recommended to run Aegis on a separate standard http port or use the adaptor
// for all auth endpoints, though complex.
```

> [!NOTE]
> Detailed Fiber support is planned for future releases via dedicated plugins.

## Gin

[Gin](https://github.com/gin-gonic/gin) is compatible via adapters.

```go
import (
    "github.com/gin-gonic/gin"
)

r := gin.Default()

// Middleware Adapter
func AuthRequired(auth *aegis.Aegis) gin.HandlerFunc {
    return func(c *gin.Context) {
        // Run standard middleware
        auth.AuthMiddleware()(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
            c.Request = r
            c.Next()
        })).ServeHTTP(c.Writer, c.Request)
    }
}

r.Use(AuthRequired(auth))
```

## Standard net/http

Aegis is native to `net/http`.

```go
mux := http.NewServeMux()

// Middleware
protectedHandler := auth.AuthMiddleware()(myHandler)
mux.Handle("/dashboard", protectedHandler)
```
