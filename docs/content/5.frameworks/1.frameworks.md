---
title: Framework Integration
description: Integrate Aegis with Chi, Echo, Fiber, Gin, and standard net/http.
---

Aegis is built on standard `net/http` interfaces, making it compatible with almost any Go web framework.

## Chi (Official Support)

Aegis provides first-class support for `go-chi`, as it is built on `net/http` standards.

```go
import (
    "github.com/go-chi/chi/v5"
    "github.com/theinventorylib/aegis"
    "github.com/theinventorylib/aegis/config"
    "github.com/theinventorylib/aegis/router"
)

mux := chi.NewRouter()
r := router.NewChiRouter(mux)

cfg := config.Default().
    WithDB(db).
    WithRouter(r).
    WithSecret([]byte("your-secret-key-must-be-32-chars!"))

a, err := aegis.New(ctx, cfg)
if err != nil {
    log.Fatal(err)
}

// Mount all auth routes at /auth/* (core routes at /auth/default/*)
a.MountRoutes("/auth")

// Apply auth middleware globally
mux.Use(a.AuthMiddleware())

// Protect routes
mux.Group(func(r chi.Router) {
    r.Use(a.RequireAuth())
    r.Get("/dashboard", dashboardHandler)
})
```

## Echo

To use Aegis with [Echo](https://echo.labstack.com/), wrap the standard middleware:

```go
import (
    "github.com/labstack/echo/v4"
    "github.com/theinventorylib/aegis"
)

e := echo.New()

// Aegis is built on chi internally, so for Echo you use the
// auth middleware wrapper and mount a chi sub-router for auth routes.
// Middleware
e.GET("/dashboard", dashboardHandler, echo.WrapMiddleware(a.AuthMiddleware()))
```

> [!NOTE]
> Aegis is designed around chi and `net/http`. For Echo, you can wrap the auth
> middleware, but auth routes should be served via the chi router that Aegis manages.

## Fiber

[Fiber](https://gofiber.io/) uses a custom (FastHTTP) context, so you need an adapter like `gofiber/adaptor`.

```go
import (
    "github.com/gofiber/fiber/v2"
    "github.com/gofiber/adaptor/v2"
)

app := fiber.New()

// Middleware
app.Use("/dashboard", adaptor.HTTPMiddleware(a.AuthMiddleware()))

// Routes
// It's recommended to run Aegis on a separate standard http port or use the adaptor
// for all auth endpoints, though complex.
```

> [!NOTE]
> Detailed Fiber support is planned for future releases via dedicated plugins.

## Gin

[Gin](https://github.com/gin-gonic/gin) is compatible via adapters.

```go
import (
    "github.com/gin-gonic/gin"
)

r := gin.Default()

// Middleware Adapter
func AuthRequired(a *aegis.Aegis) gin.HandlerFunc {
    return func(c *gin.Context) {
        // Run standard middleware
        a.AuthMiddleware()(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
            c.Request = r
            c.Next()
        })).ServeHTTP(c.Writer, c.Request)
    }
}

r.Use(AuthRequired(a))
```

## Standard net/http

Aegis is native to `net/http`.

```go
mux := http.NewServeMux()

// Middleware
protectedHandler := a.AuthMiddleware()(myHandler)
mux.Handle("/dashboard", protectedHandler)
```
