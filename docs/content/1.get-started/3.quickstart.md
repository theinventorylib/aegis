## Quick Start Guide

This guide will help you set up a basic authentication system with Aegis in just a few minutes.

## Prerequisites

- Go 1.21 or higher
- A PostgreSQL, MySQL, or SQLite database
- Basic knowledge of Go and HTTP servers

## Step 1: Install Aegis

```bash [Terminal]
go get github.com/theinventorylib/aegis
```

## Step 2: Set Up Database

Create a new database and export the migrations:

```bash [Terminal]
# Install the CLI
go install github.com/theinventorylib/aegis/cmd/aegis@latest

# Export migrations for PostgreSQL
aegis migrate export \
  --driver postgres \
  --format sql \
  --out ./migrations
```

Apply the migrations using your preferred tool:

```bash [Terminal]
# Using psql
psql -U youruser -d yourdb -f migrations/001_initial.up.sql

# Or using golang-migrate
migrate -path ./migrations -database "postgres://localhost/yourdb" up
```

## Step 3: Create Your App

Create a new file `main.go`:

```go [main.go]
package main

import (
    "context"
    "database/sql"
    "log"
    "net/http"
    
    "github.com/go-chi/chi/v5"
    _ "github.com/lib/pq"
    "github.com/theinventorylib/aegis"
    "github.com/theinventorylib/aegis/config"
    "github.com/theinventorylib/aegis/core"
    "github.com/theinventorylib/aegis/router"
)

func main() {
    // Connect to database
    db, err := sql.Open("postgres", 
        "postgres://user:password@localhost/aegis_demo?sslmode=disable")
    if err != nil {
        log.Fatal(err)
    }
    defer db.Close()
    
    // Initialize Aegis
    auth, err := aegis.New(context.Background(), &config.Config{
        DB:      db,
        Secret:  "your-secret-key-must-be-32-chars-or-longer",
        BaseURL: "http://localhost:8080",
    })
    if err != nil {
        log.Fatal(err)
    }
    
    // Create router
    r := chi.NewRouter()
    
    // Mount auth routes
    router.Mount(r, auth)
    
    // Protected route example
    r.Group(func(r chi.Router) {
        r.Use(auth.AuthMiddleware())
        r.Get("/api/profile", func(w http.ResponseWriter, r *http.Request) {
            user := core.GetUser(r.Context())
            w.Write([]byte("Hello " + user.Email))
        })
    })
    
    // Start server
    log.Println("Server starting on :8080")
    http.ListenAndServe(":8080", r)
}
```

## Step 4: Run Your App

```bash [Terminal]
go run main.go
```

## Step 5: Test Authentication

### Sign Up

```bash [Terminal]
curl -X POST http://localhost:8080/auth/signup \
  -H "Content-Type: application/json" \
  -d '{
    "email": "user@example.com",
    "password": "SecurePassword123!"
  }'
```

### Sign In

```bash [Terminal]
curl -X POST http://localhost:8080/auth/signin \
  -H "Content-Type: application/json" \
  -d '{
    "email": "user@example.com",
    "password": "SecurePassword123!"
  }' \
  -c cookies.txt
```

### Access Protected Route

```bash [Terminal]
curl http://localhost:8080/api/profile \
  -b cookies.txt
```

## Common Issues

### Database Connection Errors

Make sure your database is running and the connection string is correct:

```bash [Terminal]
# Test PostgreSQL connection
psql -U youruser -d yourdb -c "SELECT 1"
```

### Migration Errors

Ensure migrations are applied in order and the database user has proper permissions:

```sql
-- Grant permissions in PostgreSQL
GRANT ALL PRIVILEGES ON DATABASE yourdb TO youruser;
GRANT ALL PRIVILEGES ON ALL TABLES IN SCHEMA public TO youruser;
```

### Secret Key Too Short

The secret key must be at least 32 characters. Generate a secure key:

```bash [Terminal]
openssl rand -base64 32
```
