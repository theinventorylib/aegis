## Install Aegis

::steps
### Add Aegis to your Go project

Use `go get` to install the Aegis core library:

```bash [Terminal]
go get github.com/theinventorylib/aegis/v2
```

### Install the CLI tool

The Aegis CLI tool helps you export migrations for the core and plugins. Install it globally:

```bash [Terminal]
go install github.com/theinventorylib/aegis/v2/cmd/aegis@latest
```

### Initialize Aegis

In your main application file (e.g., `main.go`), initialize the Aegis instance with your configuration.

```go [main.go]
import (
    "context"
    "database/sql"
    "log"

    "github.com/go-chi/chi/v5"
    "github.com/theinventorylib/aegis/v2"
    "github.com/theinventorylib/aegis/v2/config"
    "github.com/theinventorylib/aegis/v2/router/routers"
)

func main() {
    ctx := context.Background()
    db, _ := sql.Open("postgres", "postgres://localhost/myapp?sslmode=disable")
    r := chi.NewRouter()

    ar := routers.NewChiRouter(r) // Create a router instance for aegis
    cfg := config.Default().
        WithDB(db).
        WithRouter(ar).
        WithSecret([]byte("your-secret-key-must-be-32-chars!")).
        WithCookieSecure(true)

    a, err := aegis.New(ctx, cfg)
    if err != nil {
        log.Fatal(err)
    }

    // Mount auth routes and setup middleware
    a.MountRoutes("/auth")
}
```

## Database Setup

Aegis requires a few tables in your database. You can export the necessary migrations using the CLI tool:

```bash [Terminal]
# Export core auth schema only (no plugins)
aegis export --dialect postgres --output ./migrations

# Export core auth + all plugins
aegis export --dialect postgres --plugins all --output ./migrations

# Export core auth + specific plugins
aegis export --dialect postgres --plugins organizations,jwt --output ./migrations

# Export with a specific format (goose, golang-migrate)
aegis export --dialect postgres --format goose --plugins all --output ./migrations
```

Check the [Migrations](/get-started/migration) section for more details.
