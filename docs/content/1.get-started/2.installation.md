## Install Aegis

::steps
### Add Aegis to your Go project

Use `go get` to install the Aegis core library:

```bash [Terminal]
go get github.com/theinventorylib/aegis
```

### Install the CLI tool

The Aegis CLI tool helps you export migrations for the core and plugins. Install it globally:

```bash [Terminal]
go install github.com/theinventorylib/aegis/cmd/aegis@latest
```

### Initialize Aegis

In your main application file (e.g., `main.go`), initialize the Aegis instance with your configuration.

```go [main.go]
import (
    "context"
    "github.com/theinventorylib/aegis"
    "github.com/theinventorylib/aegis/config"
    "github.com/theinventorylib/aegis/router"
)

func main() {
    ...
    ar := router.NewChiRouter(r) // Create a router instance for aegis
    cfg := config.Default().
        WithDB(db). // should be *sql.DB
        WithRouter(ar).
        WithSecret([]byte("your-secret-key-must-be-32-chars!")).
        WithCookieSecure(true)


    a, err := aegis.New(context.Background(), cfg)
    if err != nil {
        log.Fatal(err)
    }
    
    // Mount auth routes and setup middleware
    a.MountRoutes("/auth")
    ...
}
```
::

## Database Setup

Aegis requires a few tables in your database. You can export the necessary migrations using the CLI tool:

```bash [Terminal]
# Export migrations for SQLite using golang-migrate format
aegis export --dialect postgres --format goose --output ./migrations
```

Check the [Migrations](/get-started/migration) section for more details.
