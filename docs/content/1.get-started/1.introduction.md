Welcome to **Aegis**, a lightweight authentication framework for Go with a **modular plugin architecture** inspired by [better-auth](https://www.better-auth.com/).

## What is Aegis?

Aegis is designed to be a developer-friendly, flexible, and secure authentication solution. It provides a minimal core that handles the essentials of session management and password authentication, while allowing you to extend its functionality through a rich ecosystem of official plugins.

## Why Aegis?

- **Modular**: Only include the features you need. Want OAuth? Add the plugin. Need SMS OTP? There's a plugin for that.
- **Database Agnostic**: Supports PostgreSQL, MySQL, and SQLite out of the box.
- **Developer First**: No "magic" auto-migrations. You have full control over your database schema and migrations.
- **Modern Standards**: Uses Argon2id for password hashing and secure token-based sessions by default.

## Key Features

- **Minimal Core Schema**: Only 4 essential tables to get started.
- **Session Management**: Secure token-based sessions with refresh tokens and optional Redis caching.
- **CSRF Protection**: Built-in protection for web applications.
- **Password Authentication**: Robust Argon2id implementation built into the core.
- **Rich Plugin Ecosystem**: Official support for Email, SMS, OAuth, JWT, Bearer tokens, Admin, Organizations, and OpenAPI.
- **Migration CLI**: Easily export migrations for your specific plugin combination.
