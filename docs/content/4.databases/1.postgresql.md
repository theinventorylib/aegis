# PostgreSQL Setup

PostgreSQL is the recommended database for production Aegis deployments. It offers excellent performance, JSONB support for flexible schemas, and strong transactional integrity.

## Quick Start

```go
import (
    "database/sql"
    _ "github.com/lib/pq"
    
    "github.com/theinventorylib/aegis"
    "github.com/theinventorylib/aegis/config"
)

func main() {
    // Connect to PostgreSQL
    dsn := "postgres://user:password@localhost:5432/aegis?sslmode=disable"
    db, err := sql.Open("postgres", dsn)
    if err != nil {
        log.Fatal(err)
    }
    defer db.Close()
    
    // Verify connection
    if err := db.Ping(); err != nil {
        log.Fatal(err)
    }
    
    // Initialize Aegis
    cfg := config.Default().
        WithDB(db).
        WithRouter(router).
        WithSecret([]byte("your-secret-key"))
    
    a, err := aegis.New(context.Background(), cfg)
    if err != nil {
        log.Fatal(err)
    }
}
```

## Connection String Format

```
postgres://[user[:password]@][host][:port][/dbname][?param1=value1&...]
```

### Examples

**Local development:**
```go
dsn := "postgres://aegis:password@localhost:5432/aegis_dev?sslmode=disable"
```

**Production with SSL:**
```go
dsn := "postgres://aegis:secret@db.example.com:5432/aegis_prod?sslmode=require"
```

**Connection pooling:**
```go
dsn := "postgres://user:pass@localhost/dbname?" +
       "pool_max_conns=10&" +
       "pool_min_conns=2&" +
       "pool_max_conn_lifetime=1h"
```

**Unix socket:**
```go
dsn := "postgres:///dbname?host=/var/run/postgresql"
```

## SSL/TLS Configuration

### SSL Modes

| Mode | Description | Security |
|------|-------------|----------|
| `disable` | No SSL/TLS | ❌ Not secure |
| `allow` | SSL if available | ⚠️ Can downgrade |
| `prefer` | SSL preferred, fallback to plain | ⚠️ Can downgrade |
| `require` | SSL required, no certificate verification | ✅ Encrypted |
| `verify-ca` | SSL required, verify CA certificate | ✅✅ More secure |
| `verify-full` | SSL required, verify CA and hostname | ✅✅✅ Most secure |

### Production Example

```go
dsn := "postgres://user:pass@db.example.com:5432/dbname?" +
       "sslmode=verify-full&" +
       "sslrootcert=/path/to/ca-cert.pem&" +
       "sslcert=/path/to/client-cert.pem&" +
       "sslkey=/path/to/client-key.pem"
```

## Connection Pooling

Configure connection pool for optimal performance:

```go
db, err := sql.Open("postgres", dsn)
if err != nil {
    log.Fatal(err)
}

// Configure connection pool
db.SetMaxOpenConns(25)                 // Maximum connections
db.SetMaxIdleConns(5)                  // Idle connections
db.SetConnMaxLifetime(5 * time.Minute) // Connection lifetime
db.SetConnMaxIdleTime(10 * time.Minute)// Idle timeout
```

### Recommended Settings

| Environment | MaxOpenConns | MaxIdleConns | Notes |
|-------------|--------------|--------------|-------|
| Development | 10 | 2 | Low resource usage |
| Staging | 25 | 5 | Moderate load |
| Production | 50-100 | 10-20 | Based on server capacity |
| High Traffic | 100-200 | 25-50 | Monitor and adjust |

::callout{icon="i-heroicons-information-circle" color="blue"}
**Rule of thumb**: `MaxOpenConns = (Available Cores × 2) + Disk Spindles`

For cloud databases, check provider limits (e.g., AWS RDS has per-instance connection limits).
::

## Schema Migration

Aegis does not perform automatic migrations. Generate and apply migrations manually:

### 1. Generate SQL Schema

```bash
# Install CLI
go install github.com/theinventorylib/aegis/cmd/aegis@latest

# Export PostgreSQL schema
aegis migrate export --driver postgres --out ./migrations
```

This creates:
```
migrations/
  001_create_users.sql
  002_create_accounts.sql
  003_create_sessions.sql
  004_create_verification_requests.sql
```

### 2. Apply Migrations

#### Using golang-migrate

```bash
# Install migrate
brew install golang-migrate

# Apply migrations
migrate -path ./migrations -database "postgres://localhost/aegis_dev?sslmode=disable" up
```

#### Using goose

```bash
# Install goose
go install github.com/pressly/goose/v3/cmd/goose@latest

# Apply migrations
goose -dir ./migrations postgres "postgres://localhost/aegis_dev?sslmode=disable" up
```

#### Using SQL directly

```bash
psql -h localhost -U aegis -d aegis_dev -f migrations/001_create_users.sql
psql -h localhost -U aegis -d aegis_dev -f migrations/002_create_accounts.sql
psql -h localhost -U aegis -d aegis_dev -f migrations/003_create_sessions.sql
psql -h localhost -U aegis -d aegis_dev -f migrations/004_create_verification_requests.sql
```

## Core Schema

### Users Table

```sql
CREATE TABLE users (
    id TEXT PRIMARY KEY,
    name TEXT NOT NULL,
    email TEXT UNIQUE NOT NULL,
    email_verified BOOLEAN DEFAULT FALSE,
    phone TEXT,
    phone_verified BOOLEAN DEFAULT FALSE,
    metadata JSONB,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX idx_users_email ON users(email);
CREATE INDEX idx_users_phone ON users(phone) WHERE phone IS NOT NULL;
CREATE INDEX idx_users_metadata ON users USING GIN(metadata);
```

### Sessions Table

```sql
CREATE TABLE sessions (
    id TEXT PRIMARY KEY,
    user_id TEXT NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    session_token TEXT UNIQUE NOT NULL,
    refresh_token TEXT UNIQUE NOT NULL,
    ip_address TEXT,
    user_agent TEXT,
    expires_at TIMESTAMP WITH TIME ZONE NOT NULL,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
    
    CONSTRAINT fk_user FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE
);

CREATE INDEX idx_sessions_user_id ON sessions(user_id);
CREATE INDEX idx_sessions_token ON sessions(session_token);
CREATE INDEX idx_sessions_expires ON sessions(expires_at);
```

### Accounts Table

```sql
CREATE TABLE accounts (
    id TEXT PRIMARY KEY,
    user_id TEXT NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    account_type TEXT NOT NULL,
    provider TEXT,
    provider_account_id TEXT,
    password_hash TEXT,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
    
    UNIQUE(provider, provider_account_id),
    CONSTRAINT fk_user FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE
);

CREATE INDEX idx_accounts_user_id ON accounts(user_id);
CREATE INDEX idx_accounts_provider ON accounts(provider, provider_account_id);
```

## Performance Optimization

### Indexes

Aegis schema includes optimized indexes:

- **Primary keys**: B-tree indexes (automatic)
- **Foreign keys**: Explicit indexes for JOINs
- **Email/Phone**: Partial indexes for verified users
- **JSONB**: GIN indexes for metadata queries
- **Expires**: Index for session cleanup queries

### EXPLAIN ANALYZE

Monitor query performance:

```sql
EXPLAIN ANALYZE
SELECT * FROM sessions 
WHERE user_id = 'usr_123' 
  AND expires_at > NOW();
```

### Vacuum and Analyze

Regular maintenance:

```sql
-- Manual vacuum
VACUUM ANALYZE users;
VACUUM ANALYZE sessions;

-- Check last vacuum
SELECT relname, last_vacuum, last_autovacuum 
FROM pg_stat_user_tables 
WHERE schemaname = 'public';
```

### Connection Statistics

```sql
-- Active connections
SELECT count(*) FROM pg_stat_activity 
WHERE datname = 'aegis_prod';

-- Long-running queries
SELECT pid, now() - query_start as duration, query
FROM pg_stat_activity
WHERE state = 'active'
ORDER BY duration DESC;
```

## Docker Setup

### Docker Compose

```yaml
version: '3.8'

services:
  postgres:
    image: postgres:16-alpine
    environment:
      POSTGRES_DB: aegis_dev
      POSTGRES_USER: aegis
      POSTGRES_PASSWORD: password
    ports:
      - "5432:5432"
    volumes:
      - postgres_data:/var/lib/postgresql/data
      - ./migrations:/docker-entrypoint-initdb.d
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U aegis"]
      interval: 10s
      timeout: 5s
      retries: 5

volumes:
  postgres_data:
```

### Start Container

```bash
docker-compose up -d

# Check logs
docker-compose logs -f postgres

# Connect to psql
docker-compose exec postgres psql -U aegis -d aegis_dev
```

## Troubleshooting

### "Connection refused"

- Check PostgreSQL is running: `pg_isready`
- Verify port: `sudo netstat -tlnp | grep 5432`
- Check `pg_hba.conf` for client authentication
- Ensure firewall allows connection

### "Too many connections"

- Check current connections: `SELECT count(*) FROM pg_stat_activity`
- Reduce `MaxOpenConns` in your application
- Increase `max_connections` in `postgresql.conf`
- Use connection pooler (PgBouncer)

### "SSL required"

- Add `sslmode=require` to DSN
- For development: `sslmode=disable`
- Production: Use `verify-full` with certificates

### Slow queries

- Run `EXPLAIN ANALYZE` on slow queries
- Check missing indexes
- Update statistics: `ANALYZE table_name`
- Monitor with `pg_stat_statements`

### Migration errors

- Check PostgreSQL version compatibility (Aegis requires 12+)
- Verify schema doesn't already exist
- Check user permissions: `GRANT ALL ON DATABASE aegis TO aegis;`

## Best Practices

1. **Use connection pooling** - Set appropriate `MaxOpenConns` and `MaxIdleConns`
2. **Enable SSL in production** - Use `sslmode=verify-full`
3. **Regular backups** - Use `pg_dump` or cloud provider snapshots
4. **Monitor performance** - Use `pg_stat_statements` extension
5. **Keep PostgreSQL updated** - Apply security patches regularly
6. **Use prepared statements** - sqlc generates prepared statements automatically
7. **Index foreign keys** - Aegis schema includes these by default
8. **Vacuum regularly** - Enable autovacuum or schedule manual vacuums
