MySQL and MariaDB are widely used relational databases with excellent performance and broad hosting support. Aegis fully supports both with identical configuration.

## Quick Start

```go
import (
    "database/sql"
    _ "github.com/go-sql-driver/mysql"
    
    "github.com/theinventorylib/aegis"
    "github.com/theinventorylib/aegis/config"
)

func main() {
    // Connect to MySQL
    // IMPORTANT: parseTime=true is required!
    dsn := "user:password@tcp(localhost:3306)/aegis?parseTime=true"
    db, err := sql.Open("mysql", dsn)
    if err != nil {
        log.Fatal(err)
    }
    defer db.Close()
    
    // Verify connection
    if err := db.Ping(); err != nil {
        log.Fatal(err)
    }
    
    // Initialize Aegis
    cfg := config.Default().
        WithDB(db).
        WithRouter(router).
        WithSecret([]byte("your-secret-key"))
    
    auth := aegis.New(context.Background(), cfg)
}
```

::callout{icon="i-heroicons-exclamation-triangle" color="amber"}
**Critical**: You **MUST** include `parseTime=true` in your DSN string, otherwise Aegis cannot correctly parse timestamps from the database.
::

## Driver

Aegis uses the official Go MySQL driver:

```bash
go get github.com/go-sql-driver/mysql
```

```go
import _ "github.com/go-sql-driver/mysql"

dsn := "user:password@tcp(host:port)/database?parseTime=true"
db, err := sql.Open("mysql", dsn)
```

## Connection String Format

```
[username[:password]@][protocol[(address)]]/dbname[?param1=value1&...]
```

### Examples

**Local development:**
```go
dsn := "aegis:password@tcp(localhost:3306)/aegis_dev?parseTime=true"
```

**Production with charset:**
```go
dsn := "aegis:secret@tcp(db.example.com:3306)/aegis_prod?" +
       "parseTime=true&" +
       "charset=utf8mb4&" +
       "collation=utf8mb4_unicode_ci"
```

**Unix socket:**
```go
dsn := "user:password@unix(/var/run/mysqld/mysqld.sock)/dbname?parseTime=true"
```

**Multiple parameters:**
```go
dsn := "user:pass@tcp(localhost:3306)/dbname?" +
       "parseTime=true&" +
       "charset=utf8mb4&" +
       "loc=Local&" +
       "timeout=10s&" +
       "readTimeout=30s&" +
       "writeTimeout=30s"
```

## Required Parameters

### parseTime=true (Required)

Automatically parse `DATE` and `DATETIME` values to `time.Time`:

```go
// ❌ Without parseTime=true - returns []byte
dsn := "user:pass@tcp(localhost:3306)/dbname"

// ✅ With parseTime=true - returns time.Time
dsn := "user:pass@tcp(localhost:3306)/dbname?parseTime=true"
```

### charset=utf8mb4 (Recommended)

Use UTF-8 4-byte encoding to support emojis and special characters:

```go
dsn := "user:pass@tcp(localhost:3306)/dbname?" +
       "parseTime=true&" +
       "charset=utf8mb4&" +
       "collation=utf8mb4_unicode_ci"
```

## TLS/SSL Configuration

### Enable TLS

```go
import (
    "crypto/tls"
    "crypto/x509"
    "github.com/go-sql-driver/mysql"
)

// Register custom TLS config
rootCertPool := x509.NewCertPool()
pem, _ := os.ReadFile("/path/to/ca-cert.pem")
rootCertPool.AppendCertsFromPEM(pem)

mysql.RegisterTLSConfig("custom", &tls.Config{
    RootCAs: rootCertPool,
})

// Use in DSN
dsn := "user:pass@tcp(host:3306)/dbname?tls=custom&parseTime=true"
```

### Built-in TLS Modes

```go
// Skip verification (not recommended)
dsn := "user:pass@tcp(host:3306)/db?tls=skip-verify&parseTime=true"

// Preferred (use TLS if available)
dsn := "user:pass@tcp(host:3306)/db?tls=preferred&parseTime=true"

// Required (fail if TLS not available)
dsn := "user:pass@tcp(host:3306)/db?tls=true&parseTime=true"
```

## Connection Pooling

```go
db, err := sql.Open("mysql", dsn)
if err != nil {
    log.Fatal(err)
}

// Configure connection pool
db.SetMaxOpenConns(25)                 // Maximum connections
db.SetMaxIdleConns(5)                  // Idle connections
db.SetConnMaxLifetime(5 * time.Minute) // Connection lifetime
```

### Recommended Settings

| Environment | MaxOpenConns | MaxIdleConns | Notes |
|-------------|--------------|--------------|-------|
| Development | 10 | 2 | Low resource usage |
| Staging | 25 | 5 | Moderate load |
| Production | 50-100 | 10-20 | Based on server capacity |

::callout{icon="i-heroicons-information-circle" color="blue"}
MySQL default `max_connections` is 151. Check your server limit:
```sql
SHOW VARIABLES LIKE 'max_connections';
```
::

## Schema Migration

### 1. Generate SQL Schema

```bash
# Install CLI
go install github.com/theinventorylib/aegis/cmd/aegis@latest

# Export MySQL schema
aegis export --dialect mysql --output ./migrations
```

### 2. Apply Migrations

#### Using golang-migrate

```bash
migrate -path ./migrations -database "mysql://user:pass@tcp(localhost:3306)/aegis_dev" up
```

#### Using goose

```bash
goose -dir ./migrations mysql "user:pass@tcp(localhost:3306)/aegis_dev?parseTime=true" up
```

#### Using mysql client

```bash
mysql -u aegis -p aegis_dev < migrations/001_create_users.sql
mysql -u aegis -p aegis_dev < migrations/002_create_accounts.sql
mysql -u aegis -p aegis_dev < migrations/003_create_sessions.sql
mysql -u aegis -p aegis_dev < migrations/004_create_verification_requests.sql
```

## Core Schema

### Users Table

```sql
CREATE TABLE users (
    id VARCHAR(255) PRIMARY KEY,
    name VARCHAR(255) NOT NULL,
    email VARCHAR(255) UNIQUE NOT NULL,
    email_verified BOOLEAN DEFAULT FALSE,
    phone VARCHAR(50),
    phone_verified BOOLEAN DEFAULT FALSE,
    metadata JSON,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    INDEX idx_users_email (email),
    INDEX idx_users_phone (phone)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
```

### Sessions Table

```sql
CREATE TABLE sessions (
    id VARCHAR(255) PRIMARY KEY,
    user_id VARCHAR(255) NOT NULL,
    session_token VARCHAR(255) UNIQUE NOT NULL,
    refresh_token VARCHAR(255) UNIQUE NOT NULL,
    ip_address VARCHAR(45),
    user_agent TEXT,
    expires_at TIMESTAMP NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    
    INDEX idx_sessions_user_id (user_id),
    INDEX idx_sessions_token (session_token),
    INDEX idx_sessions_expires (expires_at),
    
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
```

### Accounts Table

```sql
CREATE TABLE accounts (
    id VARCHAR(255) PRIMARY KEY,
    user_id VARCHAR(255) NOT NULL,
    account_type VARCHAR(50) NOT NULL,
    provider VARCHAR(100),
    provider_account_id VARCHAR(255),
    password_hash TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    INDEX idx_accounts_user_id (user_id),
    INDEX idx_accounts_provider (provider, provider_account_id),
    UNIQUE KEY unique_provider_account (provider, provider_account_id),
    
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
```

## MySQL vs MariaDB

Both databases work identically with Aegis. Minor differences:

| Feature | MySQL | MariaDB |
|---------|-------|---------|
| **Driver** | Same (`go-sql-driver/mysql`) | Same |
| **JSON** | Native JSON type | JSON is an alias for LONGTEXT |
| **Licensing** | GPL + Commercial | GPL (open source) |
| **Performance** | Excellent | Excellent (often faster) |
| **Compatibility** | Industry standard | MySQL compatible |

## Performance Optimization

### InnoDB Configuration

Edit `my.cnf` or `my.ini`:

```ini
[mysqld]
# Buffer pool (70-80% of available RAM for dedicated server)
innodb_buffer_pool_size = 2G

# Log file size (larger = better write performance)
innodb_log_file_size = 512M

# Flush method (reduce I/O overhead)
innodb_flush_method = O_DIRECT

# Thread concurrency
innodb_thread_concurrency = 0  # Auto

# Connection limit
max_connections = 200
```

### Query Performance

```sql
-- Show slow queries
SHOW VARIABLES LIKE 'slow_query%';

-- Enable slow query log
SET GLOBAL slow_query_log = 'ON';
SET GLOBAL long_query_time = 2; -- Seconds

-- Analyze query
EXPLAIN SELECT * FROM sessions WHERE user_id = 'usr_123';
```

### Index Statistics

```sql
-- Show index usage
SELECT TABLE_NAME, INDEX_NAME, SEQ_IN_INDEX, COLUMN_NAME
FROM information_schema.STATISTICS
WHERE TABLE_SCHEMA = 'aegis_dev';

-- Analyze tables
ANALYZE TABLE users, sessions, accounts;
```

## Docker Setup

### Docker Compose

```yaml
version: '3.8'

services:
  mysql:
    image: mysql:8.0
    environment:
      MYSQL_ROOT_PASSWORD: rootpass
      MYSQL_DATABASE: aegis_dev
      MYSQL_USER: aegis
      MYSQL_PASSWORD: password
    ports:
      - "3306:3306"
    volumes:
      - mysql_data:/var/lib/mysql
      - ./migrations:/docker-entrypoint-initdb.d
    command:
      - --character-set-server=utf8mb4
      - --collation-server=utf8mb4_unicode_ci
      - --default-authentication-plugin=mysql_native_password
    healthcheck:
      test: ["CMD", "mysqladmin", "ping", "-h", "localhost"]
      interval: 10s
      timeout: 5s
      retries: 5

volumes:
  mysql_data:
```

## Troubleshooting

### "parseTime parameter is not set"

Add `parseTime=true` to your DSN:
```go
dsn := "user:pass@tcp(localhost:3306)/db?parseTime=true"
```

### "too many connections"

- Check active connections: `SHOW PROCESSLIST;`
- Reduce `MaxOpenConns` in application
- Increase MySQL `max_connections` in config
- Use connection pooler (ProxySQL)

### "access denied"

- Verify username and password
- Check user permissions:
  ```sql
  GRANT ALL PRIVILEGES ON aegis.* TO 'aegis'@'%';
  FLUSH PRIVILEGES;
  ```

### "unknown collation: utf8mb4_unicode_ci"

- Ensure MySQL/MariaDB version 5.7+ (8.0+ recommended)
- Check available collations: `SHOW COLLATION LIKE 'utf8mb4%';`

### Charset issues with emojis

- Use `utf8mb4` instead of `utf8`:
  ```sql
  ALTER DATABASE aegis CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
  ```

## Best Practices

1. **Always use `parseTime=true`** - Required for time.Time handling
2. **Use utf8mb4 charset** - Supports emojis and all Unicode
3. **Enable TLS in production** - Encrypt data in transit
4. **Set connection limits** - Prevent resource exhaustion
5. **Use InnoDB engine** - Better concurrency and crash recovery
6. **Regular backups** - Use `mysqldump` or cloud snapshots
7. **Monitor slow queries** - Enable slow query log
8. **Keep MySQL updated** - Apply security patches
