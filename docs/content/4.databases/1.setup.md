# Database Setup

Aegis is database-agnostic and supports PostgreSQL, MySQL, and SQLite. It uses standard `database/sql` interfaces, so you can use any driver you prefer.

## PostgreSQL (Recommended)

PostgreSQL is the recommended database for production Aegis deployments due to its JSONB support and transactional integrity.

### Driver
We recommend `github.com/lib/pq` or `github.com/jackc/pgx`.

### Connection

```go
import (
    "database/sql"
    _ "github.com/lib/pq"
)

func main() {
    dsn := "postgres://user:pass@localhost:5432/dbname?sslmode=disable"
    db, err := sql.Open("postgres", dsn)
    if err != nil {
        log.Fatal(err)
    }
    
    // Pass 'db' to aegis.New(...)
}
```

## MySQL / MariaDB

### Driver
We recommend `github.com/go-sql-driver/mysql`.

### Connection

```go
import (
    "database/sql"
    _ "github.com/go-sql-driver/mysql"
)

func main() {
    // Enable parseTime=true for correct timestamp handling
    dsn := "user:pass@tcp(127.0.0.1:3306)/dbname?parseTime=true"
    db, err := sql.Open("mysql", dsn)
    
    // Pass 'db' to aegis.New(...)
}
```

> [!WARNING]
> You **MUST** include `parseTime=true` in your DSN string, otherwise Aegis cannot correctly parse timestamps from the database.

## SQLite

Great for development or small, single-server applications.

### Driver
We recommend `github.com/mattn/go-sqlite3` (requires CGO) or `modernc.org/sqlite` (pure Go).

### Connection

```go
import (
    "database/sql"
    _ "github.com/mattn/go-sqlite3"
)

func main() {
    db, err := sql.Open("sqlite3", "./aegis.db")
    
    // Pass 'db' to aegis.New(...)
}
```

## Schema Management

Aegis does NOT perform auto-migrations at runtime. This is a deliberate design choice to give you control.

To get the SQL schema for your database:

1.  **Install CLI**: `go install github.com/theinventorylib/aegis/cmd/aegis@latest`
2.  **Export**:
    ```bash
    # For Postgres
    aegis migrate export --driver postgres --out ./migrations
    
    # For MySQL
    aegis migrate export --driver mysql --out ./migrations
    ```
3.  **Apply**: Use any migration tool (golang-migrate, goose, etc.) to apply the generated SQL files.
