# Admin Plugin

The Admin plugin provides administrative endpoints for managing users, sessions, and system operations.

## Features

- **User Management**: List, search, update, and delete users
- **Session Management**: View and revoke active sessions
- **Account Operations**: Manage user accounts and authentication methods
- **Audit Logging**: Track all administrative actions
- **Role-Based Access**: Customizable role checking
- **Bulk Operations**: Perform actions on multiple users

## Installation

```bash
go get github.com/theinventorylib/aegis/plugins/admin
```

## Configuration

```go
import (
    "github.com/theinventorylib/aegis"
    "github.com/theinventorylib/aegis/plugins/admin"
)

// Configure Admin plugin with role checking
adminPlugin := admin.New(&admin.Config{
    RoleCheck: func(ctx context.Context, userID string) (bool, error) {
        // Your role checking logic
        user, err := userStore.GetByID(ctx, userID)
        if err != nil {
            return false, err
        }
        return user.Role == "admin", nil
    },
})

// Register with Aegis
auth.Use(ctx, adminPlugin)
```

## HTTP Endpoints

All admin endpoints require admin authentication via the `RoleCheck` function.

### List Users

Get a paginated list of all users.

```http
GET /admin/users?page=1&limit=20&search=john
Authorization: Bearer <admin_token>
```

**Query Parameters:**
- `page`: Page number (default: 1)
- `limit`: Results per page (default: 20, max: 100)
- `search`: Search by name or email
- `status`: Filter by status (active, disabled, banned)

**Response:**

### Update User

Update user information.

```http
PUT /admin/users/:id
Authorization: Bearer <admin_token>
Content-Type: application/json

{
  "name": "John Smith",
  "email": "john.smith@example.com",
  "disabled": false
}
```

### Delete User

Permanently delete a user and all associated data.

```http
DELETE /admin/users/:id
Authorization: Bearer <admin_token>
```

**Note**: This action is irreversible and will delete:
- User account
- All sessions
- All accounts (OAuth, password, etc.)
- Associated plugin data (if plugins support it)

### Revoke Session

Force logout a user by revoking their session.

```http
DELETE /admin/sessions/:id
Authorization: Bearer <admin_token>
```

### Bulk Revoke Sessions

Revoke all sessions for a specific user.

```http
DELETE /admin/users/:id/sessions
Authorization: Bearer <admin_token>
```

## Database Schema

The Admin plugin doesn't add new tables but provides interfaces to manage existing data with enhanced permissions and audit logging.

## Audit Logging

All admin actions are automatically logged:

```go
type AuditLog struct {
    ID        string
    AdminID   string    // Admin who performed the action
    Action    string    // e.g., "user.delete", "session.revoke"
    TargetID  string    // ID of affected resource
    Metadata  string    // JSON metadata
    IPAddress string
    CreatedAt time.Time
}
```

### Viewing Audit Logs

```http
GET /admin/audit-logs?page=1&limit=50&action=user.delete
Authorization: Bearer <admin_token>
```

## Role-Based Access Control

Implement custom role checking based on your application's needs:

```go
adminPlugin := admin.New(&admin.Config{
    RoleCheck: func(ctx context.Context, userID string) (bool, error) {
        // Check database for admin role
        var role string
        err := db.QueryRow(
            "SELECT role FROM user_roles WHERE user_id = $1",
            userID,
        ).Scan(&role)
        
        if err != nil {
            return false, err
        }
        
        return role == "admin" || role == "super_admin", nil
    },
})
```

## Security Considerations

- **Authentication Required**: All endpoints require valid admin authentication
- **Audit Logging**: All actions are logged with admin ID and timestamp
- **IP Tracking**: Admin actions include IP address for security monitoring
- **Rate Limiting**: Apply strict rate limits to admin endpoints
- **MFA Recommended**: Require multi-factor authentication for admin accounts
- **Session Timeout**: Use shorter session timeouts for admin users

## Best Practices

1. **Principle of Least Privilege**: Grant admin access only when necessary
2. **Regular Audits**: Review audit logs regularly for suspicious activity
3. **Separate Admin Accounts**: Use dedicated admin accounts, not personal accounts
4. **MFA Always**: Require multi-factor authentication for all admins
5. **Monitor Actions**: Set up alerts for critical admin actions
6. **Backup Before Bulk**: Always backup before bulk operations

## Frontend Integration

### React Admin Dashboard

```jsx
import { useEffect, useState } from 'react';

function UserManagement() {
  const [users, setUsers] = useState([]);
  
  useEffect(() => {
    fetch('/admin/users', {
      headers: {
        'Authorization': `Bearer ${adminToken}`
      }
    })
    .then(res => res.json())
    .then(data => setUsers(data.users));
  }, []);
  
  const deleteUser = async (userId) => {
    if (!confirm('Are you sure?')) return;
    
    await fetch(`/admin/users/${userId}`, {
      method: 'DELETE',
      headers: {
        'Authorization': `Bearer ${adminToken}`
      }
    });
    
    setUsers(users.filter(u => u.id !== userId));
  };
  
  return (
    <div>
      {users.map(user => (
        <UserRow 
          key={user.id} 
          user={user} 
          onDelete={deleteUser} 
        />
      ))}
    </div>
  );
}
```

## Example Integration

```go
package main

import (
    "context"
    "database/sql"
    
    "github.com/go-chi/chi/v5"
    "github.com/theinventorylib/aegis"
    "github.com/theinventorylib/aegis/plugins/admin"
)

func main() {
    ctx := context.Background()
    db, _ := sql.Open("postgres", "postgres://localhost/myapp")
    r := chi.NewRouter()
    
    // Configure Admin plugin
    adminPlugin := admin.New(&admin.Config{
        RoleCheck: func(ctx context.Context, userID string) (bool, error) {
            var role string
            err := db.QueryRow(
                "SELECT role FROM users WHERE id = $1",
                userID,
            ).Scan(&role)
            return role == "admin", err
        },
    })
    
    // Initialize Aegis
    auth := aegis.New(ctx, config.Default().WithDB(db).WithRouter(r))
    auth.Use(ctx, adminPlugin)
}
```
