---
title: SMS OTP
description: Phone number verification with SMS one-time passwords and phone+password authentication.
---

The SMS OTP plugin provides phone-based authentication using one-time passwords sent via SMS, along with phone+password authentication. It extends the user model with `phone_number` and `phone_verified` fields.

## Features

- **SMS Verification**: Send verification codes via SMS with configurable length and expiry
- **Phone+Password Authentication**: Register and login with phone number and password
- **User Enrichment**: Automatically adds `phoneNumber` and `phoneVerified` to authenticated user responses
- **Multi-Provider Support**: Works with Twilio, AWS SNS, and any custom SMS provider
- **Programmatic API**: Full Go API for server-side phone verification management

## Installation

```bash
go get github.com/theinventorylib/aegis/plugins/sms
```

## Configuration

```go
import (
    "context"
    "time"
    "github.com/theinventorylib/aegis"
    "github.com/theinventorylib/aegis/plugins"
    "github.com/theinventorylib/aegis/plugins/sms"
)

// Implement sms.Provider with your SMS service
type MyTwilioProvider struct{ /* ... */ }

func (p *MyTwilioProvider) SendOTP(to, code string) error {
    // Send SMS via Twilio, AWS SNS, Vonage, etc.
    return twilioClient.Send(to, "Your code: "+code)
}

smsPlugin := sms.New(
    &sms.Config{
        Provider:  &MyTwilioProvider{},
        OTPLength: 6,                  // default: 6
        OTPExpiry: 10 * time.Minute,   // default: 10 min
    },
    nil,                          // nil = use DefaultSMSStore
    plugins.DialectPostgres,      // or DialectMySQL / DialectSQLite
)

// Register with Aegis
a, _ := aegis.New(ctx, cfg)
a.Use(ctx, smsPlugin)
a.MountRoutes("/auth")
```

### Configuration Options

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `Provider` | `sms.Provider` | nil | SMS provider implementation (required for production) |
| `OTPLength` | `int` | 6 | Length of OTP codes |
| `OTPExpiry` | `time.Duration` | 10 min | OTP code expiration time |

### Provider Interface

```go
type Provider interface {
    // SendOTP sends the given OTP code to the recipient phone number (E.164 format).
    SendOTP(to, code string) error

    // VerifyOTP validates an OTP code for the given phone number.
    // Most implementations return (true, nil) and delegate actual validation to
    // the plugin's internal OTP store. Override this for provider-managed
    // verification (e.g., Twilio Verify, which manages codes server-side).
    VerifyOTP(to, code string) (bool, error)
}
```

Implement this interface for any SMS service — Twilio, AWS SNS, Vonage, MessageBird, Plivo, or a custom gateway. A `nil` provider disables sending (useful for testing when you want to read OTP codes directly from the database).

### Store Interface

The SMS plugin also accepts an optional `Store` that manages phone-specific user records in the database:

```go
type Store interface {
    CreateUser(ctx context.Context, user User) (*User, error)
    GetUserByID(ctx context.Context, id string) (*User, error)
    GetUserByPhone(ctx context.Context, phone string) (*User, error)
    UpdateUserPhone(ctx context.Context, userID, phone string, verified bool) error
}
```

Pass `nil` to `sms.New` to use the built-in `DefaultSMSStore`, which is automatically initialised from Aegis's configured database and dialect.

### Provider vs Store — Responsibilities

| Concern | Handled by |
|---------|-----------|
| Sending SMS messages | `Provider.SendOTP` |
| Provider-level code validation (optional) | `Provider.VerifyOTP` |
| Storing and expiring OTP codes | Core `VerificationService` (internal) |
| Phone user records in the database | `Store` |
| Phone number format validation | `ValidatePhoneNumber()` helper |

> [!NOTE]
> OTP codes are stored and validated by Aegis's internal `VerificationService`, not by the `Store`. The `Store` only manages the `phone_number` / `phone_verified` columns on user records. `Provider.VerifyOTP` exists for services like Twilio Verify that manage codes themselves — for most providers, return `(true, nil)` and let the plugin handle validation.

## Database Schema

The SMS plugin extends the `user` table with:

| Column | Type | Description |
|--------|------|-------------|
| `phone_number` | VARCHAR | User's phone number |
| `phone_verified` | BOOLEAN | Whether the phone has been verified |

OTP codes are stored in the core `verification` table.

## HTTP Endpoints

### Send OTP

Send a verification code via SMS. Requires authentication.

```http
POST /auth/sms/send
Authorization: Bearer <session-token>
Content-Type: application/json

{
  "phoneNumber": "+1234567890",
  "userId": "user_abc123",
  "purpose": "verification"
}
```

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `phoneNumber` | string | Yes | Phone number in E.164 format |
| `userId` | string | No | Target user ID (defaults to the authenticated user) |
| `purpose` | string | No | OTP purpose label (e.g. `"verification"`, `"mfa"`) |

**Response (200):**

```json
{
  "success": true,
  "message": "Verification code sent"
}
```

### Verify OTP

Verify an OTP code and mark the phone number as verified.

```http
POST /auth/sms/verify
Content-Type: application/json

{
  "phoneNumber": "+1234567890",
  "code": "123456"
}
```

**Response (200):**

```json
{
  "success": true,
  "message": "Phone verified"
}
```

### Login with Phone+Password

Authenticate with phone number and password.

```http
POST /auth/sms/login
Content-Type: application/json

{
  "phoneNumber": "+1234567890",
  "password": "SecurePassword123!"
}
```

**Response (200):**

```json
{
  "success": true,
  "data": {
    "user": {
      "id": "user_abc123",
      "phoneNumber": "+1234567890"
    }
  }
}
```

### Register with Phone+Password

Create a new account with phone number and password.

```http
POST /auth/sms/register
Content-Type: application/json

{
  "name": "John Doe",
  "phoneNumber": "+1234567890",
  "password": "SecurePassword123!"
}
```

**Response (201):**

```json
{
  "success": true,
  "data": {
    "user": {
      "id": "user_abc123",
      "name": "John Doe",
      "phoneNumber": "+1234567890"
    }
  }
}
```

## Programmatic API

All SMS OTP operations are available as Go methods on the plugin instance. Use these for phone verification, two-factor authentication, and passwordless login flows.

### Getting the Plugin Instance

```go
// Type-safe retrieval (recommended)
smsPlugin, ok := aegis.GetPluginTyped[*sms.Plugin](a, "sms")
if !ok {
    log.Fatal("SMS plugin not registered")
}

// Via GetPlugin with type assertion
plugin, ok := a.GetPlugin("sms")
if ok {
    smsPlugin := plugin.(*sms.Plugin)
}
```

### OTP Methods

#### SendOTP

Generate and send a one-time password code via SMS.

```go
func SendOTP(ctx context.Context, phoneNumber, purpose string) error
```

**Parameters:**
- `ctx` — Request context for cancellation and tracing
- `phoneNumber` — Recipient phone number in E.164 format (e.g., "+1234567890")
- `purpose` — OTP purpose label (e.g., `"verification"`, `"mfa"`)

**Returns:**
- `error` — SMS sending errors, database errors, or rate limit errors

**Behavior:**
- Generates a 6-digit numeric code
- Stores code in database with 10-minute expiration
- Sends SMS via configured provider (Twilio, AWS SNS, etc.)
- Previous unused codes for the same phone number are invalidated
- Code can only be used once (deleted upon successful verification)

**Example:**
```go
// Phone verification during signup
err := smsPlugin.SendOTP(ctx, "+1234567890", "verification")
if err != nil {
    return fmt.Errorf("failed to send verification code: %w", err)
}

// Two-factor authentication
err = smsPlugin.SendOTP(ctx, user.PhoneNumber, "mfa")
if err != nil {
    return fmt.Errorf("failed to send 2FA code: %w", err)
}
```

**SMS content:**
- "Your verification code is: 123456. Expires in 10 minutes."
- Customize via SMS provider templates

**Rate limiting recommendations:**
- Max 3 codes per phone per hour
- Max 5 codes per phone per day
- Exponential backoff between requests

#### VerifyOTP

Verify a one-time password code and mark phone as verified on success.

```go
func VerifyOTP(ctx context.Context, phoneNumber, code string) (bool, error)
```

**Parameters:**
- `ctx` — Request context
- `phoneNumber` — Phone number to verify code for (E.164 format)
- `code` — 6-digit OTP code from user

**Returns:**
- `bool` — `true` if code is valid and not expired
- `error` — Database errors (not returned for invalid/expired codes)

**Behavior:**
- Looks up code in database by phone number
- Checks code matches and hasn't expired (10-minute window)
- Deletes code from database upon successful validation (single-use)
- **Automatically marks phone as verified** in user table
- Returns `false` (not error) for invalid/expired codes

**Example:**
```go
valid, err := smsPlugin.VerifyOTP(ctx, "+1234567890", "123456")
if err != nil {
    return fmt.Errorf("verification error: %w", err)
}

if !valid {
    http.Error(w, "Invalid or expired code", http.StatusBadRequest)
    return
}

// Code valid — phone is now verified
log.Info("Phone verified successfully", "phone", "+1234567890")
```

**Security considerations:**
- Implement rate limiting (3-5 attempts max)
- Log failed verification attempts
- Consider account lockout after repeated failures
- Monitor for SMS pumping/fraud patterns

### User Methods

#### GetUserByPhone

Look up a user by their phone number.

```go
func GetUserByPhone(ctx context.Context, phoneNumber string) (*User, error)
```

**Parameters:**
- `ctx` — Request context
- `phoneNumber` — Phone number to search for (E.164 format)

**Returns:**
- `*User` — User object with ID, phone, name, timestamps
- `error` — `sql.ErrNoRows` if user not found, database errors

**Example:**
```go
user, err := smsPlugin.GetUserByPhone(ctx, "+1234567890")
if err == sql.ErrNoRows {
    // User doesn't exist — proceed with registration
    return nil, nil
}
if err != nil {
    return nil, fmt.Errorf("lookup error: %w", err)
}

fmt.Printf("Found user: %s (ID: %s)\n", user.PhoneNumber, user.ID)
```

**Use cases:**
- Pre-signup phone availability checks
- Passwordless login flows
- Account recovery by phone
- Phone-based user lookup

#### CreateUserWithPhoneAndPassword

Register a new user with phone number and password authentication.

```go
func CreateUserWithPhoneAndPassword(ctx context.Context, name, phoneNumber, password string) (*User, error)
```

**Parameters:**
- `ctx` — Request context
- `name` — User's display name
- `phoneNumber` — User's phone number in E.164 format (must be unique)
- `password` — Plain-text password (will be hashed with Argon2id)

**Returns:**
- `*User` — Created user object with generated ID
- `error` — Validation errors (duplicate phone, invalid format) or database errors

**Behavior:**
- Validates phone number format (E.164)
- Checks uniqueness of phone number
- Hashes password using Argon2id with OWASP parameters
- Creates user record with `phoneVerified = false` by default
- Generates secure random user ID
- Does NOT send verification SMS (call `SendOTP` separately)

**Example:**
```go
// Registration flow
user, err := smsPlugin.CreateUserWithPhoneAndPassword(
    ctx,
    "Jane Smith",
    "+1234567890",
    "SecurePassword123!",
)
if err != nil {
    if strings.Contains(err.Error(), "duplicate") {
        http.Error(w, "Phone number already registered", http.StatusConflict)
        return
    }
    return fmt.Errorf("registration failed: %w", err)
}

// Send verification SMS
err = smsPlugin.SendOTP(ctx, user.PhoneNumber)
if err != nil {
    log.Error("Failed to send verification SMS", "error", err)
}

log.Info("User registered", "user_id", user.ID, "phone", user.PhoneNumber)
```

**Phone number validation:**
- Must be E.164 format: +[country code][number]
- Example: +12025551234 (US), +442071838750 (UK)
- Use libphonenumber library for robust validation

### Phone Verification Methods

#### MarkPhoneVerified

Mark a user's phone as verified by phone number lookup.

```go
func MarkPhoneVerified(ctx context.Context, phoneNumber string) error
```

**Parameters:**
- `ctx` — Request context
- `phoneNumber` — Phone number to mark as verified (E.164 format)

**Returns:**
- `error` — Database errors or user not found

**Behavior:**
- Looks up user by phone number
- Sets `phoneVerified = true` in database
- Called automatically by `VerifyOTP()` on successful validation
- Idempotent (safe to call multiple times)

**Example:**
```go
// Manually verify a phone (admin action)
err := smsPlugin.MarkPhoneVerified(ctx, "+1234567890")
if err != nil {
    return fmt.Errorf("failed to mark phone verified: %w", err)
}

// After OAuth login with verified phone
if oauthPhoneVerified {
    smsPlugin.MarkPhoneVerified(ctx, oauthPhone)
}
```

**Use cases:**
- Admin verification bypass
- Testing environments
- Migration from legacy systems
- Pre-verified enterprise numbers

#### UpdateUserPhone

Update a user's phone number and verification status.

```go
func UpdateUserPhone(ctx context.Context, userID, newPhone string, verified bool) error
```

**Parameters:**
- `ctx` — Request context
- `userID` — User identifier
- `newPhone` — New phone number to set (E.164 format)
- `verified` — Whether the new phone should be marked as verified

**Returns:**
- `error` — Validation errors (duplicate phone, invalid format) or database errors

**Behavior:**
- Updates user's phone number
- Sets verification status as specified
- Validates E.164 format
- Fails if new phone conflicts with existing user
- Does NOT send verification SMS (call `SendOTP` separately if `verified = false`)

**Example:**
```go
// Phone change flow (require verification)
err := smsPlugin.UpdateUserPhone(ctx, "user_123", "+9876543210", false)
if err != nil {
    if strings.Contains(err.Error(), "duplicate") {
        return fmt.Errorf("phone number already in use")
    }
    return fmt.Errorf("failed to update phone: %w", err)
}

// Send verification to new phone
err = smsPlugin.SendOTP(ctx, "+9876543210")

// Admin phone change (pre-verified)
err = smsPlugin.UpdateUserPhone(ctx, "user_456", "+1234567890", true)
```

**Best practices:**
- Set `verified = false` for user-initiated changes
- Send OTP to new phone for verification
- Consider requiring password confirmation
- Log phone change events for security audit
- Verify phone ownership before updating

The plugin automatically enriches authenticated users with phone data:


## SMS Provider Integration

### Twilio

```go
import (
    "github.com/twilio/twilio-go"
    twilioApi "github.com/twilio/twilio-go/rest/api/v2010"
)

func sendViaTwilio(to, message string) error {
    client := twilio.NewRestClientWithParams(twilio.ClientParams{
        Username: os.Getenv("TWILIO_ACCOUNT_SID"),
        Password: os.Getenv("TWILIO_AUTH_TOKEN"),
    })

    params := &twilioApi.CreateMessageParams{}
    params.SetTo(to)
    params.SetFrom(os.Getenv("TWILIO_PHONE_NUMBER"))
    params.SetBody(message)

    _, err := client.Api.CreateMessage(params)
    return err
}
```

### AWS SNS

```go
import (
    "github.com/aws/aws-sdk-go/aws"
    "github.com/aws/aws-sdk-go/aws/session"
    "github.com/aws/aws-sdk-go/service/sns"
)

func sendViaSNS(to, message string) error {
    sess := session.Must(session.NewSession())
    svc := sns.New(sess)

    _, err := svc.Publish(&sns.PublishInput{
        Message:     aws.String(message),
        PhoneNumber: aws.String(to),
    })
    return err
}
```

## Security Considerations

- OTP codes expire after the configured time (default: 10 minutes)
- Rate limiting prevents SMS bombing attacks
- Phone numbers are validated before sending
- Codes are single-use and deleted upon verification
- Passwords are hashed using **Argon2id** (OWASP-compliant parameters)
- Consider implementing CAPTCHA for additional security on public endpoints
