---
title: Admin
description: Administrative endpoints for user management, role assignment, and ban management.
---


The Admin plugin provides role-based access control (RBAC) and administrative user management. It extends the core `auth.User` model with role, ban, and disable capabilities.

## Features

- **User Management**: List, get, disable, enable, and delete users
- **Role Management**: Assign and remove roles for users (e.g., "admin", "moderator")
- **Ban Management**: Ban and unban users with reasons and optional expiry dates
- **Platform Statistics**: Get user count and other analytics
- **User Enrichment**: Automatically adds `role` field to authenticated user responses
- **OpenAPI Integration**: All endpoints are documented in the OpenAPI spec

## Installation

```bash
go get github.com/theinventorylib/aegis/plugins/admin
```

## Configuration

```go
import (
    "context"
    "github.com/theinventorylib/aegis"
    "github.com/theinventorylib/aegis/config"
    "github.com/theinventorylib/aegis/plugins/admin"
    "github.com/theinventorylib/aegis/plugins"
)

// Create with default store (uses your existing DB connection)
adminPlugin := admin.New(nil, plugins.DialectPostgres)

// Or with a custom store implementation
adminPlugin := admin.New(myCustomStore, plugins.DialectPostgres)

// Register with Aegis
a, _ := aegis.New(ctx, cfg)
a.Use(ctx, adminPlugin)

// Mount routes (admin endpoints available at /auth/admin/*)
a.MountRoutes("/auth")
```

## Database Schema

The admin plugin extends the `user` table with additional columns:

| Column | Type | Description |
|--------|------|-------------|
| `role` | VARCHAR | User role (e.g., "admin", "moderator") |
| `banned` | BOOLEAN | Whether the user is currently banned |
| `ban_reason` | TEXT | Admin-provided reason for the ban |
| `ban_expiry` | TIMESTAMP | Ban expiration date (NULL = permanent) |
| `ban_counter` | INTEGER | Number of times the user has been banned |

## HTTP Endpoints

All admin endpoints require admin authentication via the `RequireAdminMiddleware`.

### List Users

Get a paginated list of all users.

```http
GET /auth/admin/users?page=1&limit=20
Authorization: Bearer <admin_token>
```

**Query Parameters:**

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `page` | int | 1 | Page number |
| `limit` | int | 20 | Results per page |

**Response (200):**

```json
{
  "success": true,
  "data": {
    "users": [
      {
        "id": "user_abc123",
        "email": "john@example.com",
        "name": "John Doe",
        "role": "admin",
        "disabled": false,
        "banned": false,
        "createdAt": "2024-01-15T10:30:00Z",
        "updatedAt": "2024-02-15T08:45:00Z"
      }
    ],
    "page": 1,
    "limit": 20
  }
}
```

### Get User Details

Retrieve detailed information about a specific user.

```http
GET /auth/admin/users/:id
Authorization: Bearer <admin_token>
```

**Response (200):**

```json
{
  "success": true,
  "data": {
    "id": "user_abc123",
    "email": "john@example.com",
    "name": "John Doe",
    "role": "admin",
    "disabled": false,
    "banned": false,
    "banReason": "",
    "banExpiry": null,
    "banCounter": 0,
    "createdAt": "2024-01-15T10:30:00Z",
    "updatedAt": "2024-02-15T08:45:00Z"
  }
}
```

### Ban User

Ban a user with a reason and optional expiry date.

```http
POST /auth/admin/users/:id/ban
Authorization: Bearer <admin_token>
Content-Type: application/json

{
  "reason": "Spam and abusive behavior",
  "expiresAt": "2025-12-31T23:59:59Z"
}
```

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `reason` | string | Yes | Reason for the ban |
| `expiresAt` | string (RFC3339) | No | Expiry date (omit for permanent ban) |

**Response (200):**

```json
{
  "success": true,
  "message": "User banned"
}
```

### Unban User

Remove a ban from a user account.

```http
POST /auth/admin/users/:id/unban
Authorization: Bearer <admin_token>
```

**Response (200):**

```json
{
```

**Response (200):**

```json

```

### Get Platform Statistics

## Programmatic API

All admin operations are available as Go methods on the plugin instance. Use these for server-side logic, background jobs, CLI tools, or custom handlers that need programmatic user management.

### Getting the Plugin Instance

```go
// Via GetPluginTyped (type-safe, recommended)
adminPlugin, ok := aegis.GetPluginTyped[*admin.Plugin](a, "admin")
if !ok {
    log.Fatal("Admin plugin not registered")
}

// Via GetPlugin (requires type assertion)
plugin, ok := a.GetPlugin("admin")
if ok {
    adminPlugin := plugin.(*admin.Plugin)
}
```

### User Management Methods

#### ListUsers

List all users with pagination support.

```go
func ListUsers(ctx context.Context, offset, limit int) ([]admin.User, error)
```

**Parameters:**
- `ctx` — Request context for cancellation and tracing
- `offset` — Number of users to skip (for pagination)
- `limit` — Maximum number of users to return

**Returns:**
- `[]admin.User` — Slice of user objects with admin-specific fields
- `error` — Database or validation errors

**Example:**
```go
// Get first 20 users
users, err := adminPlugin.ListUsers(ctx, 0, 20)
if err != nil {
    return fmt.Errorf("failed to list users: %w", err)
}

for _, user := range users {
    fmt.Printf("User: %s (%s) - Role: %s\n", user.Name, user.Email, user.Role)
}

// Get next 20 users
moreUsers, err := adminPlugin.ListUsers(ctx, 20, 20)
```

#### ListUsersRaw

List users as raw map data structures, useful for dynamic admin UIs or custom serialization.

```go
func ListUsersRaw(ctx context.Context, offset, limit int) ([]map[string]any, error)
```

**Parameters:**
- `ctx` — Request context
- `offset` — Pagination offset
- `limit` — Results limit

**Returns:**
- `[]map[string]any` — Users as flexible map structures
- `error` — Database errors

**Example:**
```go
users, err := adminPlugin.ListUsersRaw(ctx, 0, 50)
// Each user is map[string]any with all columns
```

**Use cases:**
- Admin dashboards with dynamic columns
- Custom JSON serialization
- GraphQL resolvers

#### GetUser

Retrieve detailed information about a specific user.

```go
func GetUser(ctx context.Context, userID string) (admin.User, error)
```

**Parameters:**
- `ctx` — Request context
- `userID` — The unique user identifier

**Returns:**
- `admin.User` — User object with admin fields (role, disabled, banned, etc.)
- `error` — `sql.ErrNoRows` if user not found, other DB errors

**Example:**
```go
user, err := adminPlugin.GetUser(ctx, "user_abc123")
if err == sql.ErrNoRows {
    return fmt.Errorf("user not found")
}
if err != nil {
    return fmt.Errorf("database error: %w", err)
}

fmt.Printf("User: %s\nRole: %s\nDisabled: %t\n", user.Email, user.Role, user.Disabled)
```

#### GetUserRaw

Get user data as a raw map structure.

```go
func GetUserRaw(ctx context.Context, userID string) (map[string]any, error)
```

**Parameters:**
- `ctx` — Request context
- `userID` — User identifier

**Returns:**
- `map[string]any` — User data as flexible map
- `error` — Database errors

**Use cases:**
- Dynamic admin UIs
- Custom serialization formats
- Third-party integrations

#### DisableUser

Disable a user account, preventing login without deleting data.

```go
func DisableUser(ctx context.Context, userID string) error
```

**Parameters:**
- `ctx` — Request context
- `userID` — User to disable

**Returns:**
- `error` — Database errors or user not found

**Behavior:**
- Sets `disabled = true` in the database
- User cannot log in (existing sessions remain valid until expiry)
- Account can be re-enabled with `EnableUser()`
- User data is preserved

**Example:**
```go
// Disable a problematic user
if err := adminPlugin.DisableUser(ctx, "user_spam123"); err != nil {
    return fmt.Errorf("failed to disable user: %w", err)
}
log.Info("User account disabled", "user_id", "user_spam123")
```

#### EnableUser

Re-enable a previously disabled user account.

```go
func EnableUser(ctx context.Context, userID string) error
```

**Parameters:**
- `ctx` — Request context
- `userID` — User to enable

**Returns:**
- `error` — Database errors

**Behavior:**
- Sets `disabled = false`
- User can log in again immediately

**Example:**
```go
// Re-enable after reviewing account
if err := adminPlugin.EnableUser(ctx, "user_abc123"); err != nil {
    return fmt.Errorf("failed to enable user: %w", err)
}
```

#### DeleteUser

Permanently delete a user and all associated data.

```go
func DeleteUser(ctx context.Context, userID string) error
```

**Parameters:**
- `ctx` — Request context
- `userID` — User to delete

**Returns:**
- `error` — Database errors

**Warning:**
- **Irreversible operation** — all user data is permanently deleted
- Cascading deletes remove sessions, verification requests, plugin data
- Consider using `DisableUser()` for reversible actions

**Example:**
```go
// GDPR deletion request
if err := adminPlugin.DeleteUser(ctx, "user_to_delete"); err != nil {
    return fmt.Errorf("failed to delete user: %w", err)
}
log.Warn("User permanently deleted", "user_id", "user_to_delete")
```

### Role Management Methods

#### AssignRole

Assign an administrative role to a user.

```go
func AssignRole(ctx context.Context, userID, role string) error
```

**Parameters:**
- `ctx` — Request context
- `userID` — User to assign role to
- `role` — Role name (e.g., "admin", "moderator", "support")

**Returns:**
- `error` — Database errors or validation failures

**Behavior:**
- Creates or updates role assignment in `admin.user_roles` table
- Role is automatically included in enriched user responses
- No role hierarchy enforcement (implement in your application)

**Example:**
```go
// Promote user to admin
if err := adminPlugin.AssignRole(ctx, "user_trusted", "admin"); err != nil {
    return fmt.Errorf("failed to assign admin role: %w", err)
}

// Assign custom role
if err := adminPlugin.AssignRole(ctx, "user_support", "support"); err != nil {
    return err
}
```

#### GetUserRole

Retrieve the current role assigned to a user.

```go
func GetUserRole(ctx context.Context, userID string) (string, error)
```

**Parameters:**
- `ctx` — Request context
- `userID` — User identifier

**Returns:**
- `string` — Role name (empty string if no role assigned)
- `error` — Database errors

**Example:**
```go
role, err := adminPlugin.GetUserRole(ctx, "user_abc123")
if err != nil {
    return fmt.Errorf("failed to get role: %w", err)
}

if role == "admin" {
    // Admin-specific logic
} else if role == "" {
    // No role assigned
}
```

#### RemoveRole

Remove a role assignment from a user.

```go
func RemoveRole(ctx context.Context, userID, role string) error
```

**Parameters:**
- `ctx` — Request context
- `userID` — User to remove role from
- `role` — Role name to remove

**Returns:**
- `error` — Database errors

**Behavior:**
- Deletes the role assignment record
- User reverts to default "user" role
- No-op if role wasn't assigned

**Example:**
```go
// Demote from admin
if err := adminPlugin.RemoveRole(ctx, "former_admin", "admin"); err != nil {
    return fmt.Errorf("failed to remove admin role: %w", err)
}
```

### Ban Management Methods

#### BanUser

Ban a user temporarily or permanently.

```go
func BanUser(ctx context.Context, userID, reason string, expiry *time.Time) error
```

**Parameters:**
- `ctx` — Request context
- `userID` — User to ban
- `reason` — Ban reason (for audit/display)
- `expiry` — Ban expiration time (`nil` for permanent ban)

**Returns:**
- `error` — Database errors

**Behavior:**
- Sets `banned = true`, records reason and expiry
- Increments ban counter
- Banned users cannot log in (existing sessions remain valid)
- Automatic unban if expiry time passes (checked on login)

**Example:**
```go
// Permanent ban
if err := adminPlugin.BanUser(ctx, "spammer", "Spam violations", nil); err != nil {
    return err
}

// Temporary 30-day ban
expiry := time.Now().Add(30 * 24 * time.Hour)
if err := adminPlugin.BanUser(ctx, "toxic_user", "Harassment", &expiry); err != nil {
    return err
}

// 7-day timeout
timeout := time.Now().Add(7 * 24 * time.Hour)
adminPlugin.BanUser(ctx, "rule_violator", "Community guidelines violation", &timeout)
```

#### UnbanUser

Remove a ban from a user account.

```go
func UnbanUser(ctx context.Context, userID string) error
```

**Parameters:**
- `ctx` — Request context
- `userID` — User to unban

**Returns:**
- `error` — Database errors

**Behavior:**
- Sets `banned = false`
- Clears ban reason and expiry
- User can log in immediately
- Ban counter remains for audit history

**Example:**
```go
// Appeal approved
if err := adminPlugin.UnbanUser(ctx, "user_appealed"); err != nil {
    return fmt.Errorf("failed to unban user: %w", err)
}
```

## User Enrichment

The admin plugin automatically enriches authenticated users with their role. After `AuthMiddleware` runs, the user response includes:

```json
{
  "id": "user_abc123",
  "email": "admin@example.com",
  "role": "admin"
}
```

Access the role in handlers:

```go
func myHandler(w http.ResponseWriter, r *http.Request) {
    enriched := core.GetEnrichedUser(r.Context())
    role := enriched.GetString("role")
    if role == "admin" {
        // Admin-specific logic
    }
}
```

## Middleware

### RequireAdminMiddleware

Blocks requests from non-admin users:

```go
requireAdmin := adminPlugin.RequireAdminMiddleware()

router.With(requireAdmin).Get("/my-admin-route", myAdminHandler)
```

## Route Summary

| Method | Path | Description |
|--------|------|-------------|
| GET | `/admin/users` | List all users (paginated) |
| GET | `/admin/users/:id` | Get user details |
| POST | `/admin/users/:id/disable` | Disable user account |
| POST | `/admin/users/:id/enable` | Enable user account |
| DELETE | `/admin/users/:id` | Delete user account |
| POST | `/admin/users/:id/ban` | Ban user with reason |
| POST | `/admin/users/:id/unban` | Unban user |
| PUT | `/admin/users/:id/role` | Update user role |
| GET | `/admin/stats` | Get platform statistics |

## Security Considerations

- **Admin-only access**: All endpoints require the `admin` role via `RequireAdminMiddleware`
- **Input sanitization**: All inputs are sanitized before processing
- **Ban tracking**: Ban counter tracks repeat offenders
- **Separate role update**: Role changes use dedicated `AssignRole`/`RemoveRole` — the general `Update` method deliberately excludes role

## Example Integration

```go
package main

import (
    "context"
    "database/sql"
    "net/http"

    "github.com/go-chi/chi/v5"
    "github.com/theinventorylib/aegis"
    "github.com/theinventorylib/aegis/config"
    "github.com/theinventorylib/aegis/core"
    "github.com/theinventorylib/aegis/plugins"
    "github.com/theinventorylib/aegis/plugins/admin"
)

func main() {
    ctx := context.Background()
    db, _ := sql.Open("postgres", "postgres://localhost/myapp?sslmode=disable")
    r := chi.NewRouter()

    cfg := config.Default().
        WithDB(db).
        WithRouter(r).
        WithSecret([]byte("your-32-byte-secret-key-here!!!!"))

    a, _ := aegis.New(ctx, cfg)

    // Register admin plugin
    adminPlugin := admin.New(nil, plugins.DialectPostgres)
    a.Use(ctx, adminPlugin)

    // Mount all routes
    a.MountRoutes("/auth")

    // Use auth middleware
    r.Use(a.AuthMiddleware())

    // Custom admin endpoint using programmatic API
    r.Group(func(r chi.Router) {
        r.Use(a.RequireAuth())
        r.Get("/api/admin/dashboard", func(w http.ResponseWriter, r *http.Request) {
            stats, _ := adminPlugin.GetStats(r.Context())
            users, _ := adminPlugin.ListUsers(r.Context(), 0, 5)

            core.WriteJSON(w, http.StatusOK, &core.Response{
                Success: true,
                Data: map[string]any{
                    "stats":       stats,
                    "recentUsers": users,
                },
            })
        })
    })

    http.ListenAndServe(":8080", r)
}
```
