# Organizations Plugin

The Organizations plugin enables multi-tenancy with organizations, teams, roles, and member management.

## Features

- **Organization Management**: Create and manage organizations (workspaces, tenants)
- **Team Support**: Organize members into teams within organizations
- **Role-Based Permissions**: Owner, Admin, and Member roles
- **Invitation System**: Invite users to join organizations
- **Organization Switching**: Users can belong to multiple organizations
- **Member Management**: Add, remove, and update member roles

## Installation

```bash
go get github.com/theinventorylib/aegis/plugins/organizations
```

## Configuration

```go
import (
    "github.com/theinventorylib/aegis"
    "github.com/theinventorylib/aegis/plugins/organizations"
)

// Configure Organizations plugin
orgsPlugin := organizations.New(&organizations.Config{
    MaxMembersPerOrg: 100,
    AllowFreeOrgs:    true,
})

// Register with Aegis (lower priority for early initialization)
auth.UseWithPriority(ctx, orgsPlugin, 10)
```

## Database Schema

```sql
-- Organization table
CREATE TABLE organization (
    id TEXT PRIMARY KEY,
    name TEXT NOT NULL,
    slug TEXT NOT NULL UNIQUE,
    disabled INTEGER NOT NULL DEFAULT 0,
    created_at TEXT NOT NULL,
    updated_at TEXT NOT NULL
);

-- Member (memberships)
CREATE TABLE members (
    id TEXT PRIMARY KEY,
    user_id TEXT NOT NULL REFERENCES "user"(id) ON DELETE CASCADE,
    organization_id TEXT NOT NULL REFERENCES organization(id) ON DELETE CASCADE,
    role TEXT NOT NULL,
    created_at TEXT NOT NULL,
    updated_at TEXT NOT NULL,
    UNIQUE(user_id, organization_id)
);

-- Team table
CREATE TABLE team (
    id TEXT PRIMARY KEY,
    organization_id TEXT NOT NULL REFERENCES organization(id) ON DELETE CASCADE,
    name TEXT NOT NULL,
    description TEXT,
    created_at TEXT NOT NULL,
    updated_at TEXT NOT NULL
);

-- Team Members
CREATE TABLE team_member (
    id TEXT PRIMARY KEY,
    team_id TEXT NOT NULL REFERENCES team(id) ON DELETE CASCADE,
    user_id TEXT NOT NULL REFERENCES "user"(id) ON DELETE CASCADE,
    role TEXT NOT NULL,
    created_at TEXT NOT NULL,
    updated_at TEXT NOT NULL,
    UNIQUE(team_id, user_id)
);
```

## HTTP Endpoints

### Create Organization

Create a new organization. The creator automatically becomes the owner.

```http
POST /orgs
Authorization: Bearer <token>
Content-Type: application/json

{
  "name": "Acme Corp",
  "slug": "acme-corp"
}
```

**Response:**
```json
{
  "id": "org_abc123",
  "name": "Acme Corp",
  "slug": "acme-corp",
  "role": "owner",
  "createdAt": "2024-02-15T10:00:00Z"
}
```

### List User's Organizations

Get all organizations the current user belongs to.

```http
GET /orgs
Authorization: Bearer <token>
```

**Response:**
```json
{
  "organizations": [

      "name": "Acme Corp",
```

### Update Organization

Update organization details (owner or admin only).

```http
PUT /orgs/:id
Authorization: Bearer <token>
Content-Type: application/json

{
  "name": "Acme Corporation",
  "slug": "acme-corporation"
}
```

### Delete Organization

Delete an organization (owner only).

```http
DELETE /orgs/:id
Authorization: Bearer <token>
```

### Invite Member

Invite a user to join the organization.

```http
POST /orgs/:id/invite
Authorization: Bearer <token>
Content-Type: application/json

{
  "email": "newuser@example.com",
  "role": "member"
}
```

### List Members

Get all members of an organization.

```http
GET /orgs/:id/members
Authorization: Bearer <token>
```

### Update Member Role

Change a member's role (owner or admin only).

```http
PUT /orgs/:id/members/:userId
Authorization: Bearer <token>
Content-Type: application/json

{
  "role": "admin"
}
```

### Remove Member

Remove a member from the organization (owner or admin only).

```http
DELETE /orgs/:id/members/:userId
Authorization: Bearer <token>
```

### Create Team

Create a team within an organization.

```http
POST /orgs/:id/teams
Authorization: Bearer <token>
Content-Type: application/json

{
  "name": "Engineering Team",
  "description": "Product development team"
}
```

### Add Team Member

Add a user to a team.

```http
POST /orgs/:orgId/teams/:teamId/members
Authorization: Bearer <token>
Content-Type: application/json

{
  "userId": "user_abc123",
  "role": "member"
}
```

## Roles and Permissions

### Organization Roles

| Role | Permissions |
|------|-------------|
| **Owner** | Full access, can delete org, manage all members |
| **Admin** | Can manage members and teams, cannot delete org |
| **Member** | Read access, can view org and teams |

### Team Roles

| Role | Permissions |
|------|-------------|
| **Lead** | Can manage team members |
| **Member** | Part of the team |

## Authorization

Check if a user has access to an organization:

```go
// Middleware example
func RequireOrganizationAccess(minRole string) func(http.Handler) http.Handler {
    return func(next http.Handler) http.Handler {
        return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
            orgID := chi.URLParam(r, "id")
            userID := core.GetUser(r.Context()).ID
            
            member, err := orgsPlugin.GetMember(r.Context(), orgID, userID)
            if err != nil || !hasMinRole(member.Role, minRole) {
                http.Error(w, "Forbidden", http.StatusForbidden)
                return
            }
            
            next.ServeHTTP(w, r)
        })
    }
}
```

## Frontend Integration

### Organization Switcher

```jsx
function OrganizationSwitcher() {
  const [orgs, setOrgs] = useState([]);
  const [current, setCurrent] = useState(null);
  
  useEffect(() => {
    fetch('/orgs', {
      headers: { 'Authorization': `Bearer ${token}` }
    })
    .then(res => res.json())
    .then(data => {
      setOrgs(data.organizations);
      setCurrent(data.organizations[0]);
    });
  }, []);
  
  return (
    <select onChange={(e) => setCurrent(e.target.value)}>
      {orgs.map(org => (
        <option key={org.id} value={org.id}>
          {org.name}
        </option>
      ))}
    </select>
  );
}
```

### SaaS Application

Multi-tenant SaaS apps where each organization is a separate customer.

Internal tools with department-based organizations.

### Collaboration Platforms

Project management or team collaboration tools.

### Agency Management

Agencies managing multiple client accounts.

## Best Practices

1. **Unique Slugs**: Ensure organization slugs are unique and URL-friendly
2. **Owner Protection**: Prevent accidental deletion of the last owner
3. **Soft Deletes**: Consider soft deletes for organizations
4. **Audit Trails**: Log all organization and membership changes
5. **Billing Integration**: Link organizations to billing/subscriptions
6. **Resource Isolation**: Ensure data isolation between organizations

## Example Integration

```go

import (
    "context"
    "database/sql"
    
    "github.com/go-chi/chi/v5"
    "github.com/theinventorylib/aegis"
    "github.com/theinventorylib/aegis/plugins/organizations"
)

func main() {
    ctx := context.Background()
    db, _ := sql.Open("postgres", "postgres://localhost/myapp")
    r := chi.NewRouter()
    
    // Configure Organizations plugin
    orgsPlugin := organizations.New(&organizations.Config{
        MaxMembersPerOrg: 50,
        AllowFreeOrgs:    true,
    })
    
    // Initialize Aegis  
    auth := aegis.New(ctx, config.Default().WithDB(db).WithRouter(r))
    auth.UseWithPriority(ctx, orgsPlugin, 10)  // Early initialization
    
    // Organization-scoped routes
    r.Route("/api/orgs/{orgId}", func(r chi.Router) {
        r.Use(RequireOrganizationAccess("member"))
        r.Get("/projects", listProjectsHandler)
    })
}
```
