# OAuth Plugin

The OAuth plugin enables social login authentication with popular OAuth 2.0 providers like Google, GitHub, Facebook, and more.

## Features

- **Multiple Providers**: Support for Google, GitHub, Facebook, Twitter, Microsoft, Apple, Discord
- **Custom Providers**: Easy integration with any OAuth 2.0 compliant provider
- **Automatic Account Linking**: Links OAuth accounts to existing users
- **Profile Sync**: Automatically syncs profile information from OAuth providers
- **Token Management**: Securely stores and refreshes OAuth tokens

## Installation

```bash
go get github.com/theinventorylib/aegis/plugins/oauth
```

## Configuration

```go
import (
    "github.com/theinventorylib/aegis"
    "github.com/theinventorylib/aegis/plugins/oauth"
)

// Configure OAuth plugin with providers
oauthPlugin := oauth.New(&oauth.Config{
    Providers: []oauth.Provider{
        {
            Name:         "google",
            ClientID:     os.Getenv("GOOGLE_CLIENT_ID"),
            ClientSecret: os.Getenv("GOOGLE_CLIENT_SECRET"),
            RedirectURL:  "https://yourapp.com/auth/callback/google",
            Scopes:       []string{"email", "profile"},
        },
        {
            Name:         "github",
            ClientID:     os.Getenv("GITHUB_CLIENT_ID"),
            ClientSecret: os.Getenv("GITHUB_CLIENT_SECRET"),
            RedirectURL:  "https://yourapp.com/auth/callback/github",
            Scopes:       []string{"user:email"},
        },
    },
})

// Register with Aegis
auth.Use(ctx, oauthPlugin)
```

## Database Schema

OAuth data is stored in the core `accounts` table with the following fields:

- `provider`: The OAuth provider name (e.g., "google", "github")
- `provider_account_id`: The user's ID from the OAuth provider
- `access_token`: OAuth access token (encrypted)
- `refresh_token`: OAuth refresh token (encrypted)
- `expires_at`: Token expiration time

## HTTP Endpoints

### Initiate OAuth Flow

Redirect users to the OAuth provider's authorization page.

```http
GET /auth/oauth/:provider
```

**Example:**
```http
GET /auth/oauth/google
```

This will redirect the user to Google's login page.

### OAuth Callback

Handle the OAuth provider's callback after user authorization.

```http
GET /auth/oauth/:provider/callback?code=...&state=...
```

This endpoint is automatically handled by the plugin and redirects to your application after successful authentication.

## Frontend Integration

### HTML/JavaScript

```html
<button onclick="window.location.href='/auth/oauth/google'">
  Sign in with Google
</button>

<button onclick="window.location.href='/auth/oauth/github'">
  Sign in with GitHub
</button>
```

### React

```jsx
function LoginButton({ provider }) {
  const handleLogin = () => {
    window.location.href = `/auth/oauth/${provider}`;
  };
  
  return (
    <button onClick={handleLogin}>
      Sign in with {provider}
    </button>
  );
}
```

## Account Linking

The OAuth plugin automatically links OAuth accounts to existing users based on email address. If a user signs in with Google and later with GitHub using the same email, both OAuth accounts will be linked to the same user account.

## Security Considerations

- OAuth tokens are encrypted before storage
- State parameter prevents CSRF attacks
- Redirect URLs are validated against configuration
- Tokens are refreshed automatically when expired
- Supports PKCE (Proof Key for Code Exchange) for enhanced security

## Error Handling

Common OAuth errors and their meanings:

| Error | Description |
|-------|-------------|
| `access_denied` | User denied authorization |
| `invalid_client` | Invalid client credentials |
| `invalid_grant` | Authorization code expired or invalid |
| `invalid_scope` | Requested scope is invalid |

## Example Integration

```go
package main

import (
    "context"
    "database/sql"
    "os"
    
    "github.com/theinventorylib/aegis"
    "github.com/theinventorylib/aegis/plugins/oauth"
)

func main() {
    ctx := context.Background()
    db, _ := sql.Open("postgres", "postgres://localhost/myapp")
    
    // Configure OAuth plugin
    oauthPlugin := oauth.New(&oauth.Config{
        Providers: []oauth.Provider{
            {
                Name:         "google",
                ClientID:     os.Getenv("GOOGLE_CLIENT_ID"),
                ClientSecret: os.Getenv("GOOGLE_CLIENT_SECRET"),
                RedirectURL:  "http://localhost:8080/auth/callback/google",
                Scopes:       []string{"email", "profile"},
            },
        },
    })
    
    // Initialize Aegis
    auth := aegis.New(ctx, config.Default().WithDB(db))
    auth.Use(ctx, oauthPlugin)
}
```
