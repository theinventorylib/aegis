The Email OTP plugin provides email-based authentication, including one-time password (OTP) verification and traditional email+password authentication. It extends the user model with `email` and `email_verified` fields.

## Features

- **Email+Password Authentication**: Traditional sign up and sign in with email and password
- **Email Verification**: Send verification codes via email with configurable OTP length and expiry
- **Password Reset**: Secure password reset flow with email verification
- **User Enrichment**: Automatically adds `email` and `emailVerified` to authenticated user responses
- **Customizable Email Templates**: Full control over email content and formatting
- **Programmatic API**: Full Go API for server-side email and verification management

## Installation

```bash
go get github.com/theinventorylib/aegis/v2/plugins/emailotp
```

## Configuration

```go
import (
    "context"
    "time"
    "github.com/theinventorylib/aegis/v2"
    "github.com/theinventorylib/aegis/v2/plugins/emailotp"
)

// Implement the emailotp.Provider interface with your email service
type MyEmailProvider struct{}

func (p *MyEmailProvider) SendOTP(to, code string) error {
    // Send OTP code via your email service
    log.Printf("Email to %s: Your code is %s", to, code)
    return nil // Replace with actual email sending
}

func (p *MyEmailProvider) SendEmail(to, subject, body string) error {
    // Send arbitrary email via your email service
    log.Printf("Email to %s: %s\n%s", to, subject, body)
    return nil // Replace with actual email sending
}

func (p *MyEmailProvider) VerifyOTP(to, code string) (bool, error) {
    // Delegate validation to Aegis's internal OTP store
    return true, nil
}

emailPlugin := emailotp.New(&emailotp.Config{
    Provider:  &MyEmailProvider{},
    OTPLength: 6,
    OTPExpiry: 10 * time.Minute,
}, nil) // nil store uses default SQL storage

// Register with Aegis
a, _ := aegis.New(ctx, cfg)
a.Use(ctx, emailPlugin)
a.MountRoutes("/auth")
```

### Configuration Options

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `Provider` | `emailotp.Provider` | nil | Email provider implementing `SendOTP`, `SendEmail`, `VerifyOTP` (required) |
| `OTPLength` | `int` | 6 | Length of OTP codes |
| `OTPExpiry` | `time.Duration` | 10 min | OTP code expiration time |
| `PasswordResetURL` | `string` | "" | Link template for reset mails; `{token}` is replaced. Empty mails the raw token as a code. |
| `EmailChangeURL` | `string` | "" | Link template for email-change mails; `{token}` is replaced. Empty mails the raw token as a code. |

## Database Schema

The Email OTP plugin extends the `user` table with:

| Column | Type | Description |
|--------|------|-------------|
| `email` | VARCHAR | User's email address |
| `email_verified` | BOOLEAN | Whether the email has been verified |

OTP codes are stored in the core `verification` table.

## HTTP Endpoints

### Send OTP

Send a verification code to a user's email address. Requires authentication.

```http
POST /auth/email-otp/send
Authorization: Bearer <token>
Content-Type: application/json

{
  "email": "user@example.com",
  "purpose": "email_verification",
  "userId": "usr_abc123"
}
```

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `email` | string | Yes | Email address to send the code to |
| `purpose` | string | Yes | Verification type (e.g., `email_verification`, `password_reset`) |
| `userId` | string | Yes | Aegis user ID requesting the OTP |

**Response (200):**

```json
{
  "success": true,
  "message": "OTP sent successfully"
}
```

### Send Verification Code (unauthenticated)

Send an `email_verification` code before the user has a session — used by the
registration flow when `AuthConfig.RequireEmailVerification` is enabled. Public,
and throttled per email by the application's configured rate limiter.

```http
POST /auth/email-otp/send-verification
Content-Type: application/json

{
  "email": "user@example.com"
}
```

**Response (200):**

```json
{
  "success": true,
  "message": "Verification code sent"
}
```

### Verify OTP

Verify an OTP code and mark the email as verified.

```http
POST /auth/email-otp/verify
Content-Type: application/json

{
  "email": "user@example.com",
  "code": "123456",
  "purpose": "email_verification"
}
```

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `email` | string | Yes | Email address |
| `code` | string | Yes | OTP code received via email |
| `purpose` | string | Yes | OTP purpose (must match the value used in SendOTP) |

**Response (200):**

```json
{
  "success": true,
  "message": "OTP verified successfully"
}
```

Only an `email_verification` code marks the address verified. A
`password_reset` or `login_mfa` code is consumed but leaves the
`email_verified` flag untouched.

### Forgot Password

Mail a password-reset token to an address. Public and rate-limited per email
when a rate limiter is configured. The response is identical whether or not the
address has an account, so the endpoint cannot be used to enumerate users.

```http
POST /auth/email-otp/forgot-password
Content-Type: application/json

{
  "email": "user@example.com"
}
```

When `PasswordResetURL` is configured the mail contains a link
(`...?token=...`); otherwise the raw token is mailed as a code.

### Reset Password

Redeem a reset token and set a new password. All existing sessions are revoked.

```http
POST /auth/email-otp/reset-password
Content-Type: application/json

{
  "token": "<token from the email>",
  "new_password": "NewSecurePassword123!"
}
```

### Request Email Change

Mail a confirmation token to the new address. Requires authentication; the
account that changes is the authenticated caller.

```http
POST /auth/email-otp/email-change
Authorization: Bearer <token>
Content-Type: application/json

{
  "new_email": "new@example.com"
}
```

### Confirm Email Change

Redeem the token mailed to the new address. Because control of the address was
just proven, the new address is marked verified automatically.

```http
POST /auth/email-otp/email-change/confirm
Authorization: Bearer <token>
Content-Type: application/json

{
  "token": "<token from the email>"
}
```

## Programmatic API

All email OTP operations are available as Go methods on the plugin instance. Use these for server-side logic, user registration flows, and email verification processes.

### Getting the Plugin Instance

```go
// Type-safe retrieval (recommended)
emailPlugin, ok := aegis.GetPluginTyped[*emailotp.Plugin](a, "emailotp")
if !ok {
    log.Fatal("Email OTP plugin not registered")
}

// Via GetPlugin with type assertion
plugin, ok := a.GetPlugin("emailotp")
if ok {
    emailPlugin := plugin.(*emailotp.Plugin)
}
```

### OTP Methods

#### SendOTP

Generate and send a one-time password code via email.

```go
func SendOTP(ctx context.Context, email, purpose string) error
```

**Parameters:**
- `ctx` — Request context for cancellation and tracing
- `email` — Recipient email address
- `purpose` — OTP purpose identifier (e.g., "email_verification", "password_reset", "2fa")

**Returns:**
- `error` — Email sending errors, database errors, or rate limit errors

**Behavior:**
- Generates a 6-digit numeric code
- Stores code in database with 10-minute expiration
- Sends email via configured email provider (SMTP, SendGrid, etc.)
- Previous unused codes for the same email/purpose are invalidated
- Code can only be used once (deleted upon successful verification)

**Example:**
```go
// Email verification during signup
err := emailPlugin.SendOTP(ctx, "user@example.com", "email_verification")
if err != nil {
    return fmt.Errorf("failed to send verification email: %w", err)
}

// Password reset
err = emailPlugin.SendOTP(ctx, "user@example.com", "password_reset")

// Two-factor authentication
err = emailPlugin.SendOTP(ctx, "user@example.com", "2fa_login")
```

#### VerifyOTP

Verify a one-time password code. Does NOT automatically mark the email as verified — call `MarkEmailVerified` separately.

```go
func VerifyOTP(ctx context.Context, email, code string) (bool, error)
```

**Parameters:**
- `ctx` — Request context
- `email` — Email address to verify code for
- `code` — 6-digit OTP code from user

**Returns:**
- `bool` — `true` if code is valid and not expired
- `error` — Database errors (not returned for invalid/expired codes)

**Behavior:**
- Looks up code in database by email
- Checks code matches and hasn't expired (10-minute window)
- Deletes code from database upon successful validation (single-use)
- Does NOT mark email as verified (call `MarkEmailVerified` separately)
- Returns `false` (not error) for invalid/expired codes

**Example:**
```go
valid, err := emailPlugin.VerifyOTP(ctx, "user@example.com", "123456")
if err != nil {
    return fmt.Errorf("verification error: %w", err)
}

if !valid {
    http.Error(w, "Invalid or expired code", http.StatusBadRequest)
    return
}

// Code valid — explicitly mark email as verified
if err := emailPlugin.MarkEmailVerified(ctx, "user@example.com"); err != nil {
    return fmt.Errorf("failed to mark verified: %w", err)
}
```

#### SendEmail

Send an arbitrary email using the configured email provider.

```go
func SendEmail(ctx context.Context, to, subject, body string) error
```

**Parameters:**
- `ctx` — Request context
- `to` — Recipient email address
- `subject` — Email subject line
- `body` — Plain-text email body

**Returns:**
- `error` — If provider is configured but sending fails

**Behavior:**
- Delegates to the configured `Provider.SendEmail` implementation
- If no provider is configured, the email is not sent and no error is returned
- Other plugins (e.g., organizations) reuse this method for invitation emails

**Example:**
```go
err := emailPlugin.SendEmail(ctx, "user@example.com", "Welcome!", "Thank you for joining.")
if err != nil {
    return fmt.Errorf("failed to send email: %w", err)
}
```

### User Methods

#### GetUserByEmail

Look up a user by their email address.

```go
func GetUserByEmail(ctx context.Context, email string) (*auth.User, error)
```

**Parameters:**
- `ctx` — Request context
- `email` — Email address to search for

**Returns:**
- `*auth.User` — Core user object with ID, email, name, timestamps
- `error` — `sql.ErrNoRows` if user not found, database errors

**Example:**
```go
user, err := emailPlugin.GetUserByEmail(ctx, "user@example.com")
if err == sql.ErrNoRows {
    // User doesn't exist — proceed with registration
}
```

#### CreateUserWithEmailAndPassword

Register a new user with email and password authentication.

```go
func CreateUserWithEmailAndPassword(ctx context.Context, name, email, password string) (*User, error)
```

**Parameters:**
- `ctx` — Request context
- `name` — User's display name
- `email` — User's email address (must be unique)
- `password` — Plain-text password (will be hashed with Argon2id)

**Returns:**
- `*User` — Created user object with generated ID
- `error` — Validation errors (duplicate email, weak password) or database errors

**Behavior:**
- Validates email format and uniqueness
- Hashes password using Argon2id with OWASP parameters
- Creates user record with `emailVerified = false` by default
- Does NOT send verification email (call `SendOTP` separately)

**Example:**
```go
user, err := emailPlugin.CreateUserWithEmailAndPassword(
    ctx,
    "Jane Smith",
    "newuser@example.com",
    "SecurePassword123!",
)
if err != nil {
    if strings.Contains(err.Error(), "duplicate") {
        http.Error(w, "Email already registered", http.StatusConflict)
        return
    }
    return fmt.Errorf("registration failed: %w", err)
}

// Send verification email
emailPlugin.SendOTP(ctx, user.Email, "email_verification", user.Name)
```

### Email Verification Methods

#### MarkEmailVerified

Mark a user's email as verified by email address lookup.

```go
func MarkEmailVerified(ctx context.Context, email string) error
```

**Parameters:**
- `ctx` — Request context
- `email` — Email address to mark as verified

**Returns:**
- `error` — Database errors or user not found

**Behavior:**
- Looks up user by email address
- Sets `emailVerified = true` in database
- Called by the HTTP `VerifyOTPHandler` after successful validation; does NOT run automatically from the programmatic `VerifyOTP` method
- Idempotent (safe to call multiple times)

**Example:**
```go
// Manually verify an email (admin action)
err := emailPlugin.MarkEmailVerified(ctx, "support@example.com")

// After OAuth login with verified email
if oauthEmailVerified {
    emailPlugin.MarkEmailVerified(ctx, oauthEmail)
}
```

#### UpdateUserEmail

Update a user's email address and verification status.

```go
func UpdateUserEmail(ctx context.Context, userID, email string, verified bool) error
```

**Parameters:**
- `ctx` — Request context
- `userID` — User identifier
- `email` — New email address to set
- `verified` — Whether the new email should be marked as verified

**Returns:**
- `error` — Validation errors (duplicate email) or database errors

**Behavior:**
- Updates user's email address
- Sets verification status as specified
- Fails if new email conflicts with existing user
- Does NOT send verification email (call `SendOTP` separately if needed)

**Example:**
```go
// Email change flow (require verification)
err := emailPlugin.UpdateUserEmail(ctx, "user_123", "newemail@example.com", false)
if err != nil {
    return fmt.Errorf("failed to update email: %w", err)
}

// Send verification to new email
emailPlugin.SendOTP(ctx, "newemail@example.com", "email_verification")
```

## User Enrichment

The plugin automatically enriches authenticated users with email data:

```json
{
  "id": "user_abc123",
  "email": "user@example.com",
  "emailVerified": true
}
```

Access in handlers:

```go
func myHandler(w http.ResponseWriter, r *http.Request) {
    enriched := core.GetEnrichedUser(r.Context())
    email := enriched.GetString("email")
    verified := enriched.GetBool("emailVerified")
}
```

## Route Summary

| Method | Path | Description | Auth Required |
|--------|------|-------------|---------------|
| POST | `/email-otp/send` | Send verification code | Yes |
| POST | `/email-otp/verify` | Verify OTP code | No |
| POST | `/email-otp/send-verification` | Send verification code for a pre-session account | No |
| POST | `/email-otp/forgot-password` | Request a password reset | No |
| POST | `/email-otp/reset-password` | Complete a password reset | No |
| POST | `/email-otp/email-change` | Request an email change | Yes |
| POST | `/email-otp/email-change/confirm` | Confirm an email change | Yes |

## Security Considerations

- Passwords are hashed using **Argon2id** (OWASP-compliant parameters)
- OTP codes are stored securely with expiration times
- Email verification prevents unauthorized account usage
- The public `/send-verification` route is throttled per email by the configured
  rate limiter (`WithRateLimiting`); keep rate limiting enabled in production
- OTP codes are single-use and deleted upon verification

## Example Integration

```go
package main

import (
    "context"
    "database/sql"
    "log"
    "net/http"
    "time"

    "github.com/go-chi/chi/v5"
    "github.com/theinventorylib/aegis/v2"
    "github.com/theinventorylib/aegis/v2/config"
    "github.com/theinventorylib/aegis/v2/plugins/emailotp"
    "github.com/theinventorylib/aegis/v2/router/routers"
)

func main() {
    ctx := context.Background()
    db, _ := sql.Open("postgres", "postgres://localhost/myapp?sslmode=disable")
    r := chi.NewRouter()

    cfg := config.Default().
        WithDB(db).
        WithRouter(routers.NewChiRouter(r)).
        WithSecret([]byte("your-32-byte-secret-key-here!!!!"))

    emailPlugin := emailotp.New(&emailotp.Config{
        Provider:  &MyEmailProvider{},
        OTPLength: 6,
        OTPExpiry: 10 * time.Minute,
    })

    a, _ := aegis.New(ctx, cfg)
    a.Use(ctx, emailPlugin)
    a.MountRoutes("/auth")

    // Programmatic: verify email in a background job
    go func() {
        // After user confirms email via custom flow
        err := emailPlugin.MarkEmailVerified(ctx, "user@example.com")
        if err != nil {
            log.Printf("Failed to verify email: %v", err)
        }
    }()

    http.ListenAndServe(":8080", r)
}
```
