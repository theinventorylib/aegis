The Email OTP plugin provides email-based authentication, including one-time password (OTP) verification and traditional email+password authentication. It extends the user model with `email` and `email_verified` fields.

## Features

- **Email+Password Authentication**: Traditional sign up and sign in with email and password
- **Email Verification**: Send verification codes via email with configurable OTP length and expiry
- **Password Reset**: Secure password reset flow with email verification
- **User Enrichment**: Automatically adds `email` and `emailVerified` to authenticated user responses
- **Customizable Email Templates**: Full control over email content and formatting
- **Programmatic API**: Full Go API for server-side email and verification management

## Installation

```bash
go get github.com/theinventorylib/aegis/plugins/emailotp
```

## Configuration

```go
import (
    "context"
    "time"
    "github.com/theinventorylib/aegis"
    "github.com/theinventorylib/aegis/plugins/emailotp"
)

emailPlugin := emailotp.New(&emailotp.Config{
    // Required: Email sending function
    SendEmail: func(to, subject, body string) error {
        // Integrate with your email provider
        // (SendGrid, Mailgun, AWS SES, SMTP, etc.)
        return mailer.Send(to, subject, body)
    },

    // OTP code length (default: 6)
    OTPLength: 6,

    // OTP expiration time (default: 10 minutes)
    OTPExpiry: 10 * time.Minute,
})

// Register with Aegis
a, _ := aegis.New(ctx, cfg)
a.Use(ctx, emailPlugin)
a.MountRoutes("/auth")
```

### Configuration Options

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `SendEmail` | `func(to, subject, body string) error` | nil | Email sending function (required) |
| `OTPLength` | `int` | 6 | Length of OTP codes |
| `OTPExpiry` | `time.Duration` | 10 min | OTP code expiration time |

## Database Schema

The Email OTP plugin extends the `user` table with:

| Column | Type | Description |
|--------|------|-------------|
| `email` | VARCHAR | User's email address |
| `email_verified` | BOOLEAN | Whether the email has been verified |

OTP codes are stored in the core `verification` table.

## HTTP Endpoints

### Send OTP

Send a verification code to a user's email address. Requires authentication.

```http
POST /auth/email/send-otp
Authorization: Bearer <token>
Content-Type: application/json

{
  "email": "user@example.com",
  "type": "email_verification"
}
```

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `email` | string | Yes | Email address to send the code to |
| `type` | string | Yes | Verification type (e.g., `email_verification`, `password_reset`) |
| `name` | string | No | User's name (for email template) |

**Response (200):**

```json
{
  "success": true,
  "message": "Verification code sent"
}
```

### Verify OTP

Verify an OTP code and mark the email as verified.

```http
POST /auth/email/verify-otp
Content-Type: application/json

{
  "email": "user@example.com",
  "code": "123456"
}
```

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `email` | string | Yes | Email address |
| `code` | string | Yes | OTP code received via email |

**Response (200):**

```json
{
  "success": true,
  "message": "Email verified"
}
```

## Programmatic API

All email OTP operations are available as Go methods on the plugin instance. Use these for server-side logic, user registration flows, and email verification processes.

### Getting the Plugin Instance

```go
// Type-safe retrieval (recommended)
emailPlugin, ok := aegis.GetPluginTyped[*emailotp.Plugin](a, "emailotp")
if !ok {
    log.Fatal("Email OTP plugin not registered")
}

// Via GetPlugin with type assertion
plugin, ok := a.GetPlugin("emailotp")
if ok {
    emailPlugin := plugin.(*emailotp.Plugin)
}
```

### OTP Methods

#### SendOTP

Generate and send a one-time password code via email.

```go
func SendOTP(ctx context.Context, email, purpose, userName string) error
```

**Parameters:**
- `ctx` — Request context for cancellation and tracing
- `email` — Recipient email address
- `purpose` — OTP purpose identifier (e.g., "email_verification", "password_reset", "2fa")
- `userName` — User's display name for email personalization

**Returns:**
- `error` — Email sending errors, database errors, or rate limit errors

**Behavior:**
- Generates a 6-digit numeric code
- Stores code in database with 10-minute expiration
- Sends email via configured email provider (SMTP, SendGrid, etc.)
- Previous unused codes for the same email/purpose are invalidated
- Code can only be used once (deleted upon successful verification)

**Example:**
```go
// Email verification during signup
err := emailPlugin.SendOTP(ctx, "user@example.com", "email_verification", "John Doe")
if err != nil {
    return fmt.Errorf("failed to send verification email: %w", err)
}

// Password reset
err = emailPlugin.SendOTP(ctx, "user@example.com", "password_reset", "John Doe")

// Two-factor authentication
err = emailPlugin.SendOTP(ctx, "user@example.com", "2fa_login", "John")
```

#### VerifyOTP

Verify a one-time password code and mark email as verified on success.

```go
func VerifyOTP(ctx context.Context, email, code string) (bool, error)
```

**Parameters:**
- `ctx` — Request context
- `email` — Email address to verify code for
- `code` — 6-digit OTP code from user

**Returns:**
- `bool` — `true` if code is valid and not expired
- `error` — Database errors (not returned for invalid/expired codes)

**Behavior:**
- Looks up code in database by email
- Checks code matches and hasn't expired (10-minute window)
- Deletes code from database upon successful validation (single-use)
- **Automatically marks email as verified** in user table
- Returns `false` (not error) for invalid/expired codes

**Example:**
```go
valid, err := emailPlugin.VerifyOTP(ctx, "user@example.com", "123456")
if err != nil {
    return fmt.Errorf("verification error: %w", err)
}

if !valid {
    http.Error(w, "Invalid or expired code", http.StatusBadRequest)
    return
}

// Code valid — email is now verified
```

### User Methods

#### GetUserByEmail

Look up a user by their email address.

```go
func GetUserByEmail(ctx context.Context, email string) (*User, error)
```

**Parameters:**
- `ctx` — Request context
- `email` — Email address to search for

**Returns:**
- `*User` — User object with ID, email, name, timestamps
- `error` — `sql.ErrNoRows` if user not found, database errors

**Example:**
```go
user, err := emailPlugin.GetUserByEmail(ctx, "user@example.com")
if err == sql.ErrNoRows {
    // User doesn't exist — proceed with registration
}
```

#### CreateUserWithEmailAndPassword

Register a new user with email and password authentication.

```go
func CreateUserWithEmailAndPassword(ctx context.Context, email, password, name string) (*User, error)
```

**Parameters:**
- `ctx` — Request context
- `email` — User's email address (must be unique)
- `password` — Plain-text password (will be hashed with Argon2id)
- `name` — User's display name

**Returns:**
- `*User` — Created user object with generated ID
- `error` — Validation errors (duplicate email, weak password) or database errors

**Behavior:**
- Validates email format and uniqueness
- Hashes password using Argon2id with OWASP parameters
- Creates user record with `emailVerified = false` by default
- Does NOT send verification email (call `SendOTP` separately)

**Example:**
```go
user, err := emailPlugin.CreateUserWithEmailAndPassword(
    ctx,
    "newuser@example.com",
    "SecurePassword123!",
    "Jane Smith",
)
if err != nil {
    if strings.Contains(err.Error(), "duplicate") {
        http.Error(w, "Email already registered", http.StatusConflict)
        return
    }
    return fmt.Errorf("registration failed: %w", err)
}

// Send verification email
emailPlugin.SendOTP(ctx, user.Email, "email_verification", user.Name)
```

### Email Verification Methods

#### MarkEmailVerified

Mark a user's email as verified by email address lookup.

```go
func MarkEmailVerified(ctx context.Context, email string) error
```

**Parameters:**
- `ctx` — Request context
- `email` — Email address to mark as verified

**Returns:**
- `error` — Database errors or user not found

**Behavior:**
- Looks up user by email address
- Sets `emailVerified = true` in database
- Called automatically by `VerifyOTP()` on successful validation
- Idempotent (safe to call multiple times)

**Example:**
```go
// Manually verify an email (admin action)
err := emailPlugin.MarkEmailVerified(ctx, "support@example.com")

// After OAuth login with verified email
if oauthEmailVerified {
    emailPlugin.MarkEmailVerified(ctx, oauthEmail)
}
```

#### UpdateUserEmail

Update a user's email address and verification status.

```go
func UpdateUserEmail(ctx context.Context, userID, newEmail string, verified bool) error
```

**Parameters:**
- `ctx` — Request context
- `userID` — User identifier
- `newEmail` — New email address to set
- `verified` — Whether the new email should be marked as verified

**Returns:**
- `error` — Validation errors (duplicate email) or database errors

**Behavior:**
- Updates user's email address
- Sets verification status as specified
- Fails if new email conflicts with existing user
- Does NOT send verification email (call `SendOTP` separately if needed)

**Example:**
```go
// Email change flow (require verification)
err := emailPlugin.UpdateUserEmail(ctx, "user_123", "newemail@example.com", false)
if err != nil {
    return fmt.Errorf("failed to update email: %w", err)
}

// Send verification to new email
emailPlugin.SendOTP(ctx, "newemail@example.com", "email_verification", userName)
```

## User Enrichment

The plugin automatically enriches authenticated users with email data:

```json
{
  "id": "user_abc123",
  "email": "user@example.com",
  "emailVerified": true
}
```

Access in handlers:

```go
func myHandler(w http.ResponseWriter, r *http.Request) {
    enriched := core.GetEnrichedUser(r.Context())
    email := enriched.GetString("email")
    verified := enriched.GetBool("emailVerified")
}
```

## Route Summary

| Method | Path | Description | Auth Required |
|--------|------|-------------|---------------|
| POST | `/email/send-otp` | Send verification code | Yes |
| POST | `/email/verify-otp` | Verify OTP code | No |

## Security Considerations

- Passwords are hashed using **Argon2id** (OWASP-compliant parameters)
- OTP codes are stored securely with expiration times
- Email verification prevents unauthorized account usage
- Rate limiting should be applied to prevent email abuse
- OTP codes are single-use and deleted upon verification

## Example Integration

```go
package main

import (
    "context"
    "database/sql"
    "log"
    "net/http"
    "time"

    "github.com/go-chi/chi/v5"
    "github.com/theinventorylib/aegis"
    "github.com/theinventorylib/aegis/config"
    "github.com/theinventorylib/aegis/plugins/emailotp"
)

func main() {
    ctx := context.Background()
    db, _ := sql.Open("postgres", "postgres://localhost/myapp?sslmode=disable")
    r := chi.NewRouter()

    cfg := config.Default().
        WithDB(db).
        WithRouter(r).
        WithSecret([]byte("your-32-byte-secret-key-here!!!!"))

    emailPlugin := emailotp.New(&emailotp.Config{
        SendEmail: func(to, subject, body string) error {
            log.Printf("Email to %s: %s\n%s", to, subject, body)
            return nil // Replace with actual email sending
        },
        OTPLength: 6,
        OTPExpiry: 10 * time.Minute,
    })

    a, _ := aegis.New(ctx, cfg)
    a.Use(ctx, emailPlugin)
    a.MountRoutes("/auth")

    // Programmatic: verify email in a background job
    go func() {
        // After user confirms email via custom flow
        err := emailPlugin.MarkEmailVerified(ctx, "user@example.com")
        if err != nil {
            log.Printf("Failed to verify email: %v", err)
        }
    }()

    http.ListenAndServe(":8080", r)
}
```
