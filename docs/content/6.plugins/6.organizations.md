# Organizations Plugin

The Organizations plugin enables multi-tenancy with organizations, teams, roles, and member management. Ideal for SaaS applications, collaboration platforms, and enterprise software.

## Features

- **Organization Management**: Create, update, and delete organizations (workspaces, tenants)
- **Team Support**: Organize members into teams within organizations
- **Role-Based Permissions**: Owner, Admin, and Member roles at both org and team level
- **Member Management**: Add, remove, and update member roles
- **User Enrichment**: Automatically adds organization data to authenticated user responses
- **OpenAPI Integration**: All endpoints documented in the OpenAPI spec

## Installation

```bash
go get github.com/theinventorylib/aegis/plugins/organizations
```

## Configuration

```go
import (
    "context"
    "github.com/theinventorylib/aegis"
    "github.com/theinventorylib/aegis/plugins/organizations"
    "github.com/theinventorylib/aegis/plugins"
)

// Create with default store
orgsPlugin := organizations.New(nil, plugins.DialectPostgres)

// Or with a custom store
orgsPlugin := organizations.New(myCustomStore, plugins.DialectPostgres)

// Register with Aegis
a, _ := aegis.New(ctx, cfg)
a.Use(ctx, orgsPlugin)

// Mount routes (org endpoints available at /auth/orgs/*)
a.MountRoutes("/auth")
```

## Database Schema

### Organizations

```sql
CREATE TABLE organization (
    id TEXT PRIMARY KEY,
    name TEXT NOT NULL,
    slug TEXT NOT NULL UNIQUE,
    disabled INTEGER NOT NULL DEFAULT 0,
    created_at TEXT NOT NULL,
    updated_at TEXT NOT NULL
);
```

### Members

```sql
CREATE TABLE members (
    id TEXT PRIMARY KEY,
    user_id TEXT NOT NULL REFERENCES "user"(id) ON DELETE CASCADE,
    organization_id TEXT NOT NULL REFERENCES organization(id) ON DELETE CASCADE,
    role TEXT NOT NULL,
    created_at TEXT NOT NULL,
    updated_at TEXT NOT NULL,
    UNIQUE(user_id, organization_id)
);
```

### Teams

```sql
CREATE TABLE team (
    id TEXT PRIMARY KEY,
    organization_id TEXT NOT NULL REFERENCES organization(id) ON DELETE CASCADE,
    name TEXT NOT NULL,
    description TEXT,
    created_at TEXT NOT NULL,
    updated_at TEXT NOT NULL
);
```

### Team Members

```sql
CREATE TABLE team_member (
    id TEXT PRIMARY KEY,
    team_id TEXT NOT NULL REFERENCES team(id) ON DELETE CASCADE,
    user_id TEXT NOT NULL REFERENCES "user"(id) ON DELETE CASCADE,
    role TEXT NOT NULL,
    created_at TEXT NOT NULL,
    updated_at TEXT NOT NULL,
    UNIQUE(team_id, user_id)
);
```

## HTTP Endpoints

All organization endpoints require authentication. Role-based access is enforced where noted.

### Organizations

#### Create Organization

The authenticated user becomes the owner automatically.

```http
POST /auth/orgs
Authorization: Bearer <token>
Content-Type: application/json

{
  "name": "Acme Corp",
  "slug": "acme-corp"
}
```

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `name` | string | Yes | Organization display name |
| `slug` | string | Yes | URL-friendly unique identifier |

**Response (201):**

```json
{
  "success": true,
  "data": {
    "id": "org_abc123",
    "name": "Acme Corp",
    "slug": "acme-corp",
    "createdAt": "2024-02-15T10:00:00Z"
  }
}
```

#### List User's Organizations

Get all organizations the current user belongs to.

```http
GET /auth/orgs
Authorization: Bearer <token>
```

**Response (200):**

```json
{
  "success": true,
  "data": [
    {
      "id": "org_abc123",
      "name": "Acme Corp",
      "slug": "acme-corp",
      "role": "owner"
    }
  ]
}
```

#### Get Organization

Requires membership in the organization.

```http
GET /auth/orgs/:id
Authorization: Bearer <token>
```

#### Update Organization

## Programmatic API

All organization operations are available as Go methods on the plugin instance. Use these for server-side logic, background jobs, CLI tools, or custom handlers requiring multi-tenant functionality.

### Getting the Plugin Instance

```go
// Type-safe retrieval (recommended)
orgsPlugin, ok := aegis.GetPluginTyped[*organizations.Plugin](a, "organizations")
if !ok {
    log.Fatal("Organizations plugin not registered")
}

// Via GetPlugin with type assertion
plugin, ok := a.GetPlugin("organizations")
if ok {
    orgsPlugin := plugin.(*organizations.Plugin)
}
```

### Organization Methods

#### CreateOrganization

Create a new organization with the creator automatically assigned as owner.

```go
func CreateOrganization(ctx context.Context, userID, name, slug string) (*Organization, error)
```

**Parameters:**
- `ctx` — Request context for cancellation and tracing
- `userID` — ID of the user creating the organization (becomes owner)
- `name` — Organization display name (e.g., "Acme Corporation")
- `slug` — URL-friendly unique identifier (e.g., "acme-corp")

**Returns:**
- `*Organization` — Created organization with ID, timestamps
- `error` — Validation errors (duplicate slug) or database errors

**Behavior:**
- Creates organization record
- Automatically adds creator as organization member with "owner" role
- Slug must be unique across all organizations
- No minimum/maximum member limits enforced

**Example:**
```go
org, err := orgsPlugin.CreateOrganization(ctx, "user_123", "Acme Corp", "acme-corp")
if err != nil {
    if strings.Contains(err.Error(), "duplicate") {
        return fmt.Errorf("slug already taken")
    }
    return fmt.Errorf("failed to create organization: %w", err)
}

log.Info("Organization created", "org_id", org.ID, "slug", org.Slug)
```

#### GetOrganization

Retrieve organization details by ID.

```go
func GetOrganization(ctx context.Context, orgID string) (*Organization, error)
```

**Parameters:**
- `ctx` — Request context
- `orgID` — Organization identifier

**Returns:**
- `*Organization` — Organization object with name, slug, timestamps
- `error` — `sql.ErrNoRows` if not found, database errors

**Example:**
```go
org, err := orgsPlugin.GetOrganization(ctx, "org_abc123")
if err == sql.ErrNoRows {
    return fmt.Errorf("organization not found")
}
fmt.Printf("Organization: %s (slug: %s)\n", org.Name, org.Slug)
```

#### UpdateOrganization

Update organization name and slug.

```go
func UpdateOrganization(ctx context.Context, orgID, name, slug string) error
```

**Parameters:**
- `ctx` — Request context
- `orgID` — Organization to update
- `name` — New display name
- `slug` — New URL slug (must be unique)

**Returns:**
- `error` — Validation errors (duplicate slug) or database errors

**Behavior:**
- Updates both name and slug atomically
- Fails if new slug conflicts with existing organization
- Does not validate user permissions (implement in your handlers)

**Example:**
```go
err := orgsPlugin.UpdateOrganization(ctx, "org_abc", "New Name", "new-slug")
if err != nil {
    return fmt.Errorf("failed to update organization: %w", err)
}
```

#### DeleteOrganization

Permanently delete an organization and all associated data.

```go
func DeleteOrganization(ctx context.Context, orgID string) error
```

**Parameters:**
- `ctx` — Request context
- `orgID` — Organization to delete

**Returns:**
- `error` — Database errors

**Warning:**
- **Irreversible operation** — deletes organization, members, teams, team members
- Cascading deletes remove all related data
- Does not delete user accounts (only memberships)
- Consider soft-delete for production systems

**Example:**
```go
// Confirm before deletion
err := orgsPlugin.DeleteOrganization(ctx, "org_to_delete")
if err != nil {
    return fmt.Errorf("failed to delete organization: %w", err)
}
log.Warn("Organization permanently deleted", "org_id", "org_to_delete")
```

### Member Methods

#### AddOrganizationMember

Add a user to an organization with a specified role.

```go
func AddOrganizationMember(ctx context.Context, orgID, userID, role string) (*Member, error)
```

**Parameters:**
- `ctx` — Request context
- `orgID` — Organization identifier
- `userID` — User to add as member
- `role` — Role to assign ("owner", "admin", "member", or custom)

**Returns:**
- `*Member` — Created membership record with timestamps
- `error` — Validation errors (already a member) or database errors

**Behavior:**
- Creates membership record with specified role
- Fails if user is already a member (use `UpdateMemberRole` to change role)
- Does not validate that user exists (foreign key constraint will fail)
- Does not send invitation emails (implement separately)

**Example:**
```go
member, err := orgsPlugin.AddOrganizationMember(ctx, "org_abc", "user_456", "member")

    if strings.Contains(err.Error(), "duplicate") {
        return fmt.Errorf("user is already a member")
    }
    return fmt.Errorf("failed to add member: %w", err)
}

log.Info("Member added", "org_id", "org_abc", "user_id", "user_456", "role", "member")
```

#### UpdateMemberRole

Change an organization member's role.

```go
func UpdateMemberRole(ctx context.Context, orgID, userID, newRole string) error
```

**Parameters:**
- `ctx` — Request context
- `orgID` — Organization identifier
- `userID` — Member whose role to update
- `newRole` — New role to assign

**Returns:**
- `error` — Database errors or member not found

**Behavior:**
- Updates existing membership role
- Fails if user is not a member
- Does not validate role transitions (implement role hierarchy in your app)
- Allows changing owner role (implement ownership protection if needed)

**Example:**
```go
// Promote to admin
err := orgsPlugin.UpdateMemberRole(ctx, "org_abc", "user_456", "admin")
if err != nil {
    return fmt.Errorf("failed to update role: %w", err)
}

// Demote to member
err = orgsPlugin.UpdateMemberRole(ctx, "org_abc", "former_admin", "member")
```

#### RemoveOrganizationMember

Remove a user from an organization.


- `orgID` — Organization identifier
- `userID` — Member to remove

**Returns:**
- `error` — Database errors

**Behavior:**
- Deletes membership record
- Removes user from all teams in the organization
- Does not delete user account (only membership)
- Does not prevent removing the last owner (implement protection if needed)

**Example:**
```go

    return fmt.Errorf("failed to remove member: %w", err)
}
```

## Roles and Permissions

### Organization Roles

| Role | Permissions |
|------|-------------|
| **Owner** | Full access, can delete org, manage all members and teams |
| **Admin** | Can manage members and teams, cannot delete org |
| **Member** | Read access, can view org, teams, and members |

### Team Roles

| Role | Permissions |
|------|-------------|
| **Lead** | Can manage team members |
| **Member** | Part of the team |

## Security Considerations

- **Role enforcement**: All mutating operations validate the caller's role before proceeding
- **Owner protection**: Organizations must always have at least one owner
- **Cascading deletes**: Deleting an organization removes all members, teams, and team members
- **Input sanitization**: All inputs (names, slugs) are sanitized before processing
- **Slug uniqueness**: Organization slugs are unique across the platform

## Example Integration

```go
package main

import (
    "context"
    "database/sql"
    "net/http"

    "github.com/go-chi/chi/v5"
    "github.com/theinventorylib/aegis"
    "github.com/theinventorylib/aegis/config"
    "github.com/theinventorylib/aegis/core"
    "github.com/theinventorylib/aegis/plugins"
    "github.com/theinventorylib/aegis/plugins/organizations"
)

func main() {
    ctx := context.Background()
    db, _ := sql.Open("postgres", "postgres://localhost/myapp?sslmode=disable")
    r := chi.NewRouter()

    cfg := config.Default().
        WithDB(db).
        WithRouter(r).
        WithSecret([]byte("your-32-byte-secret-key-here!!!!"))

    a, _ := aegis.New(ctx, cfg)

    // Register organizations plugin
    orgsPlugin := organizations.New(nil, plugins.DialectPostgres)
    a.Use(ctx, orgsPlugin)

    // Mount all routes
    a.MountRoutes("/auth")
    r.Use(a.AuthMiddleware())

    // Custom org-scoped endpoint using programmatic API
    r.Route("/api/orgs/{orgId}", func(r chi.Router) {
        r.Use(func(next http.Handler) http.Handler {
            return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
                orgID := chi.URLParam(r, "orgId")
                user := core.GetUser(r.Context())
                if user == nil {
                    http.Error(w, "Unauthorized", http.StatusUnauthorized)
                    return
                }
                isMember, _ := orgsPlugin.IsOrganizationMember(r.Context(), orgID, user.ID)
                if !isMember {
                    http.Error(w, "Forbidden", http.StatusForbidden)
                    return
                }
                next.ServeHTTP(w, r)
            })
        })
        r.Get("/dashboard", func(w http.ResponseWriter, r *http.Request) {
            orgID := chi.URLParam(r, "orgId")
            members, _ := orgsPlugin.ListOrganizationMembers(r.Context(), orgID)
            teams, _ := orgsPlugin.ListTeams(r.Context(), orgID)

            core.WriteJSON(w, http.StatusOK, &core.Response{
                Success: true,
                Data: map[string]any{
                    "members": members,
                    "teams":   teams,
                },
            })
        })
    })

    http.ListenAndServe(":8080", r)
}
```
