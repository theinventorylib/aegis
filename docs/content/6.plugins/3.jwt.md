The JWT (JSON Web Token) plugin provides stateless authentication using industry-standard JWT tokens with **RSA signing** and database-backed key management.

## Features

- **RSA Signing**: Uses RS256 algorithm with secure key management
- **Key Rotation**: Automatic key rotation with configurable intervals
- **JWKS Endpoint**: Standard `.well-known/jwks.json` endpoint for public key discovery
- **Token Pairing**: Short-lived access tokens + long-lived refresh tokens
- **Revocation**: Redis-backed token blacklist
- **Stateless Verification**: Tokens can be verified by other services using public keys
- **Programmatic API**: Full Go API for token generation, validation, and key management

## Installation

```bash
go get github.com/theinventorylib/aegis/plugins/jwt
```

## Configuration

```go
import (
    "context"
    "time"
    "github.com/theinventorylib/aegis"
    "github.com/theinventorylib/aegis/plugins/jwt"
)

jwtPlugin := jwt.New(&jwt.Config{
    // Issuer identifier (e.g. your domain)
    Issuer: "yourapp.com",

    // Access tokens should be short-lived (security best practice)
    AccessTokenExpiry: 15 * time.Minute,

    // Refresh tokens can be long-lived
    RefreshTokenExpiry: 7 * 24 * time.Hour,

    // Rotate signing keys automatically every 24 hours
    KeyRotationInterval: 24 * time.Hour,

    // RSA Key Size (2048, 3072, or 4096)
    KeySize: 2048,

    // Key retention period (how long to keep old keys for verification)
    KeyRetention: 30 * 24 * time.Hour,
}, nil) // nil store uses default SQL storage (recommended)

// Or use production defaults
jwtPlugin := jwt.New(jwt.DefaultConfig(), nil)

// Register with Aegis
a, _ := aegis.New(ctx, cfg)
a.Use(ctx, jwtPlugin)
a.MountRoutes("/auth")
```

### Configuration Options

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `Issuer` | `string` | `""` | JWT `iss` claim value |
| `AccessTokenExpiry` | `time.Duration` | 15 min | Access token lifetime |
| `RefreshTokenExpiry` | `time.Duration` | 7 days | Refresh token lifetime |
| `KeyRotationInterval` | `time.Duration` | 24 hours | Auto key rotation interval (0=disabled) |
| `KeySize` | `int` | 2048 | RSA key size in bits |
| `Algorithm` | `string` | `"RSA"` | Signing algorithm |
| `KeyRetention` | `time.Duration` | 30 days | How long to keep rotated keys |

## Database Schema

```sql
CREATE TABLE jwk_keys (
    kid VARCHAR(255) PRIMARY KEY,
```

## HTTP Endpoints

### Generate Token Pair

Generate an access + refresh token pair for the authenticated user.

```http
POST /auth/jwt/token
Authorization: Bearer <session_token>
```

**Response (200):**

```json
{
  "success": true,
  "data": {
    "accessToken": "eyJhbGciOiJSUzI1NiIs...",
    "refreshToken": "eyJhbGciOiJSUzI1NiIs...",
    "tokenType": "Bearer",
    "expiresIn": 900
  }
}
```

### Get Access Token Only

Generate only an access token.

```http
POST /auth/jwt/accessToken
Authorization: Bearer <session_token>
```

### Refresh Tokens

Exchange a refresh token for a new token pair. The old refresh token is blacklisted.

```http
POST /auth/jwt/refreshToken
Content-Type: application/json

{
  "refreshToken": "eyJhbGciOiJSUzI1NiIs..."
}
```

**Response (200):**

```json
{
  "success": true,
  "data": {
    "accessToken": "eyJhbGciOiJSUzI1NiIs...",
    "refreshToken": "eyJhbGciOiJSUzI1NiIs...",
    "tokenType": "Bearer",
    "expiresIn": 900
  }
}
```

### Logout (Revoke Tokens)

Blacklist the current token. Requires Redis.

```http
POST /auth/jwt/logout
Authorization: Bearer <jwt_token>
```

### JWKS Endpoint

Get the JSON Web Key Set for token verification by external services.

```http
GET /.well-known/jwks.json
```

**Response (200):**

```json
{
  "keys": [
    {
      "kty": "RSA",
      "kid": "key-abc123",
      "use": "sig",
      "alg": "RS256",
      "n": "...",
      "e": "AQAB"
    }
  ]
}
```

## Programmatic API

All JWT operations are available as Go methods on the plugin instance.

### Getting the Plugin Instance

```go
jwtPlugin, ok := aegis.GetPluginTyped[*jwt.Plugin](a, "jwt")
if !ok {
    log.Fatal("JWT plugin not registered")
}
```

### Token Generation Methods

#### GenerateTokenPair

Generate a complete access + refresh token pair for a user.

```go
func GenerateTokenPair(ctx context.Context, userID string) (*TokenPair, error)
```

**Parameters:**
- `ctx` — Request context
- `userID` — User identifier to encode in the tokens

**Returns:**
- `*TokenPair` — Struct containing `AccessToken`, `RefreshToken`, `TokenType` ("Bearer"), and `ExpiresIn` (seconds)
- `error` — Database errors or key generation errors

**Behavior:**
- Generates RS256-signed access token (default 15min expiry)
- Generates RS256-signed refresh token (default 7 days expiry)
- Uses latest active signing key from database
- Access token contains user_id, token_type, issuer, expiry claims
- Refresh token can be exchanged for new token pair

**Example:**
```go
// After successful login
pair, err := jwtPlugin.GenerateTokenPair(ctx, user.ID)
if err != nil {
    return fmt.Errorf("failed to generate tokens: %w", err)
}

// Return tokens to client
json.NewEncoder(w).Encode(map[string]any{
    "access_token":  pair.AccessToken,
    "refresh_token": pair.RefreshToken,
    "token_type":    pair.TokenType,     // "Bearer"
    "expires_in":    pair.ExpiresIn,     // 900 (15min in seconds)
})

// Client uses: Authorization: Bearer <access_token>
```

**Token structure:**
```json
{
  "iss": "yourapp.com",
  "sub": "user_123",
  "jti": "unique-token-id",
  "iat": 1707123456,
  "exp": 1707124356,
  "token_type": "access",
  "user_id": "user_123"
}
```

#### ValidateToken

Validate a JWT and extract claims, checking blacklist if Redis is configured.

```go
func ValidateToken(ctx context.Context, tokenString string) (*Claims, error)
```

**Parameters:**
- `ctx` — Request context
- `tokenString` — JWT to validate (without "Bearer " prefix)

**Returns:**
- `*Claims` — Decoded claims with `UserID`, `TokenType`, `JTI`, expiry info
- `error` — Invalid signature, expired, blacklisted, or malformed token

**Behavior:**
- Verifies RS256 signature using public keys from database
- Checks token expiration
- Validates issuer matches configuration
- Checks blacklist in Redis (if configured)
- Returns error if any validation fails

**Example:**
```go
// In authentication middleware
token := extractBearerToken(r)
claims, err := jwtPlugin.ValidateToken(ctx, token)
if err != nil {
    http.Error(w, "Invalid token", http.StatusUnauthorized)
    return
}

// Token valid — attach user to context
user, _ := getUserByID(ctx, claims.UserID)
ctx = context.WithValue(ctx, "user", user)
```

**Validation steps:**
1. Parse JWT header to get Key ID (kid)
2. Fetch matching public key from database
3. Verify RS256 signature
4. Check expiration (`exp` claim)
5. Validate issuer (`iss` claim)
6. Check blacklist in Redis (if configured)

#### RefreshTokens

Exchange a refresh token for a new access + refresh token pair.

```go
func RefreshTokens(ctx context.Context, refreshToken string) (*TokenPair, error)
```

**Parameters:**
- `ctx` — Request context
- `refreshToken` — Valid refresh token

**Returns:**
- `*TokenPair` — New token pair with fresh expiry times
- `error` — Invalid/expired refresh token or blacklisting errors

**Behavior:**
- Validates refresh token signature and expiry
- Checks token type is "refresh"
- Generates new access + refresh token pair
- Blacklists old refresh token (if Redis configured)
- New tokens use latest active signing key

**Example:**
```go
// Token refresh endpoint
newPair, err := jwtPlugin.RefreshTokens(ctx, oldRefreshToken)
if err != nil {
    http.Error(w, "Invalid refresh token", http.StatusUnauthorized)
    return
}

// Return new tokens
json.NewEncoder(w).Encode(map[string]any{
    "access_token":  newPair.AccessToken,
    "refresh_token": newPair.RefreshToken,
    "expires_in":    newPair.ExpiresIn,
})
```

**Best practices:**
- Implement refresh token rotation (always issue new refresh token)
- Store refresh token expiry on client
- Refresh proactively before access token expires
- Handle refresh failures by redirecting to login

### Revocation Methods

#### BlacklistToken

Revoke a specific JWT by adding its ID to the blacklist.

```go
func BlacklistToken(ctx context.Context, tokenString string) error
```

**Parameters:**
- `ctx` — Request context
- `tokenString` — JWT to blacklist

**Returns:**
- `error` — Validation errors or Redis errors

**Requirements:**
- **Redis must be configured** — blacklisting stores token ID in Redis with TTL
- Without Redis, method succeeds but token remains valid

**Behavior:**
- Extracts `jti` (JWT ID) claim from token
- Stores `jti` in Redis with TTL = token's remaining lifetime
- Future validation checks blacklist before accepting token

**Example:**
```go
// Logout endpoint
err := jwtPlugin.BlacklistToken(ctx, accessToken)
if err != nil {
    log.Error("Failed to blacklist token", "error", err)
    // Consider: Should logout fail if blacklisting fails?
}

// Also blacklist refresh token
err = jwtPlugin.BlacklistToken(ctx, refreshToken)
```

**Redis key pattern:**
```
jwt:blacklist:<jti>
TTL: time until token expires
```

#### Logout

Alias for `BlacklistToken` with identical behavior.

```go
func Logout(ctx context.Context, tokenString string) error
```

**Use case:** More semantic name for logout flows.

#### LogoutAllSessions

Blacklist all tokens for a specific user.

```go
func LogoutAllSessions(ctx context.Context, userID string) error
```

**Parameters:**
- `ctx` — Request context
- `userID` — User whose tokens to revoke

**Returns:**
- `error` — Redis errors

**Requirements:**
- **Redis must be configured**

**Behavior:**
- Sets a Redis key: `jwt:blacklist:user:<userID>`
- All tokens with matching `user_id` claim are rejected during validation
- TTL set to maximum token lifetime to eventually clean up

**Example:**
```go
// Security incident: revoke all user sessions
err := jwtPlugin.LogoutAllSessions(ctx, "compromised_user_id")
if err != nil {
    return fmt.Errorf("failed to revoke all sessions: %w", err)
}

// Force re-login after password change
err = jwtPlugin.LogoutAllSessions(ctx, user.ID)
```

**Use cases:**
- Password reset/change
- Account compromise response
- Admin-initiated session termination
- Device logout

### Key Management Methods

#### StartKeyRotation

Start automatic key rotation in a background goroutine.

```go
func StartKeyRotation(ctx context.Context)
```

**Parameters:**
- `ctx` — Context for cancellation (rotation stops when context cancelled)

**Behavior:**
- Spawns background goroutine
- Rotates signing keys based on `KeyRotationInterval` config (default: 30 days)
- Keeps old keys for token validation (multi-key support)
- Automatically cleans up expired keys
- Logs rotation events

**Example:**
```go
// Start in main() after Aegis initialization
go jwtPlugin.StartKeyRotation(context.Background())

// With graceful shutdown
ctx, cancel := context.WithCancel(context.Background())
defer cancel()

go jwtPlugin.StartKeyRotation(ctx)

// Rotation stops when main context is cancelled
```

**Key rotation benefits:**
- Forward secrecy: old tokens can't be forged if new key is compromised
- Limits blast radius of key compromise
- Compliance with security standards
- Gradual key migration

#### RotateKeys

Manually trigger key rotation immediately.

```go
func RotateKeys(ctx context.Context) error
```

**Parameters:**
- `ctx` — Request context

**Returns:**
- `error` — Key generation or database errors

**Behavior:**
- Generates new RSA key pair (2048-bit default, 4096-bit configurable)
- Marks current key as inactive (still used for validation)
- Sets new key as active (used for signing new tokens)
- Stores both keys in database

**Example:**
```go
// Manual rotation after key compromise
err := jwtPlugin.RotateKeys(ctx)
if err != nil {
    return fmt.Errorf("emergency key rotation failed: %w", err)
}
log.Warn("JWT signing keys rotated", "reason", "security_incident")

// Scheduled rotation via cron job
if time.Now().Day() == 1 { // First of month
    jwtPlugin.RotateKeys(ctx)
}
```

**Post-rotation:**
- New tokens signed with new key
- Old tokens still validate with old key
- Both keys in JWKS endpoint

#### CleanupExpiredKeys

Remove old keys that are no longer needed for token validation.

```go
func CleanupExpiredKeys(ctx context.Context) error
```

**Parameters:**
- `ctx` — Request context

**Returns:**
- `error` — Database errors

**Behavior:**
- Deletes keys older than longest possible token lifetime
- Keeps all keys created within `RefreshTokenExpiry` window
- Safe to run periodically

**Example:**
```go
// Daily cleanup job
ticker := time.NewTicker(24 * time.Hour)
for range ticker.C {
    err := jwtPlugin.CleanupExpiredKeys(ctx)
    if err != nil {
        log.Error("Key cleanup failed", "error", err)
    }
}

// Manual cleanup
err := jwtPlugin.CleanupExpiredKeys(ctx)
```

**Cleanup criteria:**
- Key created > RefreshTokenExpiry (7 days) ago
- No tokens signed with this key can still be valid

## Token Revocation

Token revocation works by adding the token ID (`jti`) to a Redis blacklist.

> [!IMPORTANT]
> Redis is **required** for token revocation. If Redis is not configured, the `/logout` endpoint will succeed but tokens will not be blacklisted. Configure Redis via `config.Default().WithRedis(redisClient)`.

## Verifying Tokens in Other Services

Other services can verify tokens without connecting to the Aegis database:

1. Fetch public keys from `https://your-auth-server/.well-known/jwks.json`
2. Parse the JWT header to find the Key ID (`kid`)
3. Find the matching public key in the JWKS
4. Verify the signature (RS256)

### Go Example

```go
import "github.com/lestrrat-go/jwx/v2/jwk"

set, _ := jwk.Fetch(ctx, "https://your-auth-server/.well-known/jwks.json")
token, _ := jwt.ParseString(tokenString, jwt.WithKeySet(set))
```

### Node.js Example

```javascript
const jwksClient = require('jwks-rsa');
const jwt = require('jsonwebtoken');

const client = jwksClient({ jwksUri: 'https://your-auth-server/.well-known/jwks.json' });

function getKey(header, callback) {
  client.getSigningKey(header.kid, (err, key) => {
    callback(null, key.publicKey || key.rsaPublicKey);
  });
}

jwt.verify(token, getKey, { algorithms: ['RS256'] }, (err, decoded) => {
  console.log(decoded);
});
```

## Security Considerations

- **Short-lived access tokens**: Keep `AccessTokenExpiry` short (15 minutes recommended)
- **Key rotation**: Enable automatic key rotation for forward secrecy
- **Redis for revocation**: Token blacklisting requires Redis
- **HTTPS required**: JWTs contain sensitive claims; always use HTTPS
- **Key size**: Use at least 2048-bit RSA keys (4096 for high-security applications)

## Example Integration

```go
package main

import (
    "context"
    "database/sql"
    "net/http"
    "time"

    "github.com/go-chi/chi/v5"
    "github.com/theinventorylib/aegis"
    "github.com/theinventorylib/aegis/config"
    "github.com/theinventorylib/aegis/plugins/jwt"
)

func main() {
    ctx := context.Background()
    db, _ := sql.Open("postgres", "postgres://localhost/myapp?sslmode=disable")
    r := chi.NewRouter()

    cfg := config.Default().
        WithDB(db).
        WithRouter(r).
        WithSecret([]byte("your-32-byte-secret-key-here!!!!"))

    jwtPlugin := jwt.New(&jwt.Config{
        Issuer:              "myapp.com",
        AccessTokenExpiry:   15 * time.Minute,
        RefreshTokenExpiry:  7 * 24 * time.Hour,
        KeyRotationInterval: 24 * time.Hour,
        KeySize:             2048,
    }, nil)

    a, _ := aegis.New(ctx, cfg)
    a.Use(ctx, jwtPlugin)
    a.MountRoutes("/auth")

    // Start automatic key rotation
    jwtPlugin.StartKeyRotation(ctx)

    // Custom endpoint: generate JWT for authenticated user
    r.With(a.RequireAuth()).Post("/api/token", func(w http.ResponseWriter, r *http.Request) {
        user := core.GetUser(r.Context())
        pair, _ := jwtPlugin.GenerateTokenPair(r.Context(), user.ID)

        core.WriteJSON(w, http.StatusOK, &core.Response{
            Success: true,
            Data:    pair,
        })
    })

    http.ListenAndServe(":8080", r)
}
```
