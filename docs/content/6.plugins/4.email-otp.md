# Email OTP Plugin

The Email OTP plugin provides email-based authentication, including one-time password (OTP) verification and traditional email+password authentication.

## Features

- **Email+Password Authentication**: Traditional sign up and sign in with email and password
- **Email Verification**: Send verification codes via email
- **Password Reset**: Secure password reset flow with email verification
- **Customizable Email Templates**: Full control over email content and formatting
- **OTP Management**: Configurable OTP length and expiration times

## Installation

```bash
go get github.com/theinventorylib/aegis/plugins/emailotp
```

## Configuration

```go
import (
    "github.com/theinventorylib/aegis"
    "github.com/theinventorylib/aegis/plugins/emailotp"
    "time"
)

// Create email plugin with custom configuration
emailPlugin := emailotp.New(&emailotp.Config{
    SendEmail: func(to, subject, body string) error {
        // Integrate with your email provider
        // (SendGrid, Mailgun, SMTP, etc.)
        return mailer.Send(to, subject, body)
    },
    OTPLength:     6,
    OTPExpiration: 10 * time.Minute,
})

// Register with Aegis
auth.Use(ctx, emailPlugin)
```

## Database Schema

The Email OTP plugin uses the core `verification` table for managing OTP codes. No additional tables are required.

## HTTP Endpoints

### Sign Up with Email+Password

Create a new user account with email and password.

```http
POST /auth/email/signup
Content-Type: application/json

{
  "email": "user@example.com",
  "password": "SecurePassword123!",
  "name": "John Doe"
}
```

### Sign In with Email+Password

Authenticate an existing user with email and password.

```http
POST /auth/email/signin
Content-Type: application/json

{
  "email": "user@example.com",
  "password": "SecurePassword123!"
}
```

### Send Verification Email

Send a verification code to the user's email address.

```http
POST /auth/email/send-verification
Content-Type: application/json

{
  "email": "user@example.com"
}
```

### Verify Email

Verify the user's email with the code sent.

```http
POST /auth/email/verify
Content-Type: application/json

{
  "email": "user@example.com",
  "code": "123456"
}
```

## Security Considerations

- Passwords are hashed using **Argon2id** (OWASP-compliant parameters)
- OTP codes are stored securely in the database with expiration times
- Email verification prevents unauthorized account creation
- Rate limiting should be applied to prevent abuse

## Example Integration

```go
package main

import (
    "context"
    "database/sql"
    "log"
    
    "github.com/theinventorylib/aegis"
    "github.com/theinventorylib/aegis/plugins/emailotp"
)

func main() {
    ctx := context.Background()
    db, _ := sql.Open("postgres", "postgres://localhost/myapp")
    
    // Configure email plugin
    emailPlugin := emailotp.New(&emailotp.Config{
        SendEmail: func(to, subject, body string) error {
            log.Printf("Sending email to %s: %s", to, subject)
            return nil // Replace with actual email sending
        },
        OTPLength:     6,
        OTPExpiration: 10 * time.Minute,
    })
    
    // Initialize Aegis
    auth := aegis.New(ctx, config.Default().WithDB(db))
    auth.Use(ctx, emailPlugin)
}
```
