# OAuth Plugin

The OAuth plugin enables social login authentication with popular OAuth 2.0 providers like Google, GitHub, Facebook, Discord, and more.

## Features

- **Multiple Providers**: Support for Google, GitHub, Facebook, Twitter, Microsoft, Apple, Discord
- **Custom Providers**: Easy integration with any OAuth 2.0 / OpenID Connect compliant provider
- **Automatic Account Linking**: Links OAuth accounts to existing users by email
- **Profile Sync**: Automatically syncs profile information from OAuth providers
- **Token Management**: Securely stores and refreshes OAuth tokens
- **PKCE Support**: Proof Key for Code Exchange for enhanced security
- **Programmatic API**: Full Go API for OAuth flow management and account linking

## Installation

```bash
go get github.com/theinventorylib/aegis/plugins/oauth
```

## Configuration

```go
import (
    "context"
    "os"
    "github.com/theinventorylib/aegis"
    "github.com/theinventorylib/aegis/plugins/oauth"
)

oauthPlugin := oauth.New(&oauth.Config{
    Providers: []oauth.ProviderConfig{
        {
            ProviderID:   "google",
            ProviderType: "google",
            ClientID:     os.Getenv("GOOGLE_CLIENT_ID"),
            ClientSecret: os.Getenv("GOOGLE_CLIENT_SECRET"),
            RedirectURI:  "https://yourapp.com/auth/oauth/google/callback",
            Scopes:       []string{"email", "profile"},
        },
        {
            ProviderID:   "github",
            ProviderType: "github",
            ClientID:     os.Getenv("GITHUB_CLIENT_ID"),
            ClientSecret: os.Getenv("GITHUB_CLIENT_SECRET"),
            RedirectURI:  "https://yourapp.com/auth/oauth/github/callback",
            Scopes:       []string{"user:email"},
        },
    },
    CallbackURL: "https://yourapp.com/auth",
})

// Register with Aegis
a, _ := aegis.New(ctx, cfg)
a.Use(ctx, oauthPlugin)
a.MountRoutes("/auth")
```

### Provider Configuration Options

| Option | Type | Required | Description |
|--------|------|----------|-------------|
| `ProviderID` | `string` | Yes | Unique identifier for this provider |
| `ProviderType` | `string` | Yes | Provider type (e.g., "google", "github", "custom") |
| `ClientID` | `string` | Yes | OAuth client ID |
| `ClientSecret` | `string` | Yes | OAuth client secret |
| `RedirectURI` | `string` | No | Custom callback URL (overrides global `CallbackURL`) |
| `Scopes` | `[]string` | Yes | OAuth scopes to request |
| `AuthURL` | `string` | No | Custom authorization URL (for custom providers) |
| `TokenURL` | `string` | No | Custom token URL (for custom providers) |
| `UserInfoURL` | `string` | No | Custom user info URL (for custom providers) |
| `DiscoveryURL` | `string` | No | OpenID Connect discovery URL |
| `PKCE` | `bool` | No | Enable PKCE (recommended) |
| `DisableSignUp` | `bool` | No | Disable automatic account creation |
| `OverrideUserInfo` | `bool` | No | Override user info on each login |
| `GetUserInfo` | `func` | No | Custom function to fetch user info |
| `MapProfile` | `func` | No | Custom function to map provider profile to user |

## Database Schema

OAuth data is stored in the core `accounts` table:

| Column | Type | Description |
|--------|------|-------------|
| `provider` | VARCHAR | OAuth provider name (e.g., "google") |
| `provider_account_id` | VARCHAR | User's ID from the provider |
| `access_token` | TEXT | Encrypted OAuth access token |
| `refresh_token` | TEXT | Encrypted OAuth refresh token |
| `expires_at` | TIMESTAMP | Token expiration time |

## HTTP Endpoints

### Begin OAuth Flow

Redirect users to the OAuth provider's authorization page.

```http
GET /auth/oauth/:provider
```

**Example:**

```http
GET /auth/oauth/google
```

This redirects the user to Google's login page with the configured scopes and callback URL.

### OAuth Callback

Handle the provider's callback after user authorization.

```http
GET /auth/oauth/:provider/callback?code=...&state=...
```

After successful authentication, the user is redirected to your application with a session cookie or token.

### Link OAuth Account

Link an additional OAuth provider to an existing authenticated user.

```http
POST /auth/oauth/link
Authorization: Bearer <token>
Content-Type: application/json

{
  "provider": "github"
}
```

### Logout

Clear OAuth session state.

```http
POST /auth/oauth/logout
```

## Programmatic API

All OAuth operations are available as Go methods on the plugin instance.

### Getting the Plugin Instance

```go
oauthPlugin, ok := aegis.GetPluginTyped[*oauth.Plugin](a, "oauth")
if !ok {
    log.Fatal("OAuth plugin not registered")

```

### Authentication Flow Methods

#### BeginAuth

Initialize an OAuth authentication flow with a provider.

```go
func BeginAuth(w http.ResponseWriter, r *http.Request, providerID string) (string, error)
```

**Parameters:**
- `w` — Response writer (for setting state cookie)
- `r` — HTTP request
- `providerID` — Provider identifier (e.g., "google", "github", "facebook")

**Returns:**
- `string` — Authorization URL to redirect the user to
- `error` — Provider not configured or state generation errors

**Behavior:**
- Generates cryptographically secure state token (prevents CSRF)
- Stores state in encrypted cookie with 10-minute expiration
- Constructs OAuth authorization URL with configured scopes
- Includes PKCE challenge if provider supports it

**Example:**
```go
// OAuth login handler
func handleOAuthLogin(w http.ResponseWriter, r *http.Request) {
    provider := chi.URLParam(r, "provider") // e.g., "google"
    
    authURL, err := oauthPlugin.BeginAuth(w, r, provider)
    if err != nil {
        http.Error(w, "OAuth init failed", http.StatusBadRequest)
        return
    }
    
    // Redirect user to provider's consent screen
    http.Redirect(w, r, authURL, http.StatusFound)
}

// Route: GET /auth/oauth/{provider}
```

**State cookie:**
- Name: `oauth_state_{providerID}`
- Encrypted with AES-256
- HTTPOnly, Secure, SameSite=Lax
- Expires: 10 minutes

**Authorization URL includes:**
- `client_id` — Your app's OAuth client ID
- `redirect_uri` — Callback URL to your app
- `state` — CSRF protection token
- `scope` — Requested permissions (email, profile, etc.)
- `code_challenge` — PKCE challenge (if enabled)

#### CompleteAuth

Complete the OAuth callback flow — exchange code for token, create/link user account.

```go
func CompleteAuth(w http.ResponseWriter, r *http.Request, providerID string) (*auth.User, *core.Session, error)
```

**Parameters:**
- `w` — Response writer (for clearing state cookie, setting session cookie)
- `r` — HTTP request with `code` and `state` query parameters
- `providerID` — Provider identifier matching BeginAuth call

**Returns:**
- `*auth.User` — Created or existing user account
- `*core.Session` — New session token
- `error` — State mismatch, code exchange failure, or user creation errors

**Behavior:**
1. Validates state matches cookie (CSRF protection)
2. Exchanges authorization code for access token
3. Fetches user profile from provider's API
4. Creates new user OR links to existing user (by email)
5. Creates session and sets session cookie
6. Stores OAuth tokens (encrypted) in database
7. Clears OAuth state cookie

**Example:**
```go
// OAuth callback handler
func handleOAuthCallback(w http.ResponseWriter, r *http.Request) {
    provider := chi.URLParam(r, "provider")
    
    user, session, err := oauthPlugin.CompleteAuth(w, r, provider)
    if err != nil {
        http.Redirect(w, r, "/login?error=oauth_failed", http.StatusFound)
        return
    }
    
    // Session cookie already set by CompleteAuth
    log.Info("OAuth login successful", "user", user.ID, "provider", provider)
    
    // Redirect to app
    http.Redirect(w, r, "/dashboard", http.StatusFound)
}

// Route: GET /auth/oauth/{provider}/callback
```

**Account linking logic:**
- If email exists: Link OAuth account to existing user
- If email new: Create new user account
- Multiple OAuth providers can link to same user

**User creation:**
- `name` from OAuth profile
- `email` from OAuth profile (verified if provider confirms)
- `image` from OAuth profile picture URL
- Auto-generated user ID

### Account Management Methods

#### LinkAccount

Link an OAuth provider to an already-authenticated user.

```go
func LinkAccount(ctx context.Context, userID string, providerID string) error
```

**Parameters:**
- `ctx` — Request context (should contain OAuth callback data)
- `userID` — User to link the account to
- `providerID` — Provider to link (e.g., "github")

**Returns:**
- `error` — Provider already linked, OAuth flow errors, or database errors

**Behavior:**
- User must be authenticated with session
- Initiates OAuth flow specifically for account linking
- After callback, associates OAuth account with user ID
- Prevents duplicate links (one provider per user)
- Updates user's `connections` list

**Example:**
```go
// Link GitHub to existing user
func handleLinkAccount(w http.ResponseWriter, r *http.Request) {
    user, _ := core.GetUser(r.Context())
    
    provider := r.URL.Query().Get("provider") // "github"
    
    err := oauthPlugin.LinkAccount(r.Context(), user.ID, provider)
    if err != nil {
        http.Error(w, "Link failed: "+err.Error(), http.StatusBadRequest)
        return
    }
    
    w.Write([]byte("Account linked successfully"))
}

// POST /auth/oauth/link?provider=github
```

**Use cases:**
- Allow users to sign in with multiple providers
- Backup authentication method
- Cross-platform account unification
- Social features (show connected accounts)

#### GetUserConnections

Retrieve all OAuth provider connections for a user.

```go
func GetUserConnections(ctx context.Context, userID string) ([]Connection, error)
```

**Parameters:**
- `ctx` — Request context
- `userID` — User whose connections to fetch

**Returns:**
- `[]Connection` — List of OAuth connections
- `error` — Database errors

**Connection structure:**
```go
type Connection struct {
    ProviderID        string    // "google", "github"
    ProviderAccountID string    // User's ID at the provider
    Email             string    // Email from provider
    Name              string    // Display name from provider
    Image             string    // Profile picture URL
    AccessToken       string    // Encrypted OAuth access token
    RefreshToken      string    // Encrypted OAuth refresh token
    ExpiresAt         time.Time // Token expiration
    CreatedAt         time.Time // First linked
    UpdatedAt         time.Time // Last token refresh
}
```

**Example:**
```go
// Show user's connected accounts
func handleAccountSettings(w http.ResponseWriter, r *http.Request) {
    user, _ := core.GetUser(r.Context())
    
    connections, err := oauthPlugin.GetUserConnections(r.Context(), user.ID)
    if err != nil {
        http.Error(w, "Failed to fetch connections", http.StatusInternalServerError)
        return
    }
    
    // Build response
    type ConnectedAccount struct {
        Provider string `json:"provider"`
        Email    string `json:"email"`
        LinkedAt string `json:"linked_at"`
    }
    
    var accounts []ConnectedAccount
    for _, conn := range connections {
        accounts = append(accounts, ConnectedAccount{
            Provider: conn.ProviderID,
            Email:    conn.Email,
            LinkedAt: conn.CreatedAt.Format(time.RFC3339),
        })
    }
    
    json.NewEncoder(w).Encode(accounts)
}
```

**Use cases:**
- Account settings page (show linked providers)
- Allow unlinking providers
- Display provider-specific data (profile pictures)
- Check if user can safely remove a provider (has other auth method)

#### UnlinkAccount

Remove an OAuth provider connection from a user's account.

```go
func UnlinkAccount(ctx context.Context, userID string, providerID string) error
```

**Parameters:**
- `ctx` — Request context
- `userID` — User whose connection to remove
- `providerID` — Provider to unlink (e.g., "github")

**Returns:**
- `error` — Connection not found or database errors

**Behavior:**
- Deletes OAuth connection from database
- Removes provider from user's `connections` list
- **Warning:** Doesn't prevent re-unlinking if it's the last auth method

**Example:**
```go
// Unlink GitHub from user account
func handleUnlinkAccount(w http.ResponseWriter, r *http.Request) {
    user, _ := core.GetUser(r.Context())
    provider := r.URL.Query().Get("provider")
    
    // Safety check: ensure user has other auth methods
    connections, _ := oauthPlugin.GetUserConnections(r.Context(), user.ID)
    hasPassword := user.PasswordHash != ""
    if len(connections) == 1 && !hasPassword {
        http.Error(w, "Cannot unlink last authentication method", http.StatusBadRequest)
        return
    }
    
    err := oauthPlugin.UnlinkAccount(r.Context(), user.ID, provider)
    if err != nil {
        http.Error(w, "Unlink failed", http.StatusBadRequest)
        return
    }
    
    w.Write([]byte("Account unlinked"))
}
```

**Best practices:**
- Always check user has alternative auth before unlinking
- Log unlink events for security audit
- Notify user via email when account is unlinked
- Consider grace period or confirmation flow

#### GetStateStore

Access the underlying OAuth state store for custom flows.

```go
func GetStateStore() StateStore
```

**Returns:**
- `StateStore` — Interface for storing/retrieving OAuth state

**StateStore interface:**
```go
type StateStore interface {
    Set(ctx context.Context, state string, data StateData) error
    Get(ctx context.Context, state string) (StateData, error)
    Delete(ctx context.Context, state string) error
}

type StateData struct {
    ProviderID   string
    RedirectURI  string
    CodeVerifier string // For PKCE
    UserID       string // For account linking
    CreatedAt    time.Time
}
```

**Use cases:**
- Custom OAuth flows beyond standard login/signup
- Implementing OAuth for non-user entities (organizations, bots)
- Advanced state management (custom CSRF tokens)
- Debugging OAuth flow issues

**Example:**
```go
// Custom OAuth flow with additional state
stateStore := oauthPlugin.GetStateStore()

// Generate custom state
state := generateSecureRandomString(32)
err := stateStore.Set(ctx, state, oauth.StateData{
    ProviderID:  "google",
    RedirectURI: "/custom/callback",
    UserID:      "linking_to_user_123", // For account linking
    CreatedAt:   time.Now(),
})

// Later in callback
stateData, err := stateStore.Get(ctx, r.URL.Query().Get("state"))
// Use stateData.UserID to link account
```

## Account Linking

OAuth accounts are automatically linked to existing users based on email address. If a user signs in with Google and later with GitHub using the same email, both OAuth accounts are linked to the same user.

## Security Considerations

- OAuth tokens are encrypted before storage
- State parameter prevents CSRF attacks
- Redirect URLs are validated against configuration
- Tokens are refreshed automatically when expired
- PKCE support for enhanced security (recommended for all providers)

## Example Integration

```go
package main

import (
    "context"
    "database/sql"
    "net/http"
    "os"

    "github.com/go-chi/chi/v5"
    "github.com/theinventorylib/aegis"
    "github.com/theinventorylib/aegis/config"
    "github.com/theinventorylib/aegis/plugins/oauth"
)

func main() {
    ctx := context.Background()
    db, _ := sql.Open("postgres", "postgres://localhost/myapp?sslmode=disable")
    r := chi.NewRouter()

    cfg := config.Default().
        WithDB(db).
        WithRouter(r).
        WithSecret([]byte("your-32-byte-secret-key-here!!!!"))

    oauthPlugin := oauth.New(&oauth.Config{
        Providers: []oauth.ProviderConfig{
            {
                ProviderID:   "google",
                ProviderType: "google",
                ClientID:     os.Getenv("GOOGLE_CLIENT_ID"),
                ClientSecret: os.Getenv("GOOGLE_CLIENT_SECRET"),
                RedirectURI:  "http://localhost:8080/auth/oauth/google/callback",
                Scopes:       []string{"email", "profile"},
            },
        },
        CallbackURL: "http://localhost:8080/auth",
    })

    a, _ := aegis.New(ctx, cfg)
    a.Use(ctx, oauthPlugin)
    a.MountRoutes("/auth")

    // Custom: list user's connected accounts
    r.With(a.RequireAuth()).Get("/api/connections", func(w http.ResponseWriter, r *http.Request) {
        user := core.GetUser(r.Context())
        connections, _ := oauthPlugin.GetUserConnections(r.Context(), user.ID)

        core.WriteJSON(w, http.StatusOK, &core.Response{
            Success: true,
            Data:    connections,
        })
    })

    http.ListenAndServe(":8080", r)
}
```
