The OpenAPI plugin automatically generates interactive API documentation for your Aegis authentication endpoints using the OpenAPI 3.0 specification.

## Features

- **Auto-Generated Spec**: Automatic OpenAPI 3.0 specification from all registered plugins
- **Interactive UI**: Beautiful documentation UI with Scalar
- **Try It Out**: Test endpoints directly from the documentation
- **Plugin Discovery**: Automatically includes routes from all registered plugins
- **Custom Endpoints**: Add your own endpoints to the documentation
- **Programmatic API**: Full Go API for spec customization, schema registration, and endpoint management

## Installation

```bash
go get github.com/theinventorylib/aegis/plugins/openapi
```

## Configuration

```go
import (
    "context"
    "github.com/theinventorylib/aegis"
    "github.com/theinventorylib/aegis/plugins/openapi"
)

openapiPlugin := openapi.New(&openapi.Config{
    Title:       "My App Authentication API",
    Version:     "1.0.0",
    Description: "Authentication endpoints for My App",
    EnableDocs:  true,       // Enable /docs UI
    BasePath:    "/auth",    // API base path
})

// Register with Aegis
a, _ := aegis.New(ctx, cfg)
a.Use(ctx, openapiPlugin)
a.MountRoutes("/auth")
```

### Configuration Options

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `Title` | `string` | `"Aegis Authentication API"` | API documentation title |
| `Version` | `string` | `"1.0.0"` | API version |
| `Description` | `string` | (auto) | API description |
| `Servers` | `[]Server` | localhost:8080 | Server list |
| `Contact` | `*Contact` | nil | Contact info |
| `License` | `License` | MIT | License info |
| `EnableDocs` | `bool` | `true` | Enable Scalar docs UI |
| `BasePath` | `string` | `"/auth"` | API base path |

## HTTP Endpoints

### Documentation UI

Access the interactive Scalar documentation interface.

```http
GET /auth/docs
```

Serves the Scalar UI where users can explore and test all API endpoints.

### OpenAPI Specification

Download the OpenAPI 3.0 specification in JSON format.

```http
GET /auth/openapi.json
```

**Response (200):**

```json
{
  "openapi": "3.0.0",
  "info": {
    "title": "My App Authentication API",
    "version": "1.0.0"
  },
  "paths": {
    "/auth/email/signup": { ... },
    "/auth/email/signin": { ... }
  }
}
```

## Programmatic API

All OpenAPI operations are available as Go methods on the plugin instance.

### Getting the Plugin Instance

```go
openapiPlugin, ok := aegis.GetPluginTyped[*openapi.Plugin](a, "openapi")
if !ok {
    log.Fatal("OpenAPI plugin not registered")
}
```

### Spec Management Methods

#### UpdateSpec

Batch-update the OpenAPI spec from route metadata — used during initialization.

```go
func UpdateSpec(routes []RouteMetadata)
```

**Parameters:**
- `routes` — Array of route metadata to document

**Behavior:**
- Processes all route metadata at once
- Generates OpenAPI paths, schemas, security requirements
- Merges with existing spec (doesn't overwrite manual additions)
- Called automatically during Aegis initialization
- Idempotent: safe to call multiple times

**Example:**
```go
// Typically called automatically by Aegis during init
// Manual call for dynamic route registration:
routes := []openapi.RouteMetadata{
    {
        Path:    "/api/users",
        Method:  "GET",
        Summary: "List users",
        Tags:    []string{"Users"},
        Auth:    true,
    },
    {
        Path:    "/api/users/{id}",
        Method:  "GET",
        Summary: "Get user by ID",
        Tags:    []string{"Users"},
        Auth:    true,
    },
}

openapiPlugin.UpdateSpec(routes)
```

**Use cases:**
- Documenting dynamically registered routes
- Plugin initialization (plugins call this to register their routes)
- Testing spec generation

#### GetSpec

Retrieve the current OpenAPI specification.

```go
func GetSpec() *Spec
```

**Returns:**
- `*Spec` — OpenAPI 3.0 specification struct

**Spec structure:**
```go
type Spec struct {
    OpenAPI      string                 `json:"openapi"`       // "3.0.0"
    Info         Info                   `json:"info"`
    Servers      []Server               `json:"servers"`
    Paths        map[string]PathItem    `json:"paths"`
    Components   Components             `json:"components"`
    Security     []SecurityRequirement  `json:"security"`
    Tags         []Tag                  `json:"tags"`
}
```

**Example:**
```go
// Serve spec as JSON endpoint
func handleOpenAPISpec(w http.ResponseWriter, r *http.Request) {
    spec := openapiPlugin.GetSpec()
    
    w.Header().Set("Content-Type", "application/json")
    json.NewEncoder(w).Encode(spec)
}

// Customize spec metadata
spec := openapiPlugin.GetSpec()
spec.Info.Version = "2.0.0"
spec.Info.Contact = &Contact{
    Name:  "API Support",
    Email: "support@example.com",
}

// Export spec to file
specJSON, _ := json.MarshalIndent(spec, "", "  ")
os.WriteFile("openapi.json", specJSON, 0644)
```

**Use cases:**
- Serve spec at `/openapi.json` endpoint
- Generate client SDKs (use with OpenAPI Generator)
- API documentation tools (Swagger UI, Redoc)
- Contract testing
- Export for external tools

### Registration Methods

#### RegisterEndpoint

Add a custom endpoint to the OpenAPI specification.

```go
func RegisterEndpoint(config EndpointConfig)
```

**Parameters:**
- `config` — Endpoint configuration with path, method, metadata, schemas

**EndpointConfig structure:**
```go
type EndpointConfig struct {
    Path        string           // "/api/profile"
    Method      string           // "GET", "POST", etc.
    Summary     string           // Short description
    Description string           // Detailed description
    Tags        []string         // Grouping tags
    Auth        bool             // Requires authentication
    Parameters  []Parameter      // Path/query/header params
    RequestBody RequestBody      // Request body schema
    Response    ResponseConfig   // Success response
    Responses   map[int]Response // All possible responses
}
```

**Example:**
```go
// Document a custom API endpoint
openapiPlugin.RegisterEndpoint(openapi.EndpointConfig{
    Path:        "/api/profile",
    Method:      "GET",
    Summary:     "Get user profile",
    Description: "Retrieve the authenticated user's profile information",
    Tags:        []string{"Profile"},
    Auth:        true, // Adds Bearer token security requirement
    Parameters: []openapi.Parameter{
        {
            Name:        "include",
            In:          "query",
            Description: "Additional fields to include (e.g., 'connections,settings')",
            Required:    false,
            Schema:      map[string]interface{}{"type": "string"},
        },
    },
    Response: openapi.ResponseConfig{
        StatusCode:  200,
        Description: "User profile retrieved successfully",
        Schema: map[string]interface{}{
            "$ref": "#/components/schemas/UserProfile",
        },
    },
    Responses: map[int]openapi.Response{
        401: {Description: "Unauthorized"},
        500: {Description: "Internal server error"},
    },
})
```

**Use cases:**
- Document custom business logic endpoints
- Override auto-generated documentation
- Add detailed descriptions and examples
- Document non-CRUD operations

#### RegisterSchema

Add a reusable schema component to the spec.

```go
func RegisterSchema(name string, schema map[string]interface{})
```

**Parameters:**
- `name` — Schema identifier (referenced as `#/components/schemas/{name}`)
- `schema` — JSON Schema object

**Behavior:**
- Adds schema to `components.schemas` section
- Other endpoints can reference via `$ref: "#/components/schemas/{name}"`
- Supports nested schemas, arrays, validation rules

**Example:**
```go
// Register a user profile schema
openapiPlugin.RegisterSchema("UserProfile", map[string]interface{}{
    "type": "object",
    "required": []string{"id", "email"},
    "properties": map[string]interface{}{
        "id": map[string]interface{}{
            "type":        "string",
            "description": "Unique user identifier",
            "example":     "user_abc123",
        },
        "email": map[string]interface{}{
            "type":        "string",
            "format":      "email",
            "description": "User email address",
        },
        "name": map[string]interface{}{
            "type":        "string",
            "description": "Display name",
        },
        "connections": map[string]interface{}{
            "type":        "array",
            "description": "Linked OAuth providers",
            "items": map[string]interface{}{
                "type": "string",
                "enum": []string{"google", "github", "facebook"},
            },
        },
    },
})

// Reference in endpoint
openapiPlugin.RegisterEndpoint(openapi.EndpointConfig{
    Path:   "/api/profile",
    Method: "GET",
    Response: openapi.ResponseConfig{
        Schema: map[string]interface{}{
            "$ref": "#/components/schemas/UserProfile",
        },
    },
})
```

**Schema features:**
- `type`: "string", "number", "boolean", "object", "array"
- `format`: "email", "date-time", "uuid", "uri"
- `required`: Array of required property names
- `enum`: Allowed values
- `pattern`: Regex validation
- `minimum`, `maximum`: Number constraints
- `minLength`, `maxLength`: String length

#### RegisterSchemaFromType

Auto-generate an OpenAPI schema from a Go struct type.

```go
func RegisterSchemaFromType(name string, example interface{})
```

**Parameters:**
- `name` — Schema identifier
- `example` — Instance of Go struct to introspect

**Behavior:**
- Uses reflection to analyze struct fields
- Respects `json` struct tags for field names
- Infers OpenAPI types from Go types
- Supports nested structs and slices
- Adds validation from struct tags (if using validation library)

**Example:**
```go
// Define Go struct
type UserProfile struct {
    ID          string   `json:"id"`
    Email       string   `json:"email"`
    Name        string   `json:"name,omitempty"`
    Connections []string `json:"connections"`
    CreatedAt   string   `json:"created_at"`
}

// Auto-generate schema
openapiPlugin.RegisterSchemaFromType("UserProfile", UserProfile{})

// Generated schema:
// {
//   "type": "object",
//   "properties": {
//     "id": {"type": "string"},
//     "email": {"type": "string"},
//     "name": {"type": "string"},
//     "connections": {"type": "array", "items": {"type": "string"}},
//     "created_at": {"type": "string"}
//   }
// }
```

**Type mappings:**
- `string` → `{"type": "string"}`
- `int`, `int64` → `{"type": "integer"}`
- `float64` → `{"type": "number"}`
- `bool` → `{"type": "boolean"}`
- `[]T` → `{"type": "array", "items": {...}}`
- `struct` → `{"type": "object", "properties": {...}}`
- `time.Time` → `{"type": "string", "format": "date-time"}`

**Benefits:**
- Keeps schemas in sync with Go code
- Less boilerplate than manual schema definition
- Type-safe schema generation
- Works with existing struct definitions

#### RegisterSecurityScheme

Add a custom security scheme to the specification.

```go
func RegisterSecurityScheme(name string, scheme map[string]interface{})
```

**Parameters:**
- `name` — Security scheme identifier
- `scheme` — OpenAPI security scheme object

**Behavior:**
- Adds to `components.securitySchemes`
- Referenced in endpoint security requirements
- Supports: apiKey, http, oauth2, openIdConnect

**Example:**
```go
// API key in header
openapiPlugin.RegisterSecurityScheme("ApiKey", map[string]interface{}{
    "type": "apiKey",
    "in":   "header",
    "name": "X-API-Key",
    "description": "API key for service-to-service authentication",
})

// Basic authentication
openapiPlugin.RegisterSecurityScheme("BasicAuth", map[string]interface{}{
    "type":   "http",
    "scheme": "basic",
})

// OAuth2
openapiPlugin.RegisterSecurityScheme("OAuth2", map[string]interface{}{
    "type": "oauth2",
    "flows": map[string]interface{}{
        "authorizationCode": map[string]interface{}{
            "authorizationUrl": "https://example.com/oauth/authorize",
            "tokenUrl":         "https://example.com/oauth/token",
            "scopes": map[string]string{
                "read:users":  "Read user data",
                "write:users": "Modify user data",
            },
        },
    },
})

// Use in endpoint
openapiPlugin.RegisterEndpoint(openapi.EndpointConfig{
    Path:   "/api/admin/users",
    Method: "GET",
    Security: []map[string][]string{
        {"ApiKey": []string{}},
    },
})
```

**Security scheme types:**
- `apiKey`: API key in header/query/cookie
- `http`: HTTP auth (basic, bearer)
- `oauth2`: OAuth 2.0 flows
- `openIdConnect`: OpenID Connect discovery

#### RegisterTag

Add a tag for grouping operations in documentation.

```go
func RegisterTag(name string, description string)
```

**Parameters:**
- `name` — Tag identifier (used in endpoint `tags` array)
- `description` — Tag description (shown in docs)

**Behavior:**
- Adds to `tags` section of spec
- Documentation tools use tags to organize endpoints
- Endpoints reference tags to indicate grouping

**Example:**
```go
// Register tags
openapiPlugin.RegisterTag("Profile", "User profile management endpoints")
openapiPlugin.RegisterTag("Admin", "Administrative operations (requires admin role)")
openapiPlugin.RegisterTag("Auth", "Authentication and session management")

// Use in endpoints
openapiPlugin.RegisterEndpoint(openapi.EndpointConfig{
    Path:   "/api/profile",
    Method: "GET",
    Tags:   []string{"Profile"}, // Grouped under "Profile" in docs
})
```

**Tag organization in Swagger UI:**
```
├── Auth
│   ├── POST /auth/signup
│   ├── POST /auth/signin
│   └── POST /auth/signout
├── Profile
│   ├── GET /api/profile
│   └── PUT /api/profile
└── Admin
    ├── GET /api/admin/users
    └── DELETE /api/admin/users/{id}
```

#### RegisterRouteMetadata

Register a single route to the OpenAPI spec.

```go
func RegisterRouteMetadata(metadata RouteMetadata)
```

**Parameters:**
- `metadata` — Route metadata with path, method, summary, etc.

**RouteMetadata structure:**
```go
type RouteMetadata struct {
    Path        string
    Method      string
    Summary     string
    Description string
    Tags        []string
    Auth        bool
    Parameters  []Parameter
    RequestBody interface{}
    Responses   map[int]Response
}
```

**Example:**
```go
// Document a health check endpoint
openapiPlugin.RegisterRouteMetadata(openapi.RouteMetadata{
    Path:    "/api/health",
    Method:  "GET",
    Summary: "Health check",
    Description: "Check if the API is running and accessible",
    Tags:    []string{"System"},
    Auth:    false, // Public endpoint
    Responses: map[int]openapi.Response{
        200: {
            Description: "Service is healthy",
            Content: map[string]openapi.MediaType{
                "application/json": {
                    Schema: map[string]interface{}{
                        "type": "object",
                        "properties": map[string]interface{}{
                            "status": map[string]string{"type": "string", "example": "ok"},
                            "timestamp": map[string]string{"type": "string", "format": "date-time"},
                        },
                    },
                },
            },
        },
    },
})
```

**Difference from RegisterEndpoint:**
- `RegisterRouteMetadata`: Simpler, focused on path + method + metadata
- `RegisterEndpoint`: More detailed, includes request/response schemas
- Both ultimately add to the same OpenAPI spec

## Automatic Documentation

The OpenAPI plugin automatically documents:

1. **Core Auth Routes**: Sign up, sign in, sign out, session management
2. **Plugin Routes**: All routes from registered plugins (admin, jwt, emailotp, sms, oauth, organizations)
3. **Request Schemas**: Parameter and body validations
4. **Response Schemas**: Expected response formats
5. **Authentication**: Bearer token and session cookie security schemes

## Security Schemes

The plugin automatically documents authentication methods:

```json
{
  "components": {
    "securitySchemes": {
      "BearerAuth": {
        "type": "http",
        "scheme": "bearer"
      },
      "SessionAuth": {
        "type": "apiKey",
        "in": "cookie",
        "name": "session_token"
      }
    }
  }
}
```

## Example Integration

```go
package main

import (
    "context"
    "database/sql"
    "net/http"

    "github.com/go-chi/chi/v5"
    "github.com/theinventorylib/aegis"
    "github.com/theinventorylib/aegis/config"
    "github.com/theinventorylib/aegis/plugins/openapi"
)

func main() {
    ctx := context.Background()
    db, _ := sql.Open("postgres", "postgres://localhost/myapp?sslmode=disable")
    r := chi.NewRouter()

    cfg := config.Default().
        WithDB(db).
        WithRouter(r).
        WithSecret([]byte("your-32-byte-secret-key-here!!!!"))

    openapiPlugin := openapi.New(&openapi.Config{
        Title:       "My SaaS API",
        Version:     "1.0.0",
        Description: "Authentication and user management API",
        EnableDocs:  true,
    })

    a, _ := aegis.New(ctx, cfg)
    a.Use(ctx, openapiPlugin)
    a.MountRoutes("/auth")

    // Register custom endpoints in the spec
    openapiPlugin.RegisterEndpoint(openapi.EndpointConfig{
        Path:    "/api/dashboard",
        Method:  "GET",
        Summary: "Get dashboard data",
        Tags:    []string{"Dashboard"},
        Auth:    true,
    })

    // Documentation available at http://localhost:8080/auth/docs
    http.ListenAndServe(":8080", r)
}
```
