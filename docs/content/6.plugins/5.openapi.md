The OpenAPI plugin automatically generates interactive API documentation for your Aegis authentication endpoints using the OpenAPI 3.0 specification.

## Features

- **Auto-Generated Spec**: Automatic OpenAPI 3.0 specification from all registered plugins
- **Interactive UI**: Beautiful documentation UI with Scalar
- **Try It Out**: Test endpoints directly from the documentation
- **Plugin Discovery**: Automatically includes routes from all registered plugins
- **Custom Endpoints**: Add your own endpoints to the documentation
- **Programmatic API**: Full Go API for spec customization, schema registration, and endpoint management

## Installation

```bash
go get github.com/theinventorylib/aegis/plugins/openapi
```

## Configuration

```go
import (
    "context"
    "github.com/theinventorylib/aegis"
    "github.com/theinventorylib/aegis/plugins/openapi"
)

openapiPlugin := openapi.New(&openapi.Config{
    Title:       "My App Authentication API",
    Version:     "1.0.0",
    Description: "Authentication endpoints for My App",
    EnableDocs:  true,       // Enable /docs UI
    BasePath:    "/auth",    // API base path
})

// Register with Aegis
a, _ := aegis.New(ctx, cfg)
a.Use(ctx, openapiPlugin)
a.MountRoutes("/auth")
```

### Configuration Options

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `Title` | `string` | `"Aegis Authentication API"` | API documentation title |
| `Version` | `string` | `"1.0.0"` | API version |
| `Description` | `string` | (auto) | API description |
| `Servers` | `[]Server` | localhost:8080 | Server list |
| `Contact` | `*Contact` | nil | Contact info |
| `License` | `License` | MIT | License info |
| `EnableDocs` | `bool` | `true` | Enable Scalar docs UI |
| `BasePath` | `string` | `"/auth"` | API base path |

## HTTP Endpoints

### Documentation UI

Access the interactive Scalar documentation interface.

```http
GET /auth/docs
```

Serves the Scalar UI where users can explore and test all API endpoints.

### OpenAPI Specification

Download the OpenAPI 3.0 specification in JSON format.

```http
GET /auth/openapi.json
```

**Response (200):**

```json
{
  "openapi": "3.0.0",
  "info": {
    "title": "My App Authentication API",
    "version": "1.0.0"
  },
  "paths": {
    "/auth/email/signup": { ... },
    "/auth/email/signin": { ... }
  }
}
```

## Programmatic API

The OpenAPI plugin exposes a single global function, `openapi.Doc`, for registering route documentation anywhere in your codebase — before or after the plugin is initialised.

### Global Queue Pattern

`openapi.Doc` uses a global, thread-safe queue. Routes registered before `openapi.New` is loaded are buffered and automatically applied when the plugin initialises. This means you can document routes inside `MountRoutes`, `init`, or any other place without worrying about call order.

```go
import "github.com/theinventorylib/aegis/plugins/openapi"

openapi.Doc(openapi.Route{
    Method:      "POST",
    Path:        "/auth/login",
    OperationID: "login",
    Summary:     "Authenticate with email and password",
    Tags:        []string{"Auth"},
    Body:        openapi.BodyOf[LoginRequest](),
    Responses: openapi.Responses{
        200: openapi.DataResponseOf[SessionWithUser]("Login successful"),
        401: openapi.TextResponse("Invalid credentials"),
    },
})
```

> [!IMPORTANT]
> The OpenAPI plugin must be registered **last** via `a.Use(ctx, openapi.New(...))`, after all other plugins. This ensures the pending queue is drained only after all routes are documented.

### Route Struct

```go
type Route struct {
    Method      string      // HTTP method: "GET", "POST", "PUT", "PATCH", "DELETE"
    Path        string      // Full path, e.g. "/auth/login"
    OperationID string      // Unique operation identifier
    Summary     string      // Short description shown in the docs UI
    Description string      // Longer description (supports Markdown)
    Tags        []string    // Groups the operation in the docs sidebar
    Auth        bool        // true adds Bearer token security requirement
    Deprecated  bool        // Marks the route as deprecated
    Params      []Param     // Path, query, header, or cookie parameters
    Body        *BodySchema // Request body (nil for GET / DELETE)
    Responses   Responses   // map[int]ResponseDef
}
```

### Parameters

Use `Param` to describe path variables, query strings, headers, or cookies:

```go
Params: []openapi.Param{
    {Name: "id",     In: "path",  Description: "User ID",          Required: true,  Type: "string"},
    {Name: "limit",  In: "query", Description: "Page size",         Required: false, Type: "integer"},
    {Name: "cursor", In: "query", Description: "Pagination cursor", Required: false, Type: "string"},
},
```

`In` accepts `"path"`, `"query"`, `"header"`, or `"cookie"`. Path parameters always have `Required` forced to `true`.

### Request Body Helpers

| Function | Description |
|----------|-------------|
| `BodyOf[T]()` | Generates a schema from Go struct `T` via reflection; registers the type under `components/schemas` |
| `RefBody(name)` | References an existing named schema in `components/schemas` |

```go
Body: openapi.BodyOf[CreateUserRequest](),
// or
Body: openapi.RefBody("LoginRequest"),
```

### Response Helpers

| Function | Description |
|----------|-------------|
| `ResponseOf[T](desc)` | Plain schema generated from Go struct `T` |
| `DataResponseOf[T](desc)` | Wraps `T` in the `{ success, message, data }` core envelope |
| `PaginatedResponseOf[T](desc)` | Plain schema from `T` — use when `T` is already the paginated envelope |
| `RefResponse(desc, name)` | References a named schema; plain (no envelope) |
| `DataRefResponse(desc, name)` | References a named schema wrapped in the data envelope |
| `TextResponse(desc)` | Description-only response with no body schema |

```go
Responses: openapi.Responses{
    200: openapi.DataResponseOf[auth.Session]("Session created"),
    400: openapi.TextResponse("Validation error"),
    401: openapi.RefResponse("Not authenticated", "Error"),
},
```

### Protected Routes

Set `Auth: true` to add a Bearer token security requirement to the generated operation:

```go
openapi.Doc(openapi.Route{
    Method:  "GET",
    Path:    "/auth/session",
    Summary: "Get current session",
    Auth:    true,
    Responses: openapi.Responses{
        200: openapi.DataResponseOf[auth.Session]("Current session"),
        401: openapi.TextResponse("Not authenticated"),
    },
})
```

## Automatic Documentation

All built-in Aegis routes and registered plugin routes are documented automatically via `openapi.Doc` calls inside each plugin's `MountRoutes`. You do not need to manually register core auth endpoints — they appear in the spec once the plugin initialises.

Plugins included automatically:
- Core auth routes (login, signup, logout, session management)
- Admin plugin routes
- JWT plugin routes
- Email OTP plugin routes
- SMS OTP plugin routes
- OAuth plugin routes
- Organizations plugin routes

## Security Schemes

The plugin automatically defines authentication schemes in the spec:

```json
{
  "components": {
    "securitySchemes": {
      "BearerAuth": {
        "type": "http",
        "scheme": "bearer"
      },
      "SessionAuth": {
        "type": "apiKey",
        "in": "cookie",
        "name": "aegis_session"
      }
    }
  }
}
```

## Full Example

```go
package main

import (
    "context"
    "database/sql"
    "net/http"

    "github.com/go-chi/chi/v5"
    "github.com/theinventorylib/aegis"
    "github.com/theinventorylib/aegis/config"
    "github.com/theinventorylib/aegis/plugins/openapi"
    "github.com/theinventorylib/aegis/router/routers"
)

func main() {
    ctx := context.Background()
    db, _ := sql.Open("postgres", "postgres://localhost/myapp?sslmode=disable")

    mux := chi.NewRouter()
    r := routers.NewChiRouter(mux)

    cfg := config.Default().
        WithDB(db).
        WithRouter(r).
        WithSecret([]byte("your-32-byte-secret-key-here!!!!"))

    // Document a custom application route; buffered until plugin Init runs
    openapi.Doc(openapi.Route{
        Method:      "GET",
        Path:        "/api/dashboard",
        OperationID: "getDashboard",
        Summary:     "Get dashboard data",
        Tags:        []string{"Dashboard"},
        Auth:        true,
        Responses: openapi.Responses{
            200: openapi.DataResponseOf[DashboardResponse]("Dashboard data"),
            401: openapi.TextResponse("Not authenticated"),
        },
    })

    // OpenAPI plugin must be registered last
    openapiPlugin := openapi.New(&openapi.Config{
        Title:      "My SaaS API",
        Version:    "1.0.0",
        EnableDocs: true,
    })

    a, _ := aegis.New(ctx, cfg)
    a.Use(ctx, openapiPlugin)
    a.MountRoutes("/auth")

    // Interactive docs at http://localhost:8080/auth/docs
    http.ListenAndServe(":8080", mux)
}
```
