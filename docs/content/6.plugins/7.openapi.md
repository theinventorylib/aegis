# OpenAPI Plugin

The OpenAPI plugin automatically generates interactive API documentation for your Aegis authentication endpoints.

## Features

- **Auto-Generated Spec**: Automatic OpenAPI 3.0 specification generation
- **Interactive UI**: Beautiful documentation UI with Scalar or Swagger
- **Try It Out**: Test endpoints directly from the documentation
- **Schema Validation**: Automatic request/response schema validation
- **Plugin Discovery**: Automatically includes routes from all registered plugins
- **Customizable**: Add your own endpoints to the documentation

## Installation

```bash
go get github.com/theinventorylib/aegis/plugins/openapi
```

## Configuration

```go
import (
    "github.com/theinventorylib/aegis"
    "github.com/theinventorylib/aegis/plugins/openapi"
)

// Configure OpenAPI plugin
openapiPlugin := openapi.New(&openapi.Config{
    Title:       "My App Authentication API",
    Version:     "1.0.0",
    Description: "Authentication endpoints for My App",
    Path:        "/docs",
    UI:          openapi.Scalar, // or openapi.Swagger
})

// Register with Aegis
auth.Use(ctx, openapiPlugin)
```

## Configuration Options

| Option | Type | Description | Default |
|--------|------|-------------|---------|
| `Title` | string | API documentation title | "Aegis API" |
| `Version` | string | API version | "1.0.0" |
| `Description` | string | API description | "" |
| `Path` | string | Documentation UI path | "/docs" |
| `UI` | UIType | UI framework (Scalar or Swagger) | Scalar |
| `SpecPath` | string | OpenAPI spec JSON path | "/openapi.json" |

## HTTP Endpoints

### Documentation UI

Access the interactive documentation interface.

```http
GET /docs
```

This serves the HTML interface (Scalar or Swagger UI) where users can explore and test the API.

### OpenAPI Specification

Download the OpenAPI 3.0 specification in JSON format.

```http
GET /openapi.json
```

**Response:**
```json
{
  "openapi": "3.0.0",
  "info": {
    "title": "My App Authentication API",
    "version": "1.0.0",
    "description": "Authentication endpoints for My App"
  },
  "servers": [
    {
      "url": "https://api.myapp.com"
    }
  ],
  "paths": {
    "/auth/email/signup": {
      "post": {
        "summary": "Sign up with email and password",
        "requestBody": {
          "content": {
            "application/json": {
              "schema": {
                "type": "object",
                "properties": {
                  "email": { "type": "string", "format": "email" },
                  "password": { "type": "string", "minLength": 8 }
                }
              }
            }
          }
        },
        "responses": {
          "200": {
            "description": "Successful signup"
          }
        }
      }
    }
  }
}
```

## Automatic Documentation

The OpenAPI plugin automatically documents:

1. **Core Auth Routes**: Sign up, sign in, sign out
2. **Plugin Routes**: All routes from registered plugins
3. **Request Schemas**: Parameter and body validations
4. **Response Schemas**: Expected response formats
5. **Authentication**: Bearer token, session requirements

## Adding Custom Endpoints

Document your own application endpoints:

```go
openapiPlugin.AddEndpoint(openapi.Endpoint{
    Path:        "/api/profile",
    Method:      "GET",
    Summary:     "Get user profile",
    Description: "Retrieve the authenticated user's profile",
    Auth:        true, // Requires authentication
    Response: openapi.Response{
        StatusCode: 200,
        Schema: map[string]interface{}{
            "type": "object",
            "properties": map[string]interface{}{
                "id":    map[string]string{"type": "string"},
                "name":  map[string]string{"type": "string"},
                "email": map[string]string{"type": "string"},
            },
        },
    },
})
```

## Access Control

### Public Access

Make the documentation publicly accessible:

```go
openapiPlugin := openapi.New(&openapi.Config{
    Path:   "/docs",
    Public: true,
})
```

### Protected Access

Require authentication to view documentation:

```go
openapiPlugin := openapi.New(&openapi.Config{
    Path:      "/docs",
    Public:    false,
    AuthCheck: func(ctx context.Context) bool {
        user := core.GetUser(ctx)
        return user != nil
    },
})
```

## Export Specification

Export the OpenAPI spec for external tools:

```bash
# Download the spec
curl https://api.yourapp.com/openapi.json > openapi.json

# Generate client SDKs
openapi-generator generate -i openapi.json -g typescript-fetch -o ./sdk

# Import into Postman or Insomnia
```

## Integration with External Tools

### Postman

1. Open Postman
2. Click "Import"
3. Enter URL: `https://api.yourapp.com/openapi.json`
4. All endpoints are imported as a collection

### Insomnia

1. Open Insomnia
2. Click "Import/Export"
3. Import from URL: `https://api.yourapp.com/openapi.json`

### SDK Generation

Generate client libraries for any language:

```bash
# TypeScript
openapi-generator generate -i openapi.json -g typescript-axios

# Python
openapi-generator generate -i openapi.json -g python

# Go
openapi-generator generate -i openapi.json -g go
```

## Best Practices

1. **Version Your API**: Include version in the title and path
2. **Detailed Descriptions**: Add helpful descriptions to all endpoints
3. **Examples**: Include request and response examples
4. **Security**: Document authentication requirements clearly
5. **Keep Updated**: Ensure spec stays in sync with code
6. **Test Endpoints**: Use "Try It Out" to verify docs accuracy

## Example Integration

```go
package main

import (
    "context"
    "database/sql"
    
    "github.com/go-chi/chi/v5"
    "github.com/theinventorylib/aegis"
    "github.com/theinventorylib/aegis/plugins/openapi"
)

func main() {
    ctx := context.Background()
    db, _ := sql.Open("postgres", "postgres://localhost/myapp")
    r := chi.NewRouter()
    
    // Configure OpenAPI plugin
    openapiPlugin := openapi.New(&openapi.Config{
        Title:       "My SaaS API",
        Version:     "1.0.0",
        Description: "Authentication and user management API",
        Path:        "/docs",
        UI:          openapi.Scalar,
        Public:      true, // Anyone can view docs
    })
    
    // Initialize Aegis
    auth := aegis.New(ctx, config.Default().WithDB(db).WithRouter(r))
    auth.Use(ctx, openapiPlugin)
    
    // Documentation is now available at http://localhost:8080/docs
}
```
