# SMS OTP Plugin

The SMS OTP plugin provides phone-based authentication using one-time passwords sent via SMS.

## Features

- **SMS Verification**: Send verification codes via SMS
- **Phone Number Validation**: Automatic phone number format validation
- **Multi-Provider Support**: Works with Twilio, AWS SNS, and custom SMS providers
- **Rate Limiting**: Built-in protection against SMS abuse
- **Configurable Codes**: Customizable OTP length and expiration

## Installation

```bash
go get github.com/theinventorylib/aegis/plugins/sms
```

## Configuration

```go
import (
    "github.com/theinventorylib/aegis"
    "github.com/theinventorylib/aegis/plugins/sms"
    "time"
)

// Create SMS plugin with custom configuration
smsPlugin := sms.New(&sms.Config{
    SendSMS: func(to, message string) error {
        // Integrate with your SMS provider
        // (Twilio, AWS SNS, Nexmo, etc.)
        return smsProvider.Send(to, message)
    },
    OTPLength:     6,
    OTPExpiration: 5 * time.Minute,
})

// Register with Aegis
auth.Use(ctx, smsPlugin)
```

## Database Schema

The SMS plugin uses the core `verification` table for managing OTP codes. No additional tables are required.

## HTTP Endpoints

### Send SMS Verification Code

Send a verification code to the user's phone number.

```http
POST /auth/sms/send
Content-Type: application/json

{
  "phone": "+1234567890"
}
```

**Response:**
```json
{
  "success": true,
  "message": "Verification code sent"
}
```

### Verify Phone Number

Verify the phone number with the code sent via SMS.

```http
POST /auth/sms/verify
Content-Type: application/json

{
  "phone": "+1234567890",
  "code": "123456"
}
```

**Response:**
```json
{
  "success": true,
  "user": {
    "id": "user_abc123"
  }
}
```

## SMS Provider Integration

### Twilio Example

```go
import (
    "github.com/twilio/twilio-go"
    twilioApi "github.com/twilio/twilio-go/rest/api/v2010"
)

func sendViaTwilio(to, message string) error {
    client := twilio.NewRestClientWithParams(twilio.ClientParams{
        Username: os.Getenv("TWILIO_ACCOUNT_SID"),
        Password: os.Getenv("TWILIO_AUTH_TOKEN"),
    })
    
    params := &twilioApi.CreateMessageParams{}
    params.SetTo(to)
    params.SetFrom(os.Getenv("TWILIO_PHONE_NUMBER"))
    params.SetBody(message)
    
    _, err := client.Api.CreateMessage(params)
    return err
}
```

### AWS SNS Example

```go
import (
    "github.com/aws/aws-sdk-go/aws"
    "github.com/aws/aws-sdk-go/aws/session"
    "github.com/aws/aws-sdk-go/service/sns"
)

func sendViaSNS(to, message string) error {
    sess := session.Must(session.NewSession())
    svc := sns.New(sess)
    
    _, err := svc.Publish(&sns.PublishInput{
        Message:     aws.String(message),
        PhoneNumber: aws.String(to),
    })
    return err
}
```

## Security Considerations

- OTP codes expire after the configured time (default: 5 minutes)
- Rate limiting prevents SMS bombing attacks
- Phone numbers are validated before sending
- Codes are single-use and deleted upon verification
- Consider implementing CAPTCHA for additional security

## Example Integration

```go
package main

import (
    "context"
    "database/sql"
    
    "github.com/theinventorylib/aegis"
    "github.com/theinventorylib/aegis/plugins/sms"
)

func main() {
    ctx := context.Background()
    db, _ := sql.Open("postgres", "postgres://localhost/myapp")
    
    // Configure SMS plugin
    smsPlugin := sms.New(&sms.Config{
        SendSMS: sendViaTwilio, // Use your SMS provider
        OTPLength:     6,
        OTPExpiration: 5 * time.Minute,
    })
    
    // Initialize Aegis
    auth := aegis.New(ctx, config.Default().WithDB(db))
    auth.Use(ctx, smsPlugin)
}
```
