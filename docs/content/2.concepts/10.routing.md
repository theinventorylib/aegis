`Aegis.MountRoutes(prefix)` mounts core authentication routes under `{prefix}/default/*` and every registered plugin under `{prefix}/{plugin-name}/*`. All Aegis routes are identity/authentication surfaces, but some plugins are management or tooling rather than login endpoints — and you may not want them under `/auth`.

Per-call mount options let you keep authentication where it belongs while placing everything else at its own root, without changing the default behavior.

## Default Layout

```go
a.MountRoutes("/auth")
```

| Owner | Mount point | Example |
|-------|-------------|---------|
| Core (`default`) | `{prefix}/default` | `POST /auth/default/login` |
| `oauth` | `{prefix}/oauth` | `GET /auth/oauth/google` |
| `jwt` | `{prefix}/jwt` | `POST /auth/jwt/token` |
| `sms` | `{prefix}/sms` | `POST /auth/sms/verify` |
| `email-otp` | `{prefix}/email-otp` | `POST /auth/email-otp/reset-password` |
| `totp` | `{prefix}/totp` | `POST /auth/totp/setup` |
| `organizations` | `{prefix}/organizations` | `GET /auth/organizations/:id` |
| `admin` | `{prefix}/admin` | `GET /auth/admin/users` |
| `openapi` | `{prefix}/openapi` | `GET /auth/openapi/docs` |

## Options

### `WithCorePath(sub)`

Moves the core email/password and session routes. The value is relative to the mount prefix, so `""` drops the `/default` segment:

```go
a.MountRoutes("/auth", aegis.WithCorePath(""))
```

```text
POST /auth/login          GET /auth/session       POST /auth/session/refresh
POST /auth/signup         GET /auth/sessions      DELETE /auth/sessions/:id
POST /auth/logout         DELETE /auth/sessions
```

### `WithPluginPrefix(name, path)`

Moves a single plugin. Path semantics:

| Value | Meaning | Result (mount prefix `/auth`) |
|-------|---------|-------------------------------|
| `"/admin"` | absolute | `/admin/*` |
| `"backoffice"` | relative | `/auth/backoffice/*` |
| `""` | mount prefix root | `/auth/*` |
| `"/"` | server root | `/*` |

Unknown plugin names are ignored, with a warning when a logger is configured.

## Example: Authentication Under `/auth`, Everything Else at Its Own Root

```go
a.MountRoutes("/auth",
    aegis.WithCorePath(""),                      // /auth/login
    aegis.WithPluginPrefix("admin", "/admin"),   // /admin/users
    aegis.WithPluginPrefix("organizations", "/orgs"),
    aegis.WithPluginPrefix("openapi", "/"),      // /docs, /openapi.json
)
```

Resulting surface:

```text
Auth:        /auth/login, /auth/signup, /auth/session, /auth/sessions
             /auth/oauth/:provider, /auth/jwt/token, /auth/sms/verify
             /auth/email-otp/..., /auth/totp/...
Management:  /admin/users, /admin/stats, /orgs/:id/members
Docs:        /docs (Scalar UI), /openapi.json (spec)
```

Your own application routes are unaffected — `MountRoutes` only registers Aegis routes, and never applies authentication middleware beyond the individual handlers that opt in.

## OpenAPI

The generated specification records each route with the prefix it was mounted with, so moving a plugin automatically moves its documented paths too. No manual documentation changes are required.

The `openapi` plugin is a special case: its own `DocsPath` and `SpecPath` are appended to its mount point. Mount it at the server root to serve them as configured:

```go
a.MountRoutes("/auth", aegis.WithPluginPrefix("openapi", "/"))

// GET /docs          -> Scalar UI
// GET /openapi.json  -> OpenAPI spec
```

Without the override the docs live under the plugin namespace: `GET /auth/openapi/docs` and `GET /auth/openapi/openapi.json`.

## Notes

- Calling `MountRoutes` more than once registers duplicate routes; call it once after all plugins are registered.
- The `openapi` plugin must be registered last, regardless of where it is mounted.
- To mount a plugin *outside* the auth prefix, always use an absolute value; relative values intentionally nest inside it.
