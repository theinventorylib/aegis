## Cookie Security

All Aegis cookies are configured with security-first defaults:

- **HttpOnly**: `true` — Prevents JavaScript access (XSS protection)
- **Secure**: `true` — HTTPS-only transmission (production requirement)
- **SameSite**: `Lax` — CSRF protection while allowing top-level navigation
- **Path**: `/` — Available across your entire application

## Configuration

### Basic Setup

```go
cfg := config.Default().
    WithDB(db).
    WithRouter(r).
    WithSecret([]byte("your-secret-key-must-be-32-chars!")).
    WithCookieName("myapp_session").
    WithCookieDomain(".example.com").    // Subdomain sharing
    WithCookieSameSite("Strict").         // Maximum CSRF protection
    WithCookieSecure(true).
    WithCookieHTTPOnly(true)

a, err := aegis.New(ctx, cfg)
```

### SameSite Modes

| Mode | Behavior | Use Case |
|------|----------|----------|
| `Strict` | Never sent cross-site | Maximum security, single-domain apps |
| `Lax` | Sent on top-level navigation | **Default**, balanced security |
| `None` | Always sent (requires `Secure=true`) | Cross-domain APIs, OAuth flows |

::callout{icon="i-heroicons-shield-check" color="green"}
**Production Recommendation**: Use `Strict` for high-security apps, `Lax` for standard web apps, `None` only when necessary for cross-site requests.
::

## Cookie Manager API

The `CookieManager` provides a clean API for cookie operations:

### Session Cookies

```go
// Set session cookie (auto-login after signup/login)
session, _ := sessionService.CreateSession(ctx, user)
cookieManager.SetSessionCookie(w, session.Token)

// Get session cookie (for validation)
token, err := cookieManager.GetSessionCookie(r)

// Clear session cookie (logout)
cookieManager.ClearSessionCookie(w)
```

### Custom Cookies

```go
// For plugins or custom features
cookieManager.SetCookie(w, "custom_data", "value", 24*time.Hour)

// With fine-grained control
cookieManager.SetCustomCookie(w, core.CookieOptions{
    Name:     "csrf_token",
    Value:    token,
    Path:     "/api",
    MaxAge:   3600,  // 1 hour
    HTTPOnly: true,
    Secure:   true,
    SameSite: http.SameSiteStrictMode,
})
```

## Security Best Practices

### XSS Protection

```go
// ✓ Always HttpOnly for session cookies
config.CookieHTTPOnly = true  // Default

// ✗ Never expose session tokens to JavaScript
// This would allow XSS attacks to steal tokens
```

### CSRF Protection

```go
// ✓ Use SameSite for automatic CSRF protection
// Configure via builder pattern:
cfg := config.Default().WithCookieSameSite("Lax")  // or "Strict"
```

### HTTPS Enforcement

```go
// ✓ Always Secure in production
config.CookieSecure = true

// ✗ Only disable for local development
if os.Getenv("ENV") == "development" {
    config.CookieSecure = false
}
```

## Subdomain Cookie Sharing

Enable single sign-on across subdomains:

```go
config.CookieDomain = ".example.com"
// Cookie accessible at:
// - app.example.com
// - api.example.com
// - www.example.com
```

::callout{icon="i-heroicons-information-circle" color="blue"}
**Note**: Domain must start with `.` for subdomain sharing. Without the dot, the cookie is restricted to the exact domain.
::

## Examples

### Multi-Domain Setup

```go
// Main app (app.example.com)
mainCfg := config.Default().
    WithDB(db).
    WithRouter(r).
    WithSecret([]byte("your-secret-key-must-be-32-chars!")).
    WithCookieDomain(".example.com")  // Share with subdomains

// API (api.example.com) - uses same cookie
apiCfg := config.Default().
    WithDB(db).
    WithRouter(apiRouter).
    WithSecret([]byte("your-secret-key-must-be-32-chars!")).
    WithCookieDomain(".example.com")  // Same domain
```

### Remember Me Cookie

```go
// Extend session expiry for "Remember Me"
cfg := config.Default().
    WithDB(db).
    WithRouter(r).
    WithSecret([]byte("your-secret-key-must-be-32-chars!")).
    WithSessionExpiry(30 * 24 * time.Hour).  // 30 days
    WithCookieHTTPOnly(true).
    WithCookieSecure(true).
    WithCookieSameSite("Lax")
```

## Troubleshooting

### Cookie Not Set

**Symptom**: Session cookie not appearing in browser

**Solutions**:
```go
// 1. Check HTTPS in production
// Use WithCookieSecure(true) — requires HTTPS

// 2. Verify domain matches
// Use WithCookieDomain(".example.com") — must match your domain

// 3. Check SameSite + cross-site requests
// Use WithCookieSameSite("None") — if cross-site needed
// Note: SameSite=None requires Secure=true
```

### Cookie Not Sent in Requests

**Symptom**: Cookie exists but not sent to server

**Solutions**:
```go
// 1. Use WithCookieSameSite("Lax") — or "None" for cross-site
// 2. Use WithCookieDomain(".example.com") — cookie domain must be parent of request domain
// 3. Check AuthMiddleware setup
```

### CSRF Errors

**Symptom**: CSRF-related issues with cross-site requests

**Solutions**:
```go
// 1. Use consistent SameSite setting
// WithCookieSameSite("Lax") — allows top-level navigation

// 2. Use SameSite=Strict for maximum CSRF protection
// WithCookieSameSite("Strict")
```

## Reference

### Cookie Configuration Fields

These fields are set via builder methods on `config.Config`:

| Field | Builder Method | Default |
|-------|---------------|----------|
| `CookieName` | `WithCookieName(name)` | `"aegis_session"` |
| `CookieDomain` | `WithCookieDomain(domain)` | `""` (current domain) |
| `CookieSecure` | `WithCookieSecure(bool)` | `true` |
| `CookieHTTPOnly` | `WithCookieHTTPOnly(bool)` | `true` |
| `CookieSameSite` | `WithCookieSameSite(mode)` | `"Lax"` |

### CookieManager Methods

```go
// Session cookies
SetSessionCookie(w http.ResponseWriter, token string)
GetSessionCookie(r *http.Request) (string, error)
ClearSessionCookie(w http.ResponseWriter)

// Custom cookies
SetCookie(w http.ResponseWriter, name, value string, maxAge time.Duration)
GetCookie(r *http.Request, name string) (string, error)
SetCustomCookie(w http.ResponseWriter, opts CookieOptions)

// Config
GetConfig() *SessionConfig
GetSessionCookieName() string
```
