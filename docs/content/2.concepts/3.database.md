## Multi-Database Support

### Supported Databases

| Database | Version | Production Ready | Use Case |
|----------|---------|------------------|----------|
| **PostgreSQL** | 9.6+ | ✅ Yes | Recommended for production |
| **MySQL** | 5.7+ / MariaDB 10.2+ | ✅ Yes | Enterprise compatibility |
| **SQLite** | 3.35+ | ⚠️ Development only | Local development, testing |

::callout{icon="i-heroicons-shield-check" color="green"}
**Production Recommendation**: Use PostgreSQL for production deployments. It offers superior concurrency, JSON support, and full-text search capabilities.
::

### Driver Configuration

```go
import (
    "database/sql"
    _ "github.com/lib/pq"              // PostgreSQL
    _ "github.com/go-sql-driver/mysql" // MySQL
    _ "github.com/mattn/go-sqlite3"    // SQLite
)

// PostgreSQL
db, err := sql.Open("postgres", "postgres://user:pass@localhost/dbname?sslmode=disable")

// MySQL
db, err := sql.Open("mysql", "user:pass@tcp(localhost:3306)/dbname?parseTime=true")

// SQLite
db, err := sql.Open("sqlite3", "./aegis.db?_foreign_keys=on")
```

## Core Schema

Aegis uses a **4-table core schema** designed for simplicity and performance:

### 1. Users Table

Stores the core user identity:

```sql
CREATE TABLE "user" (
    id TEXT PRIMARY KEY,           -- ULID or UUID
    avatar TEXT,                   -- Profile picture URL
    name TEXT NOT NULL,            -- Display name
    email TEXT UNIQUE,             -- Email (optional for OAuth-only users)
    created_at TEXT NOT NULL,      -- ISO 8601 timestamp
    updated_at TEXT NOT NULL,      -- Last modification
    disabled INTEGER NOT NULL DEFAULT 0  -- Account status
);
``` 

### 2. Accounts Table

Links users to authentication providers:

```sql
CREATE TABLE accounts (
    id TEXT PRIMARY KEY,
    user_id TEXT NOT NULL,         -- Foreign key to user
    provider TEXT NOT NULL,        -- "password", "google", "github"
    provider_account_id TEXT,      -- Provider's user ID
    password_hash TEXT,            -- Argon2id hash (credentials only)
    access_token TEXT,             -- OAuth access token
    refresh_token TEXT,            -- OAuth refresh token
    expires_at TEXT,               -- Token expiration
    created_at TEXT NOT NULL,
    updated_at TEXT NOT NULL,
    UNIQUE(provider, provider_account_id),
    FOREIGN KEY (user_id) REFERENCES "user"(id) ON DELETE CASCADE
);

```

::callout{icon="i-heroicons-information-circle" color="blue"}
**Multi-Provider Design**: A single user can have multiple accounts (e.g., one for email/password, one for Google, one for GitHub). This enables account linking and flexible authentication.
::

### 3. Sessions Table

Manages active user sessions:

```sql
CREATE TABLE session (
    id TEXT PRIMARY KEY,
    user_id TEXT NOT NULL,
    token TEXT UNIQUE NOT NULL,    -- Access token (bearer token)
    refresh_token TEXT,            -- Refresh token for token rotation
    ip_address TEXT,               -- Client IP for security auditing
    user_agent TEXT,               -- Browser/client identifier
    expires_at TEXT NOT NULL,      -- Session expiration
    created_at TEXT NOT NULL,
    FOREIGN KEY (user_id) REFERENCES "user"(id) ON DELETE CASCADE
);

```

### 4. Verification Table

Stores temporary verification tokens:

```sql
CREATE TABLE verification (
    id TEXT PRIMARY KEY,
    identifier TEXT NOT NULL,      -- Email, phone, user ID
    token TEXT UNIQUE NOT NULL,    -- Verification code/token
    type TEXT NOT NULL,            -- "email", "reset", "otp"
    expires_at TEXT NOT NULL,      -- Token expiration
    created_at TEXT NOT NULL
);

```

## Migration Strategies

### Using the Aegis CLI

The recommended approach is the Aegis CLI for migration export:

```bash
# Export PostgreSQL migrations
aegis export \
  --dialect postgres \
  --output ./migrations

# Export with plugins
aegis export \
  --dialect postgres \
  --plugins oauth,organizations,admin \
  --output ./migrations
```

Generated structure:

```
migrations/
├── 001_initial.up.sql       # Core schema
├── 001_initial.down.sql
├── 002_oauth.up.sql         # OAuth plugin
├── 002_oauth.down.sql
├── 003_organizations.up.sql
└── 003_organizations.down.sql
```

### Manual Migration with golang-migrate

```bash
# Install golang-migrate
go install -tags 'postgres' github.com/golang-migrate/migrate/v4/cmd/migrate@latest

# Export migrations
aegis export \
  --dialect postgres \
  --format golang-migrate \
  --output ./migrations

# Run migrations
migrate -path ./migrations \
  -database "postgres://user:pass@localhost/dbname?sslmode=disable" \
  up

# Rollback
migrate -path ./migrations \
  -database "postgres://user:pass@localhost/dbname?sslmode=disable" \
  down 1
```

### Programmatic Schema Access

For custom tooling or documentation:


## Database Connection Examples

### PostgreSQL with Connection Pooling

```go
import (
    "database/sql"
    "time"
    _ "github.com/lib/pq"
)

func NewPostgresDB(connString string) (*sql.DB, error) {
    db, err := sql.Open("postgres", connString)
    if err != nil {
        return nil, err
    }

    // Connection pool settings
    db.SetMaxOpenConns(25)                 // Max concurrent connections
    db.SetMaxIdleConns(5)                  // Idle connections to keep
    db.SetConnMaxLifetime(5 * time.Minute) // Connection reuse time

    // Verify connection
    if err := db.Ping(); err != nil {
        return nil, err
    }

    return db, nil
}

// Usage
db, err := NewPostgresDB("postgres://aegis:secret@localhost/aegis?sslmode=require")
if err != nil {
    log.Fatal(err)
}
defer db.Close()

auth := aegis.New(ctx, &config.Config{
    DB: db,
    // ... other config
})
```

### MySQL with TLS

```go
import (
    "crypto/tls"
    "crypto/x509"
    "database/sql"
    "github.com/go-sql-driver/mysql"
)

func NewMySQLDB(dsn string, tlsConfig *tls.Config) (*sql.DB, error) {
    // Register TLS config
    mysql.RegisterTLSConfig("custom", tlsConfig)
    
    // Connection string with TLS
    db, err := sql.Open("mysql", dsn+"?tls=custom&parseTime=true")
    if err != nil {
        return nil, err
    }

    db.SetMaxOpenConns(20)
    db.SetMaxIdleConns(5)
    db.SetConnMaxLifetime(5 * time.Minute)

    return db, db.Ping()
}
```

### SQLite for Testing

```go
import (
    "database/sql"
    _ "github.com/mattn/go-sqlite3"
)

func NewTestDB(t *testing.T) *sql.DB {
    // In-memory database
    db, err := sql.Open("sqlite3", ":memory:?_foreign_keys=on")
    if err != nil {
        t.Fatal(err)
    }

    // Apply schema
    schema, _ := auth.GetSchema(auth.DialectSQLite)
    if _, err := db.Exec(schema.SQL); err != nil {
        t.Fatal(err)
    }

    t.Cleanup(func() { db.Close() })
    return db
}
```

```go
	// GetByID retrieves a user by ID.
	GetByID(ctx context.Context, id string) (User, error)

		// ========== Role Management ==========

	// AssignRole assigns a role to a user (e.g., "admin").
	AssignRole(ctx context.Context, userID string, role string) error

	// GetRole retrieves a user's role (empty string if no role).
	GetRole(ctx context.Context, userID string) (string, error)

		return err

	}

	return nil
}
```

### Plugin-Specific Tables

Plugins can also add their own tables:

```sql
-- OAuth plugin adds oauth_connections table
CREATE TABLE oauth_connections (
    id TEXT PRIMARY KEY,
    user_id TEXT NOT NULL,
    provider TEXT NOT NULL,
    provider_user_id TEXT NOT NULL,
    access_token TEXT,
    refresh_token TEXT,
    expires_at TEXT,
    created_at TEXT NOT NULL,
    updated_at TEXT NOT NULL,
    FOREIGN KEY (user_id) REFERENCES "user"(id) ON DELETE CASCADE
);
```

Export plugin migrations with CLI:

```bash
aegis export \
  --dialect postgres \
  --plugins oauth \
  --output ./migrations
```

## Performance Considerations

### Indexing Strategy

Critical indexes for performance:

```sql
-- User lookups
CREATE INDEX idx_user_email ON "user"(email);           -- Email login
CREATE INDEX idx_user_disabled ON "user"(disabled);     -- Active users filter

-- Session validation (high traffic)
CREATE INDEX idx_session_token ON session(token);       -- Bearer token auth
CREATE INDEX idx_session_user_id ON session(user_id);   -- User's sessions

-- Cleanup queries
CREATE INDEX idx_session_expires_at ON session(expires_at);         -- Expire old sessions
CREATE INDEX idx_verification_expires_at ON verification(expires_at); -- Cleanup tokens
```

### Query Optimization

```go
// ❌ Bad: N+1 query problem
for _, userID := range userIDs {
    user, _ := userStore.GetByID(ctx, userID)
    // Process user
}

// ✅ Good: Batch query
users, _ := userStore.GetByIDs(ctx, userIDs)
```

### Connection Pool Tuning

```go
// High traffic production settings
db.SetMaxOpenConns(100)              // Allow up to 100 concurrent connections
db.SetMaxIdleConns(10)               // Keep 10 connections ready
db.SetConnMaxLifetime(time.Hour)     // Recycle connections hourly
db.SetConnMaxIdleTime(10 * time.Minute) // Close idle connections after 10 min
```
