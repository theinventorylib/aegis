# Email

Aegis provides comprehensive email-based authentication with verification flows, password reset tokens, and one-time password (OTP) delivery. Integrate with any email service provider using a simple interface.

## Email Verification Flow

### Standard Verification Process

```go
// 1. User signs up
user, err := emailPasswordHandlers.Register(ctx, "John Doe", "user@example.com", "secure-password")

// 2. Generate verification token
verification, err := verificationService.CreateVerification(
    ctx,
    user.GetEmail(),
    "email",              // Verification type
    24*time.Hour,         // Token valid for 24 hours
    nil,                  // Auto-generate random token
)

// 3. Send verification email (your email provider)
err = emailProvider.Send(EmailOptions{
    To:       user.GetEmail(),
    Subject:  "Verify your email",
    Template: "verify-email",
    Data: map[string]any{
        "name":  user.GetName(),
        "token": verification.Token,
        "url":   fmt.Sprintf("https://example.com/verify?token=%s", verification.Token),
    },
})

// 4. User clicks link → validate token
verified, err := verificationService.ValidateVerification(ctx, verification.Token, "email")
if err != nil {
    // Invalid or expired token
    return err
}

// 5. Mark email as verified (store in user metadata or custom field)
```

### Custom Verification Codes

Generate short numeric codes for email OTP:

```go
import "math/rand"

// Generate 6-digit code
code := fmt.Sprintf("%06d", rand.Intn(1000000))

// Create verification with custom code
verification, err := verificationService.CreateVerification(
    ctx,
    "user@example.com",
    "email-otp",
    10*time.Minute,       // OTP valid for 10 minutes
    &code,                // Use custom code
)

// Send via email
emailProvider.Send(EmailOptions{
    To:      "user@example.com",
    Subject: "Your verification code",
    Body:    fmt.Sprintf("Your code is: %s", code),
})

// Validate
verified, err := verificationService.ValidateVerification(ctx, code, "email-otp")
```

## Email + Password Authentication

### Registration

```go
import "github.com/theinventorylib/aegis/core"

// Programmatic registration
result, err := emailPasswordHandlers.Register(
    ctx,
    "John Doe",           // Name
    "user@example.com",   // Email
    "MySecurePass123!",   // Password
)
if err != nil {
    // Handle error (duplicate email, weak password, etc.)
```

### Password Reset Flow

```go
// 1. User requests password reset
verification, err := verificationService.CreateVerification(
    ctx,
    "user@example.com",
    "reset",              // Reset token type
    1*time.Hour,          // Token valid for 1 hour
    nil,
)

// 2. Send reset email
emailProvider.Send(EmailOptions{
    To:       "user@example.com",
    Subject:  "Reset your password",
    Template: "reset-password",
    Data: map[string]any{
        "url": fmt.Sprintf("https://example.com/reset?token=%s", verification.Token),
    },
})

// 3. User clicks link → validate token
verified, err := verificationService.ValidateVerification(ctx, token, "reset")
if err != nil {
    return errors.New("invalid or expired reset token")
}

// 4. Update password
err = accountService.UpdatePassword(ctx, userID, "NewSecurePassword456!")

// 5. Invalidate reset token (consumed)
err = verificationService.DeleteVerification(ctx, verification.ID)

// 6. Optional: Invalidate all existing sessions
err = sessionService.InvalidateAllSessions(ctx, userID)
```

## Email Provider Integration

### Provider Interface

Implement this interface for your email service:

```go
type EmailProvider interface {
    Send(ctx context.Context, opts EmailOptions) error
}

type EmailOptions struct {
    To       string            // Recipient email
    From     string            // Sender email (optional)
    Subject  string            // Email subject
    Body     string            // Plain text body
    HTML     string            // HTML body
    Template string            // Template name (if using templates)
    Data     map[string]any    // Template data
}
```

### SMTP Provider Example

```go
import (
    "crypto/tls"
    "net/smtp"
)

type SMTPProvider struct {
    host     string
    port     int
    username string
    password string
    from     string
}

func (p *SMTPProvider) Send(ctx context.Context, opts EmailOptions) error {
    auth := smtp.PlainAuth("", p.username, p.password, p.host)
    
    // Build message
    msg := fmt.Sprintf("From: %s\r\n", p.from)
    msg += fmt.Sprintf("To: %s\r\n", opts.To)
    msg += fmt.Sprintf("Subject: %s\r\n", opts.Subject)
    msg += "\r\n" + opts.Body
    
    // Send with TLS
    tlsConfig := &tls.Config{ServerName: p.host}
    conn, err := tls.Dial("tcp", fmt.Sprintf("%s:%d", p.host, p.port), tlsConfig)
    if err != nil {
        return err
    }
    defer conn.Close()
    
    client, err := smtp.NewClient(conn, p.host)
    if err != nil {
        return err
    }
    defer client.Quit()
    
    if err := client.Auth(auth); err != nil {
        return err
    }
    
    if err := client.Mail(p.from); err != nil {
        return err
    }
    if err := client.Rcpt(opts.To); err != nil {
        return err
    }
    
    w, err := client.Data()
    if err != nil {
        return err
    }
    _, err = w.Write([]byte(msg))
    if err != nil {
        return err
    }
    
    return w.Close()
}
```

### SendGrid Example

```go
import "github.com/sendgrid/sendgrid-go"
import "github.com/sendgrid/sendgrid-go/helpers/mail"

type SendGridProvider struct {
    apiKey string
    from   string
}

func (p *SendGridProvider) Send(ctx context.Context, opts EmailOptions) error {
    from := mail.NewEmail("Your App", p.from)
    to := mail.NewEmail("", opts.To)
    message := mail.NewSingleEmail(from, opts.Subject, to, opts.Body, opts.HTML)
    
    client := sendgrid.NewSendClient(p.apiKey)
    _, err := client.Send(message)
    return err
}
```

### Resend Example

```go
import "github.com/resendlabs/resend-go"

type ResendProvider struct {
    apiKey string
    from   string
}

func (p *ResendProvider) Send(ctx context.Context, opts EmailOptions) error {
    client := resend.NewClient(p.apiKey)
    
    params := &resend.SendEmailRequest{
        From:    p.from,
        To:      []string{opts.To},
        Subject: opts.Subject,
        Html:    opts.HTML,
        Text:    opts.Body,
    }
    
    _, err := client.Emails.Send(params)
    return err
}
```

## Verification Codes / OTP

### Email OTP Plugin

For managed OTP delivery, use the official `emailotp` plugin:

```go
import (
    "github.com/theinventorylib/aegis/plugins/emailotp"
)

// Configure email OTP
emailOTPConfig := &emailotp.Config{
    CodeLength:   6,              // 6-digit codes
    CodeExpiry:   10 * time.Minute, // 10-minute expiry
    EmailFrom:    "noreply@example.com",
    EmailSubject: "Your verification code",
}

otpPlugin := emailotp.New(emailOTPConfig, yourEmailProvider)

// Register plugin
auth := aegis.New(ctx, &config.Config{
    Plugins: []plugins.Plugin{otpPlugin},
})

// Send OTP
code, err := otpPlugin.SendOTP(ctx, "user@example.com")

// Verify OTP
valid, userID, err := otpPlugin.VerifyOTP(ctx, "user@example.com", code)
```

### Manual OTP Implementation

```go
import (
    "crypto/rand"
    "math/big"
)

// Generate cryptographically secure OTP
func GenerateOTP(length int) (string, error) {
    const digits = "0123456789"
    result := make([]byte, length)
    
    for i := range result {
        num, err := rand.Int(rand.Reader, big.NewInt(int64(len(digits))))
        if err != nil {
            return "", err
        }
        result[i] = digits[num.Int64()]
    }
    
    return string(result), nil
}

// Usage
code, err := GenerateOTP(6) // "482731"

verification, err := verificationService.CreateVerification(
    ctx,
    email,
    "otp",
    10*time.Minute,
    &code,
)

// Send via your email provider
emailProvider.Send(EmailOptions{
    To:      email,
    Subject: "Your verification code",
    Body:    fmt.Sprintf("Your code is: %s\n\nThis code expires in 10 minutes.", code),
})
```

## Email Templates

### Template System

```go
import "html/template"

type EmailTemplateProvider struct {
    templates map[string]*template.Template
}

func NewEmailTemplateProvider() *EmailTemplateProvider {
    return &EmailTemplateProvider{
        templates: map[string]*template.Template{
            "verify-email": template.Must(template.New("verify").Parse(`
<!DOCTYPE html>
<html>
<body>
    <h1>Verify your email</h1>
    <p>Hello {{.name}},</p>
    <p>Click the link below to verify your email address:</p>
    <a href="{{.url}}">Verify Email</a>
    <p>Or copy this code: <strong>{{.token}}</strong></p>
    <p>This link expires in 24 hours.</p>
</body>
</html>
            `)),
            
            "reset-password": template.Must(template.New("reset").Parse(`
<!DOCTYPE html>
<html>
<body>
    <h1>Reset your password</h1>
    <p>You requested a password reset. Click the link below:</p>
    <a href="{{.url}}">Reset Password</a>
    <p>This link expires in 1 hour.</p>
    <p>If you didn't request this, please ignore this email.</p>
</body>
</html>
            `)),
        },
    }
}

func (p *EmailTemplateProvider) Render(templateName string, data map[string]any) (string, error) {
    tmpl, ok := p.templates[templateName]
    if !ok {
        return "", fmt.Errorf("template not found: %s", templateName)
    }
    
    var buf bytes.Buffer
    if err := tmpl.Execute(&buf, data); err != nil {
        return "", err
    }
    
    return buf.String(), nil
}
```

## Rate Limiting for Emails

Prevent abuse by rate limiting email sends:

```go
import "github.com/theinventorylib/aegis/core"

// Configure rate limiter for email verification
rateLimiter := core.NewRateLimiter(
    &core.RateLimitConfig{
        RequestsPerWindow: 3,              // 3 emails max
        WindowDuration:    15 * time.Minute, // per 15 minutes
        KeyPrefix:         "email-verify:",
        ByIP:              true,           // Limit by IP address
    },
    redisClient,
    auditLogger,
)

// Before sending verification email
allowed, retryAfter, err := rateLimiter.AllowRequest(ctx, "email-verify:"+email)
if !allowed {
    return fmt.Errorf("too many verification emails sent, try again in %s", retryAfter)
}

// Send email
verification, err := verificationService.CreateVerification(ctx, email, "email", 24*time.Hour, nil)
emailProvider.Send(...)
```

### Per-User Email Limits

```go
// Limit password reset emails per user
type PasswordResetLimiter struct {
    rateLimiter *core.RateLimiter
}

func (l *PasswordResetLimiter) CanSendReset(ctx context.Context, email string) (bool, time.Duration, error) {
    return l.rateLimiter.AllowRequest(ctx, "reset:"+email)
}

// Usage
limiter := &PasswordResetLimiter{
    rateLimiter: core.NewRateLimiter(&core.RateLimitConfig{
        RequestsPerWindow: 3,
        WindowDuration:    time.Hour,
        KeyPrefix:         "reset:",
    }, nil, nil),
}

allowed, retryAfter, _ := limiter.CanSendReset(ctx, "user@example.com")
if !allowed {
    return fmt.Errorf("too many reset attempts, try again in %s", retryAfter)
}
```

## Security Best Practices

### Email Validation

```go
import "github.com/theinventorylib/aegis/core"

// Sanitize and validate email
email := core.SanitizeEmail("  User@EXAMPLE.com  ")
// Result: "user@example.com" (trimmed, lowercased)

// Additional validation
if !isValidEmail(email) {
    return errors.New("invalid email format")
}
```

### Prevent Email Enumeration

```go
// ❌ Bad: Reveals if email exists
user, err := userStore.GetUserByEmail(ctx, email)
if err != nil {
    return errors.New("email not found")  // Attacker knows email doesn't exist
}

// ✅ Good: Generic error message
_, err := userStore.GetUserByEmail(ctx, email)
if err != nil {
    return errors.New("if this email exists, a reset link has been sent")
}
// Always send success response, even if email doesn't exist
```

### Token Security

```go
// ✓ Use cryptographically secure random tokens
verification, _ := verificationService.CreateVerification(
    ctx, email, "email", 24*time.Hour, nil,
)
// Generates 64-character hex token (32 bytes of entropy)

// ✗ Don't use predictable tokens
badToken := fmt.Sprintf("%d", time.Now().Unix()) // Predictable
```
