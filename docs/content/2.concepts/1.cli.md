# CLI

The Aegis CLI provides powerful command-line tools for managing database migrations, exporting schemas, and streamlining your development workflow.

## Installation

```bash
go install github.com/theinventorylib/aegis/cmd/aegis@latest
```

Verify installation:

```bash
aegis --version
```

## Commands

### `migrate export`

Export database migrations for Aegis core and plugins.

#### Basic Usage

```bash
# Export PostgreSQL migrations
aegis migrate export --driver postgres --out ./migrations

# Export MySQL migrations
aegis migrate export --driver mysql --out ./migrations

# Export SQLite migrations
aegis migrate export --driver sqlite --out ./migrations
```

#### Export with Plugins

```bash
# Export core + specific plugins
aegis migrate export \
  --driver postgres \
  --plugins emailotp,oauth,organizations \
  --out ./migrations

# Export all available plugins
aegis migrate export \
  --driver postgres \
  --plugins all \
  --out ./migrations
```

#### Migration Formats

Aegis supports multiple migration formats:

**SQL (Default)**
```bash
aegis migrate export --driver postgres --format sql --out ./migrations
```

Generates:
```
migrations/
├── 001_initial.up.sql
├── 001_initial.down.sql
├── 002_emailotp.up.sql
└── 002_emailotp.down.sql
```

**Goose**
```bash
aegis migrate export --driver postgres --format goose --out ./migrations
```

Generates:
```
migrations/
├── 00001_initial.sql
└── 00002_emailotp.sql
```

**golang-migrate**
```bash
aegis migrate export --driver postgres --format golang-migrate --out ./migrations
```

Generates:
```
migrations/
├── 000001_initial.up.sql
├── 000001_initial.down.sql
├── 000002_emailotp.up.sql
└── 000002_emailotp.down.sql
```

### Available Plugins

| Plugin | Flag Value | Description |
|--------|------------|-------------|
| Email OTP | `emailotp` | Email verification via OTP |
| SMS | `sms` | Phone verification via OTP |
| OAuth | `oauth` | Social login providers |
| JWT | `jwt` | JWT token management |
| Admin | `admin` | Administrative endpoints |
| Organizations | `organizations` | Multi-tenant support |
| OpenAPI | `openapi` | API documentation (no schema) |

## Configuration File

Create `aegis.yaml` in your project root for default settings:

```yaml
# aegis.yaml
database:
  driver: postgres
  
migrations:
  output: ./migrations
  format: golang-migrate
  
plugins:
  - emailotp
  - oauth
  - organizations
```

Then run:

```bash
aegis migrate export  # Uses config file
```

## Examples

### New Project Setup

```bash
# 1. Install CLI
go install github.com/theinventorylib/aegis/cmd/aegis@latest

# 2. Export migrations
aegis migrate export \
  --driver postgres \
  --plugins emailotp,oauth \
  --out ./db/migrations

# 3. Apply migrations (using golang-migrate)
migrate -path ./db/migrations \
  -database "postgres://localhost/myapp?sslmode=disable" up
```

### Updating Schema

```bash
# Add new plugin
aegis migrate export \
  --driver postgres \
  --plugins emailotp,oauth,organizations \  # Added organizations
  --out ./db/migrations

# Review generated migrations
ls -la ./db/migrations

# Apply new migrations
migrate -path ./db/migrations -database $DATABASE_URL up
```

### Multi-Environment Workflow

```bash
# Development (SQLite)
aegis migrate export --driver sqlite --out ./migrations/dev

# Staging/Production (PostgreSQL)
aegis migrate export --driver postgres --out ./migrations/prod
```

## Migration Tools Compatibility

Aegis-generated migrations work with popular migration tools:

### golang-migrate

```bash
# Install
brew install golang-migrate

# Run
migrate -path ./migrations \
  -database "postgres://localhost/mydb?sslmode=disable" up
```

### Goose

```bash
# Install
go install github.com/pressly/goose/v3/cmd/goose@latest

# Run
goose -dir ./migrations postgres \
  "user=postgres dbname=mydb sslmode=disable" up
```

### Atlas

```bash
# Install
brew install ariga/tap/atlas

# Apply
atlas migrate apply \
  --dir file://migrations \
  --url "postgres://localhost/mydb?sslmode=disable"
```

### Raw SQL

```bash
# PostgreSQL
psql -U postgres -d mydb -f migrations/001_initial.up.sql

# MySQL
mysql -u root -p mydb < migrations/001_initial.up.sql
```

## Advanced Usage

### Version Pinning

```bash
# Install specific version
go install github.com/theinventorylib/aegis/cmd/aegis@v1.2.3

# Or in go.mod
go get github.com/theinventorylib/aegis/cmd/aegis@v1.2.3
```

### CI/CD Integration

**GitHub Actions**

```yaml
name: Export Migrations
on: [push]
jobs:
  migrations:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - uses: actions/setup-go@v4
        with:
          go-version: '1.21'
      - run: go install github.com/theinventorylib/aegis/cmd/aegis@latest
      - run: aegis migrate export --driver postgres --out ./migrations
      - run: git diff --exit-code migrations/  # Fail if migrations changed
```

**GitLab CI**

```yaml
export-migrations:
  image: golang:1.21
  script:
    - go install github.com/theinventorylib/aegis/cmd/aegis@latest
    - aegis migrate export --driver postgres --out ./migrations
  artifacts:
    paths:
      - migrations/
```

## Troubleshooting

### Command Not Found

```bash
# Ensure GOPATH/bin is in PATH
export PATH=$PATH:$(go env GOPATH)/bin

# Or use full path
$(go env GOPATH)/bin/aegis migrate export
```

### Permission Denied

```bash
# Make sure output directory is writable
chmod -R 755 ./migrations
```

### Plugin Not Found

```bash
# List available plugins
aegis migrate export --help

# Check spelling (case-sensitive)
aegis migrate export --plugins emailotp,oauth  # ✓
aegis migrate export --plugins EmailOTP,OAuth  # ✗
```

## Best Practices

1. **Version Control**: Always commit generated migrations to your repository
2. **Review Changes**: Review migration diffs before applying to production
3. **Backup First**: Backup your database before applying migrations
4. **Test Locally**: Test migrations on a local database first
5. **One Direction**: Don't manually edit generated migrations

::callout{icon="i-heroicons-light-bulb" color="amber"}
**Tip**: Use `--format golang-migrate` for the most flexibility — it supports both up and down migrations and works with multiple tools.
::
