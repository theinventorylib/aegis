## Installation

```bash
go install github.com/theinventorylib/aegis/cmd/aegis@latest
```

Verify installation:

```bash
aegis version
```

## Commands

### `export`

Export database migrations for Aegis core and plugins.

#### Basic Usage

```bash
# Export PostgreSQL migrations (auth only)
aegis export --dialect postgres --output ./migrations

# Export MySQL migrations
aegis export --dialect mysql --output ./migrations

# Export SQLite migrations
aegis export --dialect sqlite --output ./migrations
```

#### Export with Plugins

```bash
# Export core + specific plugins
aegis export \
  --dialect postgres \
  --plugins emailotp,oauth,organizations \
  --output ./migrations

# Export all available plugins
aegis export \
  --dialect postgres \
  --plugins all \
  --output ./migrations
```

#### Migration Formats

Aegis supports multiple migration formats:

**SQL (Default)**
```bash
aegis export --dialect postgres --format sql --plugins emailotp --output ./migrations
```

Generates:
```
migrations/
├── 001_aegis_auth_1.sql
└── 002_aegis_email-otp_Initial schema.sql
```

**Goose**
```bash
aegis export --dialect postgres --format goose --plugins emailotp --output ./migrations
```

Generates:
```
migrations/
├── 00001_aegis_auth_1.sql
└── 00002_aegis_email-otp_Initial schema.sql
```

**golang-migrate**
```bash
aegis export --dialect postgres --format golang-migrate --plugins emailotp --output ./migrations
```

Generates:
```
migrations/
├── 000001_aegis_auth_1.up.sql
├── 000001_aegis_auth_1.down.sql
├── 000002_aegis_email-otp_Initial schema.up.sql
└── 000002_aegis_email-otp_Initial schema.down.sql
```

### Flags

| Flag | Default | Description |
|------|---------|-------------|
| `--dialect` | *(required)* | Database dialect: `postgres`, `mysql`, `sqlite` |
| `--format` | `sql` | Output format: `sql`, `goose`, `golang-migrate` |
| `--output` | `./migrations` | Output directory |
| `--plugins` | *(none)* | Comma-separated plugin list, or `all` |
| `--auth-only` | `false` | Export auth schema only (deprecated, omit `--plugins` instead) |

### Available Plugins

| Plugin | Flag Value | Description |
|--------|------------|-------------|
| Email OTP | `emailotp` | Email verification via OTP |
| SMS | `sms` | Phone verification via OTP |
| OAuth | `oauth` | Social login providers |
| JWT | `jwt` | JWT token management |
| Admin | `admin` | Administrative endpoints |
| Organizations | `organizations` | Multi-tenant support |
| OpenAPI | `openapi` | API documentation (no schema) |


## Examples

### New Project Setup

```bash
# 1. Install CLI
go install github.com/theinventorylib/aegis/cmd/aegis@latest

# 2. Export migrations
aegis export \
  --dialect postgres \
  --plugins emailotp,oauth \
  --output ./db/migrations

# 3. Apply migrations (using golang-migrate)
migrate -path ./db/migrations \
  -database "postgres://localhost/myapp?sslmode=disable" up
```

### Updating Schema (Adding a Plugin)

```bash
# Add organizations plugin
aegis export \
  --dialect postgres \
  --plugins emailotp,oauth,organizations \
  --output ./db/migrations

# Review generated migrations
ls -la ./db/migrations

# Apply new migrations
migrate -path ./db/migrations -database $DATABASE_URL up
```

### Multi-Environment Workflow

```bash
# Development (SQLite)
aegis export --dialect sqlite --output ./migrations/dev

# Staging/Production (PostgreSQL)
aegis export --dialect postgres --output ./migrations/prod
```

## Migration Tools Compatibility

Aegis-generated migrations work with popular migration tools:

### golang-migrate

```bash
# Install
brew install golang-migrate

# Run
migrate -path ./migrations \
  -database "postgres://localhost/mydb?sslmode=disable" up
```

### Goose

```bash
# Install
go install github.com/pressly/goose/v3/cmd/goose@latest

# Run
goose -dir ./migrations postgres \
  "user=postgres dbname=mydb sslmode=disable" up
```

### Atlas

```bash
# Install
brew install ariga/tap/atlas

# Apply
atlas migrate apply \
  --dir file://migrations \
  --url "postgres://localhost/mydb?sslmode=disable"
```

### Raw SQL

```bash
# PostgreSQL
psql -U postgres -d mydb -f migrations/001_aegis_auth_1.sql

# MySQL
mysql -u root -p mydb < migrations/001_aegis_auth_1.sql
```

## Advanced Usage

### Version Pinning

```bash
# Install specific version
go install github.com/theinventorylib/aegis/cmd/aegis@v1.2.3
```

### CI/CD Integration

**GitHub Actions**

```yaml
name: Export Migrations
on: [push]
jobs:
  migrations:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - uses: actions/setup-go@v4
        with:
          go-version: '1.21'
      - run: go install github.com/theinventorylib/aegis/cmd/aegis@latest
      - run: aegis export --dialect postgres --output ./migrations
      - run: git diff --exit-code migrations/  # Fail if migrations changed
```

**GitLab CI**

```yaml
export-migrations:
  image: golang:1.21
  script:
    - go install github.com/theinventorylib/aegis/cmd/aegis@latest
    - aegis export --dialect postgres --output ./migrations
  artifacts:
    paths:
      - migrations/
```

## Troubleshooting

### Command Not Found

```bash
# Ensure GOPATH/bin is in PATH
export PATH=$PATH:$(go env GOPATH)/bin

# Or use full path
$(go env GOPATH)/bin/aegis export
```

### Permission Denied

```bash
# Make sure output directory is writable
chmod -R 755 ./migrations
```

### Unknown Plugin

```bash
# Check spelling (case-sensitive, lowercase)
aegis export --plugins emailotp,oauth  # ✓
aegis export --plugins EmailOTP,OAuth  # ✗

# See all available plugins
aegis help
```

## Best Practices

1. **Version Control**: Always commit generated migrations to your repository
2. **Review Changes**: Review migration diffs before applying to production
3. **Backup First**: Backup your database before applying migrations
4. **Test Locally**: Test migrations on a local database first
5. **One Direction**: Don't manually edit generated migrations

::callout{icon="i-heroicons-light-bulb" color="amber"}
**Tip**: Use `--format goose` for the most flexibility — it supports both up and down migrations and works with multiple tools.
::
