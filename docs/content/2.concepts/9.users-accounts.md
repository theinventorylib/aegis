# Users & Accounts

Aegis separates user identity from authentication methods through a flexible user and account model. Users represent people, while accounts represent authentication providers (email/password, OAuth, etc.) linked to those users.

## User Model Structure

### Core User Fields

```go
type User struct {
    ID        string          // Unique identifier (ULID or UUID)
    Avatar    string          // Profile picture URL
    Name      string          // Display name
    Email     string          // Email address (optional for OAuth-only users)
    CreatedAt time.Time       // Account creation timestamp
    UpdatedAt time.Time       // Last modification timestamp
    Disabled  bool            // Account status (active/disabled)
    Metadata  json.RawMessage // Custom JSON data
}
```

### User Interface

For custom implementations, implement the `UserModel` interface:

```go
type UserModel interface {
    GetID() string
    SetID(string)
    GetEmail() string
    SetEmail(string)
    GetName() string
    SetName(string)
    SetCreatedAt(time.Time)
    SetUpdatedAt(time.Time)
}
```

### Creating Users

```go
import "github.com/theinventorylib/aegis/core"

// Create user with email/password
user, err := userService.CreateUser(ctx, auth.User{
    Name:  "John Doe",
    Email: "john@example.com",
}, "securePassword123!")

if err != nil {
    // Handle error (duplicate email, validation failure, etc.)
    return err
}

fmt.Println(user.ID)        // Generated ID
fmt.Println(user.CreatedAt) // Timestamp
```

Internal flow:

```go
func (s *UserService) CreateUser(ctx context.Context, user auth.User, password string) (auth.User, error) {
    // 1. Sanitize input
    user.Name = SanitizeString(user.Name, nil)
    user.Email = SanitizeEmail(user.Email)
    user.Avatar = SanitizeURL(user.Avatar)
    
    // 2. Generate ID if not provided
    if user.ID == "" {
        user.ID = GenerateID()
    }
    
    // 3. Set timestamps
    user.CreatedAt = time.Now()
    user.UpdatedAt = time.Now()
    
    // 4. Create user record
    u, err := s.userStore.Create(ctx, user)
    if err != nil {
        return u, err
    }
    
    // 5. Hash password using Argon2id
    hashedPassword, err := HashPassword(password, 
        s.hashConfig.Argon2Time,
        s.hashConfig.Argon2Memory,
        s.hashConfig.Argon2Threads,
        s.hashConfig.Argon2KeyLength,
    )
    if err != nil {
        return u, err
    }
    
    // 6. Create password account
    account := auth.Account{
        ID:                GenerateID(),
        UserID:            u.GetID(),
        Provider:          "password",
        ProviderAccountID: user.Email,
        PasswordHash:      hashedPassword,
        CreatedAt:         time.Now(),
        UpdatedAt:         time.Now(),
    }
    
    err = s.accountStore.Create(ctx, account)
    return u, err
}
```

## Password Hashing (Argon2id)

### Why Argon2id?

Aegis uses **Argon2id**, the winner of the Password Hashing Competition and recommended by OWASP:

- **Memory-hard**: Resistant to GPU/ASIC attacks
- **Side-channel resistant**: Protects against timing attacks
- **Configurable**: Tune security vs. performance
- **Future-proof**: Designed to remain secure

### Hash Format

Passwords are stored in PHC string format:

```
$argon2id$v=19$m=65536,t=1,p=4$<base64-salt>$<base64-hash>
```

Parameters:
- `v=19`: Argon2 version
- `m=65536`: Memory cost (64 MB)
- `t=1`: Time cost (iterations)
- `p=4`: Parallelism (threads)
- Salt: 16 bytes random (base64 encoded)
- Hash: 32 bytes derived key (base64 encoded)

### Default Parameters

```go
const (
    DefaultArgon2Time      = 1      // Iterations
    DefaultArgon2Memory    = 65536  // 64 MB
    DefaultArgon2Threads   = 4      // 4 parallel threads
    DefaultArgon2KeyLength = 32     // 32 byte hash
    SaltLength             = 16     // 16 byte salt
)
```

### Hashing Passwords

```go
// Hash password with default parameters
hash, err := core.HashPassword("MySecurePassword123!", 0, 0, 0, 0)
// Result: "$argon2id$v=19$m=65536,t=1,p=4$..."

// Custom parameters for higher security
hash, err := core.HashPassword("MySecurePassword123!",
    5,      // 5 iterations (slower)
    131072, // 128 MB memory
    4,      // 4 threads
    32,     // 32 byte key
)
```

### Verifying Passwords

```go
// Verify password against hash
valid, err := core.VerifyPassword("MySecurePassword123!", hash)
if !valid {
    return errors.New("invalid password")
}

// Internal verification logic
func VerifyPassword(password, hash string) (bool, error) {
    // Parse PHC string to extract parameters
    params := parseArgon2Hash(hash)
    
    // Hash password with same parameters
    derivedHash := argon2.IDKey(
        []byte(password),
        params.salt,
        params.time,
        params.memory,
        params.threads,
        params.keyLength,
    )
    
    // Constant-time comparison (prevents timing attacks)
    return subtle.ConstantTimeCompare(derivedHash, params.hash) == 1, nil
}
```

### Performance Tuning

```go
// Development/Testing (faster)
hashConfig := &core.PasswordHasherConfig{
    Argon2Time:      1,
    Argon2Memory:    32768,  // 32 MB
    Argon2Threads:   2,
    Argon2KeyLength: 32,
}

// Production (balanced)
hashConfig := &core.PasswordHasherConfig{
    Argon2Time:      3,
    Argon2Memory:    65536,  // 64 MB
    Argon2Threads:   4,
    Argon2KeyLength: 32,
}

// High Security (slower)
hashConfig := &core.PasswordHasherConfig{
    Argon2Time:      5,
    Argon2Memory:    131072, // 128 MB
    Argon2Threads:   8,
    Argon2KeyLength: 32,
}
```

Benchmark results (approximate):

| Config | Time | Security |
|--------|------|----------|
| Development | ~50ms | Medium |
| Production | ~150ms | High |
| High Security | ~400ms | Very High |

## Account Types

### Credentials Account (Email/Password)

```go
type Account struct {
    ID                string
    UserID            string
    Provider          string      // "password"
    ProviderAccountID string      // Email address
    PasswordHash      string      // Argon2id hash
    CreatedAt         time.Time
    UpdatedAt         time.Time
}

// Example
account := auth.Account{
    Provider:          "password",
    ProviderAccountID: "user@example.com",
    PasswordHash:      "$argon2id$v=19$m=65536,t=1,p=4$...",
}
```

### OAuth Account (Google, GitHub, etc.)

```go
type Account struct {
    ID                string
    UserID            string
    Provider          string      // "google", "github"
    ProviderAccountID string      // Provider's user ID
    AccessToken       string      // OAuth access token
    RefreshToken      string      // OAuth refresh token
    ExpiresAt         time.Time   // Token expiration
    CreatedAt         time.Time
    UpdatedAt         time.Time
}

// Example
account := auth.Account{
    Provider:          "google",
    ProviderAccountID: "108234567890",  // Google user ID
    AccessToken:       "ya29.a0AfH6...",
    RefreshToken:      "1//0gDRxYy...",
    ExpiresAt:         time.Now().Add(time.Hour),
}
```

### Multiple Accounts Per User

A user can have multiple authentication methods:

```go
user := auth.User{
    ID:    "user_123",
    Email: "john@example.com",
    Name:  "John Doe",
}

// Account 1: Email/Password
credentialsAccount := auth.Account{
    UserID:            user.ID,
    Provider:          "password",
    ProviderAccountID: "john@example.com",
    PasswordHash:      "$argon2id$...",
}

// Account 2: Google OAuth
googleAccount := auth.Account{
    UserID:            user.ID,
    Provider:          "google",
    ProviderAccountID: "108234567890",
    AccessToken:       "ya29...",
}

// Account 3: GitHub OAuth
githubAccount := auth.Account{
    UserID:            user.ID,
    Provider:          "github",
    ProviderAccountID: "12345678",
    AccessToken:       "gho_...",
}

// User can now sign in with email/password, Google, OR GitHub
```

### Custom Metadata

Store arbitrary JSON in the `Metadata` field:

```go
import "encoding/json"

type UserMetadata struct {
    PhoneNumber    string `json:"phone_number"`
    EmailVerified  bool   `json:"email_verified"`
    PhoneVerified  bool   `json:"phone_verified"`
    TwoFactorAuth  bool   `json:"two_factor_auth"`
    Preferences    map[string]any `json:"preferences"`
}

metadata := UserMetadata{
    PhoneNumber:   "+1-555-0123",
    EmailVerified: true,
    PhoneVerified: false,
    TwoFactorAuth: true,
    Preferences: map[string]any{
        "theme":    "dark",
        "language": "en",
    },
}

metadataJSON, _ := json.Marshal(metadata)
user.Metadata = metadataJSON

// Retrieve metadata
var meta UserMetadata
json.Unmarshal(user.Metadata, &meta)
fmt.Println(meta.PhoneNumber) // "+1-555-0123"
```

## Password Policies

### Validation Rules

```go
type PasswordPolicy struct {
    MinLength      int
    RequireUpper   bool
    RequireLower   bool
    RequireNumber  bool
    RequireSpecial bool
}

func ValidatePassword(password string, policy PasswordPolicy) error {
    if len(password) < policy.MinLength {
        return fmt.Errorf("password must be at least %d characters", policy.MinLength)
    }
    
    if policy.RequireUpper && !containsUpper(password) {
        return errors.New("password must contain uppercase letter")
    }
    
    if policy.RequireLower && !containsLower(password) {
        return errors.New("password must contain lowercase letter")
    }
    
    if policy.RequireNumber && !containsNumber(password) {
        return errors.New("password must contain number")
    }
    
    if policy.RequireSpecial && !containsSpecial(password) {
        return errors.New("password must contain special character")
    }
    
    return nil
}

// Usage
policy := PasswordPolicy{
    MinLength:      12,
    RequireUpper:   true,
    RequireLower:   true,
    RequireNumber:  true,
    RequireSpecial: true,
}

err := ValidatePassword("MyPassword123!", policy)
if err != nil {
    return err  // Password doesn't meet policy
}
```

### Password Strength Estimation

```go
import "github.com/nbutton23/zxcvbn-go"

func EstimatePasswordStrength(password string) map[string]any {
    result := zxcvbn.PasswordStrength(password, nil)
    
    return map[string]any{
        "score":       result.Score,           // 0-4
        "crack_time":  result.CrackTimeDisplay, // "centuries", "hours"
        "suggestions": result.Feedback.Suggestions,
        "warning":     result.Feedback.Warning,
    }
}

// Example
strength := EstimatePasswordStrength("password123")
// {score: 0, crack_time: "instant", warning: "This is a top-10 common password"}

strength := EstimatePasswordStrength("MyS3cur3P@ssw0rd!")
// {score: 4, crack_time: "centuries"}
```

### Password History

Prevent password reuse:

```go
type PasswordHistory struct {
    UserID    string
    Hash      string
    CreatedAt time.Time
}

func (s *UserService) UpdatePassword(ctx context.Context, userID, newPassword string) error {
    // Get password history
    history, _ := s.passwordHistoryStore.GetByUserID(ctx, userID, 5) // Last 5 passwords
    
    // Check if password was used before
    newHash, _ := HashPassword(newPassword, 0, 0, 0, 0)
    for _, entry := range history {
        valid, _ := VerifyPassword(newPassword, entry.Hash)
        if valid {
            return errors.New("password was recently used, choose a different one")
        }
    }
    
    // Update password
    s.accountStore.UpdatePassword(ctx, userID, newHash)
    
    // Save to history
    s.passwordHistoryStore.Create(ctx, PasswordHistory{
        UserID:    userID,
        Hash:      newHash,
        CreatedAt: time.Now(),
    })
    
    return nil
}
```

// Enable user account

userService.Update(ctx, user)

// Middleware checks disabled status
func RequireActiveUser(next http.Handler) http.Handler {
    return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
        user, _ := core.GetUser(r.Context())
        if user.Disabled {
            http.Error(w, "Account disabled", http.StatusForbidden)
            return
        }
        next.ServeHTTP(w, r)
    })
}

## Security Best Practices

### Input Sanitization

```go
// Automatically sanitized in CreateUser
user.Name = core.SanitizeString("  John<script>  ", nil)
// Result: "John" (trimmed, HTML stripped)

user.Email = core.SanitizeEmail("  JOHN@EXAMPLE.COM  ")
// Result: "john@example.com" (trimmed, lowercased)

user.Avatar = core.SanitizeURL("javascript:alert(1)")
// Result: "" (dangerous scheme removed)
```

### Prevent Email Enumeration

```go
// ❌ Bad: Reveals if email exists
_, err := userStore.GetUserByEmail(ctx, email)
if err != nil {
    return errors.New("email not found")
}

// ✅ Good: Generic error message
_, err := userStore.GetUserByEmail(ctx, email)
if err != nil {
    return errors.New("invalid email or password")
}
// Attacker can't tell if email exists
```

### Rate Limit Account Creation

```go
// Prevent mass account creation
rateLimiter := core.NewRateLimiter(&core.RateLimitConfig{
    RequestsPerWindow: 5,
    WindowDuration:    time.Hour,
    ByIP:              true,
}, redisClient, nil)

func handleRegister(w http.ResponseWriter, r *http.Request) {
    allowed, retryAfter, _ := rateLimiter.AllowRequest(r.Context(), "")
    if !allowed {
        http.Error(w, "Too many registration attempts", http.StatusTooManyRequests)
        return
    }
    
    // Process registration...
}
```

## Examples

### User Profile Update

```go
func handleUpdateProfile(w http.ResponseWriter, r *http.Request) {
    user, _ := core.GetUser(r.Context())
    
    var updates struct {
        Name   string `json:"name"`
        Avatar string `json:"avatar"`
    }
    json.NewDecoder(r.Body).Decode(&updates)
    
    // Update user
    user.Name = updates.Name
    user.Avatar = updates.Avatar
    user.UpdatedAt = time.Now()
    
    err := userService.Update(r.Context(), user)
    if err != nil {
        http.Error(w, "Update failed", http.StatusInternalServerError)
        return
    }
    
    json.NewEncoder(w).Encode(user)
}
```

### Password Change

```go
func handleChangePassword(w http.ResponseWriter, r *http.Request) {
    user, _ := core.GetUser(r.Context())
    
    var req struct {
        CurrentPassword string `json:"current_password"`
        NewPassword     string `json:"new_password"`
    }
    json.NewDecoder(r.Body).Decode(&req)
    
    // Verify current password
    valid, _ := accountService.VerifyPassword(r.Context(), user.GetID(), req.CurrentPassword)
    if !valid {
        http.Error(w, "Invalid current password", http.StatusUnauthorized)
        return
    }
    
    // Update password
    err := accountService.UpdatePassword(r.Context(), user.GetID(), req.NewPassword)
    if err != nil {
        http.Error(w, "Password update failed", http.StatusInternalServerError)
        return
    }
    
    // Optional: Invalidate all sessions (force re-login on all devices)
    sessionService.InvalidateAllSessions(r.Context(), user.GetID())
    
    json.NewEncoder(w).Encode(map[string]string{
        "message": "Password updated successfully",
    })
}
```
